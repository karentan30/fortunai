📈 数据流详解
═══════════════════════════════════════════════════════════════════════════════

用户反馈流程：
─────────────

  用户 → 填写反馈 → 点击提交 → Fetch POST /api/feedback
         (5星评分)
         (分类选择)
         (文本反馈)
         (可选: 姓名/邮箱)
                                    │
                                    ▼
                        验证参数 → 记录时间戳 → 记录IP/UA
                                    │
                                    ▼
                        插入 _M.feedbacks[] 数组
                                    │
                                    ▼
                        调用 _persist() 保存到 data.json
                                    │
                                    ▼
                        返回 {success: true, feedbackId: N}
                                    │
                                    ▼
                        前端显示 Toast: "感谢您的反馈"


管理员查看流程：
───────────────

  管理员 → 访问 /pages/admin-feedback.html
            │
            ▼ 检查 localStorage 中的 admin_token
            │
            ├─ Token存在 → 进入后台
            │             │
            │             ▼
            │        请求 GET /api/feedback/stats
            │             │
            │             ▼
            │        后端计算统计数据：
            │        • total: 反馈总数
            │        • avgRating: 平均分
            │        • byRating: 分布
            │        • byCategory: 分类
            │        • byReadingType: 占算类型
            │        • topIssues: 关键词
            │        • recentFeedbacks: 最近20条
            │             │
            │             ▼
            │        前端渲染仪表板
            │             │
            │        ┌────┴───────────────────┐
            │        │                        │
            │        ▼                        ▼
            │     卡片统计              柱状图表
            │     (实时更新)            (直观展示)
            │
            └─ Token不存在 → 重定向到登录页


数据统计流程：
─────────────

  _M.feedbacks[] 数组
         │
         ├─ 按评分筛选 → byRating {1, 2, 3, 4, 5}
         │
         ├─ 按分类筛选 → byCategory {quality, ui, ...}
         │
         ├─ 按占算类型 → byReadingType {bazi, tarot, ...}
         │
         └─ 文本分析 → topIssues [
              { word: "准确", count: 12 },
              { word: "加载", count: 8 },
              ...
            ]

📊 数据模型详解
═══════════════════════════════════════════════════════════════════════════════

反馈记录 (Feedback Record)
────────────────────

{
  "id": 123,                      // 自增ID
  "name": "小王",                 // 用户名 (可选，默认"匿名用户")
  "email": "wang@example.com",    // 邮箱 (可选)
  "message": "报告很准确！",      // 反馈内容 (必需)
  "rating": 5,                    // 评分 (1-5，0=不评)
  "category": "quality",          // 分类 (quality/accuracy/ui/performance/other/general)
  "readingType": "bazi",          // 占算类型 (bazi/tarot/ziwei/...)
  "lang": "zh",                   // 语言 (zh/en/kr)
  "ip": "192.168.1.1",            // IP地址 (自动记录)
  "userAgent": "Mozilla/5.0...",  // 浏览器信息 (自动记录)
  "created_at": "2026-08-11T..."  // ISO 8601时间戳
}

🔐 权限模型
═══════════════════════════════════════════════════════════════════════════════

API权限清单：

┌─────────────────────────┬──────────────┬─────────────────────┐
│ 端点                    │ 权限要求     │ 数据返回            │
├─────────────────────────┼──────────────┼─────────────────────┤
│ POST /api/feedback      │ 无需认证     │ {success, id}       │
│ GET /api/feedback/stats │ 管理员token  │ 完整统计数据        │
│ GET /api/feedback/:id   │ 管理员token  │ 单条反馈详情        │
│ DELETE /api/feedback/:id│ 管理员token  │ {success}           │
└─────────────────────────┴──────────────┴─────────────────────┘

认证流程：

  请求 → 检查 Authorization header
         │
         ├─ 无Header → 返回 {error: '需要认证', status: 401}
         │
         ├─ Token无效 → 返回 {error: '权限不足', status: 403}
         │
         └─ Token有效 → req.user = 解析的用户信息 → 继续处理
