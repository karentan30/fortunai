# 善缘地理定价系统（Geo-Pricing）集成指南

## 概述

地理定价系统根据用户所在地理位置，自动显示该地区的本地货币和价格，从而提升转化率。系统包括：

- **后端**: IP 地理位置检测 + 定价矩阵存储
- **前端**: 自动价格更新 + 缓存管理
- **安全**: 支付时后端验证价格，防止 VPN 欺骗

### 2. API 端点

已添加到 `server/index.js`：

```javascript
const geoRouter = require('./routes/geo');
app.use('/api/geo', geoRouter);
```

#### GET `/api/geo/detect`

检测用户 IP 地理位置 + 返回该国定价

**优先级顺序**:
1. CloudFlare headers (`cf-ipcountry`) — 生产推荐
2. Vercel headers (`x-vercel-ip-country`)
3. 第三方 IP API (`geojs.io` / `ip-api.com`)

**响应**:
```json
{
  "country": "US",
  "region": "north-america",
  "currency": "USD",
  "symbol": "$",
  "bazi_full": 9.90,
  "bazi_vip": 19.90,
  "hehun_full": 19.90,
  "member_monthly": 9.90,
  "member_quarterly": 24.90,
  "member_yearly": 69.00,
  "ip": "1.2.3.4",
  "source": "cloudflare"
}
```

#### GET `/api/geo/pricing/:country`

获取指定国家定价

```bash
curl https://shenyuan.mylumee.cn/api/geo/pricing/CN
```

#### POST `/api/geo/validate-price`

后端验证前端报价（支付时调用）

**请求**:
```json
{
  "country": "US",
  "product": "bazi_full",
  "amount": 9.90
}
```

**响应** (价格 ±10% 范围内):
```json
{
  "ok": true,
  "country": "US",
  "product": "bazi_full",
  "currency": "USD",
  "server_price": 9.90,
  "client_price": 9.90,
  "min_allowed": 8.91,
  "max_allowed": 10.89
}
```

#### GET `/api/geo/all` (仅 Admin)

查看所有定价矩阵

```bash
curl -H "x-admin-token: YOUR_TOKEN" https://shenyuan.mylumee.cn/api/geo/all
```

## 前端集成

### 1. 引入脚本

在 HTML 文件的 `<head>` 中加入：

```html
<script src="/geo-pricing.js"></script>
```

该脚本会在页面加载时自动：
1. 检测用户地理位置
2. 获取本地货币定价
3. 更新页面所有价格显示
4. 缓存数据 24 小时（减少 API 调用）

### 2. HTML 标记

#### 显示价格

使用 `data-price` 属性标记价格元素：

```html
<!-- 简单价格 -->
<span data-price="bazi_full">¥99</span>

<!-- 完整按钮 -->
<button onclick="GEO.createCheckout('bazi_full')">
  立即解锁 <span data-price="bazi_full">¥99</span> →
</button>

<!-- 多个产品 -->
<div class="pricing-card">
  <h3>基础报告</h3>
  <p>仅需 <span data-price="bazi_full">¥99</span></p>
  <button onclick="GEO.createCheckout('bazi_full')">购买</button>
</div>

<div class="pricing-card">
  <h3>深度报告</h3>
  <p>仅需 <span data-price="bazi_vip">¥199</span></p>
  <button onclick="GEO.createCheckout('bazi_vip')">购买</button>
</div>
```

#### 显示货币符号

```html
<span data-currency-symbol>¥</span>99
<!-- 自动变为 $99 (美国) 或 €99 (欧洲) 等 -->
```

### 3. JavaScript 集成

#### 获取当前定价

```javascript
const pricing = GEO.getPricingData();
console.log(pricing.country);      // 'US'
console.log(pricing.currency);     // 'USD'
console.log(pricing.symbol);       // '$'
console.log(pricing.bazi_full);    // 9.90
```

#### 手动更新价格（用户改国家时）

```javascript
// 用户选择了中国
GEO.updatePricingByCountry('CN');
```

#### 创建支付

```javascript
// 自动处理微信/支付宝/Stripe
GEO.createCheckout('bazi_full');
```

#### 验证价格（可选）

```javascript
const isValid = await GEO.validatePriceBeforeCheckout('bazi_full', 9.90);
if (isValid) {
  // 继续支付流程
}
```

#### 监听价格更新事件

```javascript
document.addEventListener('geopricing-updated', (e) => {
  const pricing = e.detail;
  console.log('Prices updated for', pricing.country);
  // 自定义逻辑
});
```

## 支付流程集成

### Stripe 支付（海外用户）

后端已支持（无需改动）:

```javascript
// 前端自动调用 GEO.createCheckout()
// ↓
// 后端 POST /api/create-checkout 接收 geo 信息
// ↓
// 返回 Stripe Checkout URL
// ↓
// 用户跳转到 Stripe 支付
```

### 微信/支付宝支付（国内用户）

后端已支持（无需改动）:

```javascript
// 前端自动检测 country === 'CN'
// ↓
// 自动调用 POST /api/pay/wechat/create 而非 Stripe
// ↓
// 返回二维码或支付链接
```

### 支付时价格验证

在 `server/routes/payment.js` 中已添加安全检查：

```javascript
// create-checkout 端点
const { currency, country, amount } = req.body;

// 后端检查价格是否合理
const serverPrice = GEO_PRICING[country][product];
if (amount < serverPrice * 0.9) {  // 允许 10% 偏差
  return res.status(400).json({error: 'Price mismatch - possible fraud'});
}
```

## 故障排查

### 价格不更新

**症状**: 页面加载后价格仍是硬编码值

**排查**:
1. 检查浏览器控制台：`[GEO]` 开头的日志
2. 确认 `geo-pricing.js` 已加载：`window.GEO` 存在
3. 检查 HTML 元素是否有 `data-price` 属性
4. 清除 localStorage: `localStorage.removeItem('sy_user_geo')`

### 获取 IP 失败

**症状**: 总是显示默认价格（USD）

**排查**:
1. 检查后端日志：`[GEO]` 开头
2. 如果是本地开发，IP 可能被识别为 localhost（预期行为）
3. 在生产服务器上测试（需要公网 IP）
4. 检查防火墙是否拦截了 `geojs.io` 或 `ip-api.com` 请求

### Stripe 支付报错

**症状**: 支付流程报错 "Price mismatch"

**排查**:
1. 确认前端价格与后端 `geo-pricing.js` 一致
2. 后端验证允许 ±10% 偏差（汇率浮动）
3. 检查是否在支付时修改了 `currency` 参数
4. 查看后端日志中的 `[CHECKOUT ERR]`

### VPN 用户支付异常

**症状**: VPN 用户显示当地价格但被拦截

**解决**: 这是预期行为（防止欺骗）。VPN 用户会看到本地价格，支付金额不匹配时被拒绝。可以：

1. 允许用户手动选择国家：
   ```html
   <select onchange="GEO.updatePricingByCountry(this.value)">
     <option value="US">United States</option>
     <option value="CN">中国大陆</option>
   </select>
   ```

2. 放宽后端检查范围（修改 `±10%` 为 `±20%`）
