# 商业方案 · AI 报告 = 命理师赋能供给引擎

> 决策文档 · 2026-07-30 · 供拍板用
> 一句话:**把 9.6 分 AI 万字深报告从"卖给用户的商品",升级为"招募素人做真人连麦的供给引擎",用充足供给解开真人连麦(第一 ROI 爆款)的供给死结。**
> 战略对齐:算命=基本盘(桶 A),真人连麦=桶 C 高客单曲线;本方案是桶 C 的供给侧引擎设计。见 `project_shenyuan_revenue_strategy` / `project_shenyuan_competitors`。

---

## 1. 机会定义 — 为什么这能解开供给死结

**死结**:真人连麦是记忆里定的**第一 ROI 爆款**(测测/高人汇/천명验证),但瓶颈永远是**供给侧**——真大师稀缺、难招、难标准化、成本高、还有资质合规风险。善缘现 6 个"大师"是虚构人设,**不能真收钱(=欺诈,踩测测雷)**。没供给,连麦这条最赚的线就是死的。

**钥匙(创始人洞察)**:AI 深报告已经具体到"照着念就能算"。这意味着**咨询师的专业门槛从"十年命理功力"降到"会念会共情"**——报告=预生成的专业弹药,素人在报告基础上做**温度、陪伴、互动**即可上麦。供给来源从"稀缺老师傅"变成"海量可培训兼职",供给曲线一夜拉平。

**市场**:全球华人八字连麦 + 韩国 사주($3.7B、66-70% 国民每年算命)。竞品验证客单:Sanctuary $49.99/10 分、Nebula $120/年、천명 5-30 万韩元/次、高人汇达人"半小时四位数"。平台抽成 30-50%。善缘差异化=**AI 深报告作弹药,让平台能自建供给收全款**,而非做第 4 层分账给别人打工。

## 2. 三种变现路径

| # | 路径 | 怎么运作 | 收入模型 | 启动难度 |
|---|------|----------|----------|----------|
| ① | **to C 自购报告(现有)** | 用户直接买 AI 深报告/订阅 | 报告 9,900–19,900 韩元 / $15/月订阅;90% 毛利 | ★ 已跑通,基本盘桶 A |
| ② | **供给引擎(最狠·本方案核心)** | 招素人→AI 报告转连麦脚本→上麦念+共情+互动→平台按分钟计费,与咨询师分账 | 用户付 $2–4/分钟(≈Sanctuary/천명);平台抽 **40-50%**;报告成本几分钱;咨询师赚剩余=其兼职时薪吸引力 | ★★★ 需招募+培训+质检+分账系统(Lumee 可复用) |
| ③ | **to B 卖工具给现有命理师/塔罗店** | 把"AI 报告→脚本生成器"打包成 SaaS,卖给已有客源的命理师/塔罗店/寺庙,帮他们提效接更多单 | SaaS 订阅 $49–199/月/席,或按报告 $5–10 抽量 | ★★ 无需自建供给,但获客慢、教育成本高、放大竞对 |

**排序结论**:② 是主力增长引擎(自建供给 + 高抽成 + 报告近零成本),① 是现金地基,③ 是后期渠道补充(优先级最低,因为等于武装潜在竞对)。**本方案聚焦 ②。**

## 3. 供给引擎详细设计(核心)

### 3.1 招募什么人
**不招"大师",招"会共情的兼职念稿人"**。目标画像:
- 华人区兼职宝妈/退休/大学生/客服背景;声音温暖、耐心、会聊天;对命理有兴趣但**无需专业功底**。
- 韩国城:25-40 女性、语气温柔重情(契合韩式 사주陪伴文化)。
- **绝不招需要伪造资质的"名师"**——定位就是"陪伴顾问",反而没有资质门槛。

### 3.2 培训 / 话术工具(AI 报告 → 连麦脚本)
这是引擎心脏。产品要做一个 **"连麦驾驶舱"**(咨询师上麦时的屏幕):
1. **一键脚本化**:AI 报告自动拆成**连麦话术卡**——开场破冰句 / 用户此刻最可能问的 3 个问题 / 每个问题对应的报告要点 + 温柔话术 / 收尾祝福句。咨询师**照着念 + 自己的温度**。
2. **实时提词**:用户说"我最近工作不顺",系统从报告里秒调"事业宫/大运"段落浮到屏幕。
3. **话术护栏(硬编码)**:提词卡内置**禁语高亮**——不承诺治病/发财/投资,自动插入免责话术。
4. **7 天上岗培训**:2 小时话术课 + 5 场陪练(AI 扮用户)+ 1 场真人考核。**门槛低到一周能量产供给**。

### 3.3 质检
- **上岗考核**:陪练评分≥8 才放行(复用产审分离:AI 打分 + 人工抽审)。
- **过程质检**:云录音(**双方同意才录**,复用 Lumee `call_sessions` 合规设计)+ AI 抽检情绪/禁语违规。
- **结果质检**:每场后用户评分,<4 星人工复听;连续低分/触碰禁语=**降权→停牌**。
- **用户端信任**:显示"AI 辅助陪伴顾问"+ 真实评分,不造假资质。

### 3.4 抽成分账
- **平台抽 40-50%**(报告成本几分钱可全吃在平台侧,咨询师净得高于纯人力平台=招募吸引力)。
- 复用 **Lumee 生产级引擎**:`_call_fee(duration, rate_per_minute)` 按分钟计量 + `call_credit_ledger` 钱包 + `counselor_settlement` 佣金结算 + `_counselor_apply` 入驻。**省的是踩过的坑**(Agora token 续期/云录音合规/计量/分账),Python→Node 重写即可。
- 咨询师分档费率(参考测测 10 级):新手低价引流 → 高分晋级涨价,平台按分成不变。

### 3.5 冷启动:前 50 个咨询师怎么找
1. **第 1-10 个:自己人 + 熟人内测**(团队/朋友/宝妈群),验证脚本工具好不好用。
2. **第 10-30 个:内容获客反向招募**——小红书/TikTok 发"在家兼职做情感陪伴顾问,AI 帮你准备,时薪 $X"(同一批爆款内容既拉用户也拉供给,双面市场同源获客)。
3. **第 30-50 个:定向华人区**(法拉盛/Monterey Park/San Gabriel/Markham)兼职社群 + 韩国 MZ 女性社群。
4. **供需配平**:先攒 20-30 个咨询师再放量拉用户,避免用户约不到人;初期用**预约兜底**(复用 Lumee `bookings` 异步预约)填即时供给缺口。

## 4. 三条红线(必须内建)

**红线 1 · 定位护栏 —— "AI 辅助陪伴顾问",不是"高人"。**
素人冒充大师若被识破=品牌重伤(测测达人"资质可代考"已爆雷)。**产品文案、头衔、宣传一律"AI 辅助陪伴顾问 / 命理陪伴师"**,主打"AI 出专业底稿 + 真人给你温度陪伴",诚实反而是差异化。绝不打"名师""大师"旗号。

**红线 2 · 合规免责 —— 不承诺治病/投资,免责必现。**
话术卡硬编码禁语(治病、发财、投资、必然),自动插入免责("仅供参考娱乐,不构成医疗/投资/法律建议")。云录音双方同意才录。韩国加娱乐免责应对 2026 AI 法。**与 slim 健康红线同价值观:诚实健康、不制造焦虑、不诱导高消费**(测测半年充 13 万反面教材)。设月消费软顶提醒。

**红线 3 · 护城河不在报告,在真人温度 + memory + 互动。**
纯照念=同质化(报告谁都能生成)。**报告是弹药,不是护城河**。护城河三件:①真人温度(共情、即时回应)②**memory 记住用户**(复用 Lumee 军师+钱包引擎:记住上次聊的事、复购时"上次你说要换工作,后来呢")③连麦实时互动(掷筊/今日运势/命格卡等仪式感)。报告可复制,"记得你的顾问"不可复制。

## 5. 90 天验证计划(最小成本跑通)

**目标**:验证"素人靠 AI 报告能不能上麦交付,用户愿不愿付费,单位经济成不成立"。

| 阶段 | 时间 | 动作 | 成功指标(Gate) |
|------|------|------|------------------|
| **P0 手动 MVP** | 第 1-2 周 | 不写复杂系统。**招 5-10 个咨询师**(熟人),脚本工具用**报告 + 人工整理的话术卡(Google Doc)**,连麦直接用 Lumee 现成 Agora 端点。 | 5 个咨询师完成培训 + 通过考核 |
| **P1 小范围真收费** | 第 3-6 周 | 拉 30-50 个真实付费用户(内容获客),真金白银按分钟付费。人工质检每一场。 | 完成 100+ 场付费连麦;**用户评分均≥4.3**;复购率>15% |
| **P2 工具化 + 配平** | 第 7-10 周 | 把话术卡做成产品内"连麦驾驶舱" v1(自动拆报告);咨询师扩到 20-30;跑供需配平。 | 咨询师上麦准备时间<5 分钟;约不到人的比例<10% |
| **P3 单位经济验证** | 第 11-13 周 | 结算真实分账,算清 LTV/CAC、单场毛利、咨询师留存。 | **单场毛利为正**;咨询师 4 周留存>50%;CAC 回收<3 个月 |

**总预算**:主要是 Agora 用量 + 内容获客投放 + 咨询师前期保底/激励。生图/API 成本走本机 ComfyUI/DeepSeek 压到最低。**任何付费投放/API 前先给 Karen 预算数字点头**(遵循花钱审批铁律)。

## 6. 风险与止损点

| 风险 | 信号 | 止损动作 |
|------|------|----------|
| **素人交付质量撑不住** | P1 用户评分<4.0 或差评集中在"不专业/尬" | 收紧考核门槛;若话术工具无法让素人达标 → **回退 to C 报告 + 纯 AI 军师**,连麦转"少量精选顾问" |
| **供需失衡**(约不到人 / 咨询师没单闲置) | 约不到>20% 或咨询师周留存<40% | 预约兜底 + 高峰调度 + 分时费率;供给过剩则暂停招募 |
| **合规/舆情**(被指冒充大师、诱导消费) | 平台投诉、媒体质疑、监管问询 | 红线 1-2 是硬护栏;设消费软顶;必要时下线争议话术。**诚实定位是保险** |
| **单位经济不成立** | P3 单场毛利为负 / CAC 回收>4 个月 | 提高抽成或客单;砍投放转自然内容获客;若仍不成立 → 供给引擎降级为桶 A 报告的增值附加,不作独立主力 |
| **IP/资质风险** | "麦玲玲"名号误用、咨询师伪造资质 | 只用"麦玲玲风格"不打名号(除非授权);咨询师一律"陪伴顾问"无资质声明 |

**总止损原则**:桶 A(报告+订阅,90% 毛利)是地基**永远不动**。供给引擎(桶 C)是**高客单增长实验**——90 天任一 Gate 连续不达标即降级为报告增值项,不拖累基本盘现金流。
