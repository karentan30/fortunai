## 一、数据表结构

### 表1: referrals（邀请关系记录）
```sql
CREATE TABLE referrals (
  id INT PRIMARY KEY AUTO_INCREMENT,
  referrer_id INT NOT NULL,        -- 邀请人ID
  referee_id INT,                   -- 被邀请人ID（可null，未注册）
  referee_email VARCHAR(255),       -- 被邀请人邮箱（用于追踪）
  ref_code VARCHAR(20) UNIQUE,      -- 邀请码（6位大写base36）
  status ENUM('pending','completed','expired'),  -- pending邀请/completed付费/expired过期
  created_at TIMESTAMP DEFAULT NOW(),
  completed_at TIMESTAMP,           -- 被邀请人付费时间
  expires_at TIMESTAMP,             -- 邀请链接过期时间(30天)
  INDEX idx_referrer (referrer_id),
  INDEX idx_referee (referee_id),
  INDEX idx_ref_code (ref_code)
);
```

### 表2: referral_rewards（返佣奖励记录）
```sql
CREATE TABLE referral_rewards (
  id INT PRIMARY KEY AUTO_INCREMENT,
  referrer_id INT NOT NULL,        -- 邀请人ID
  referee_id INT,                  -- 被邀请人ID
  referee_order_id INT,            -- 被邀请人的订单ID
  reward_type ENUM('cash','discount','product'),  -- 奖励类型
  amount DECIMAL(10,2),            -- 返佣金额/折扣额
  currency VARCHAR(3),             -- CNY/USD/KRW
  status ENUM('pending','paid','claimed'),  -- pending未到账/paid已发放/claimed已兑现
  created_at TIMESTAMP DEFAULT NOW(),
  paid_at TIMESTAMP,               -- 发放时间
  tier INT,                         -- Tier等级(1/2/3)
  INDEX idx_referrer (referrer_id),
  INDEX idx_status (status),
  INDEX idx_created (created_at)
);
```

### 表3: referral_stats（用户裂变统计）
```sql
CREATE TABLE referral_stats (
  user_id INT PRIMARY KEY,
  total_referrals INT DEFAULT 0,       -- 邀请总数
  completed_referrals INT DEFAULT 0,   -- 成功转化数
  total_rewards DECIMAL(10,2),         -- 总返佣金额
  tier_1_unlocked BOOL DEFAULT FALSE,  -- 解锁Tier1(3人)
  tier_2_unlocked BOOL DEFAULT FALSE,  -- 解锁Tier2(10人)
  tier_3_unlocked BOOL DEFAULT FALSE,  -- 解锁Tier3(50人)
  last_updated TIMESTAMP DEFAULT NOW() ON UPDATE NOW(),
  INDEX idx_user (user_id)
);
```

## 三、后端实现

### 3.1 邀请链接API
```javascript
// POST /api/referral/link
router.post('/referral/link', authMiddleware, (req, res) => {
  try {
    const userId = req.user.id;
    const user = getUserById.get(userId);
    if (!user) return res.status(404).json({ error: 'user_not_found' });
    
    const refCode = user.ref_code; // 用户唯一邀请码
    const shareableUrl = `${process.env.FRONTEND_URL}/pages/bazi.html?ref=${refCode}`;
    
    // 返回邀请链接（带短链服务优化）
    res.json({
      ref_code: refCode,
      shareable_url: shareableUrl,
      qr_code_data: generateQR(shareableUrl) // 二维码data-uri
    });
  } catch (err) {
    res.status(500).json({ error: err.message });
  }
});
```

### 3.2 邀请追踪
```javascript
// GET /pages/bazi.html?ref=ABC123
// 前端在页面加载时调用
async function trackReferral(refCode) {
  if (!refCode) return;
  
  localStorage.setItem('referral_code', refCode); // 保存邀请码
  
  // 记录访问
  await fetch('/api/referral/track', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ ref_code: refCode })
  });
}
```

### 3.3 邀请完成触发
```javascript
// routes/payment.js webhook回调中
router.post('/stripe-webhook', (req, res) => {
  // ... 现有webhook逻辑 ...
  
  if (event.type === 'charge.succeeded') {
    const orderId = event.data.object.metadata.order_id;
    const order = _findOrder(orderId);
    
    // 检查是否来自邀请链接
    const refCode = order.referral_code; // 订单中保存ref_code
    if (refCode) {
      completeReferral(refCode, order); // 触发返佣
    }
  }
});

function completeReferral(refCode, order) {
  // 1. 更新referrals表状态
  const referral = _M.referrals.find(r => r.ref_code === refCode);
  if (!referral) return;
  
  referral.status = 'completed';
  referral.completed_at = new Date().toISOString();
  
  // 2. 生成返佣记录
  const reward = calculateReward(referral.referrer_id, order);
  _M.referral_rewards.push({
    id: _M._id.rw++,
    referrer_id: referral.referrer_id,
    referee_id: order.user_id,
    referee_order_id: order.id,
    reward_type: reward.type,
    amount: reward.amount,
    currency: order.currency,
    status: 'pending', // 待发放
    created_at: new Date().toISOString(),
    tier: calculateTier(referral.referrer_id)
  });
  
  // 3. 更新统计表
  updateReferralStats(referral.referrer_id);
  
  _persist();
}
```

## 四、返佣规则（关键商业逻辑）

### Tier 1: 新用户激励（0-3邀请）
| 邀请人数 | 触发返佣 | 奖励形式 | 金额 |
|---------|--------|--------|------|
| 1人付费 | ✅ | 折扣码 | ¥5 或 $0.99 |
| 3人付费 | 解锁Tier1 | 1个月会员 | +会员权益 |

**文案**: "邀请朋友 3 人，免费用 1 个月会员"

### Tier 2: 活跃邀请人（4-10邀请）
| 邀请人数 | 触发返佣 | 奖励形式 | 金额 |
|---------|--------|--------|------|
| 每 1 人付费 | ✅ | 现金返佣 | ¥10 或 $1.99 |
| 10 人付费 | 解锁Tier2 | 运营佣金 | ¥50 或 $9.99 |

**文案**: "邀请伙伴赚返佣，每单 ¥10，月入 1000+"

### Tier 3: 命理师合作（11-50+邀请）
| 邀请人数 | 触发返佣 | 奖励形式 | 金额 |
|---------|--------|--------|------|
| 每 1 人付费 | ✅ | 返佣提升 | ¥15 或 $2.99 |
| 50 人付费 | 解锁Tier3 | VIP标签 | "合作命理师" |
| 月度Top5 | ✅ | 额外奖励 | ¥1000 或 Bonus |

**文案**: "成为善缘合作命理师，月均邀请 50+ 用户，年收入 ¥30K+"

## 七、风险控制

### 7.1 反作弊
- 同一IP/设备邀请超过10个账户 → 标记为风险账户
- 邀请人与被邀请人同一设备 → 不计返佣
- 邀请人本人多次付费"自购" → 一个月限制1单返佣

### 7.2 风险文案
```
【邀请协议】
- 邀请人必须诚实推荐，不得虚假宣传
- 违反用户协议的邀请，返佣立即作废
- 恶意刷单账户，冻结返佣并可能起诉
- 如有异议可联系: support@shenyuan.mylumee.cn
```
