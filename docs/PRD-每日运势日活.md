## 0. 一句话定位

> **命盘×今日干支 = 属于你的今天，不是每个人的今天。**  
> Moonly 卖月相氛围感，Runae 卖精算：你的日主 + 今日天干地支 → 今天对你意味着什么。这是任何通用星座 App 无法复制的护城河。

---

## 1. 核心差异化：为什么是"真个性化"

| | 通用星座运势（Co-Star / Nebula）| Runae 每日运势 |
|---|---|---|
| 个性化基础 | 太阳星座（12种）| 八字日主 × 今日干支（60甲子 × 个人命盘 = 实际上每人每天唯一）|
| 内容来源 | 通用文案编辑/AI | 后端引擎计算干支关系（生克冲合）+ LLM 解读 |
| 时效精度 | 星座日运（约1/12人相同）| 日主 + 今日天干冲合关系（精确到个人） |
| 节气/月相 | 无或通用 | 24节气 × 个人命盘（节气日缺什么五行/命盘如何应对）|
| 数据沉淀 | 无 | 用户越用，命历越丰富，迁移成本越高 |

**护城河来源**：Runae 后端已有 `computeBaziChart()` 可算出用户日主、五行强弱、大运流年。今日天干地支可由现有 `calcBazi()` 对今天的年月日时算出。两者合并 = 个性化日运，不需要额外引擎。

## 2. 每日运势核心内容设计

### 2.1 每日运势卡 · 六个模块

用户每天打开 App 看到一张「今日命盘×天机卡」，包含以下六层：

**① 今日干支 × 命盘关系**（最核心·差异化来源）
- 今日天干地支（如「甲子日」）与用户日主的生克关系
- 用一句白话说透：「今天甲木克你的日主戊土——对你来说是压力日，但压力中有机遇」
- 不是泛化的「今日主旺」，是具体的「对你的日主来说今天是什么关系」

**② 今日宜忌**（可执行·打开欲望强）
- 宜：具体到行为（「宜签约」「宜见长辈」「宜学习新技能」）
- 忌：同样具体（「忌冲动消费」「忌动土搬家」「忌午时出行」）
- 来源：今日日柱 + 月令 + 用户五行喜用神的综合推算

**③ 幸运信息三件套**（分享钩子·视觉亮点）
- 幸运色（1-2个，说明五行原因）
- 幸运方位（1个，与喜用神方位对应）
- 最吉时辰（一个2小时窗口，「今天 09:00-11:00 是你的黄金时段」）

**④ 情绪调频·今日一句**（心理共鸣·情感粘性）
- 不是通用励志金句，而是基于今日干支能量写的「命理师悄悄话」
- 风格：「你的木性今天受到克制，感到控制不住局面是正常的——今天不是输，是在蓄力。」
- 这是用户截图分享的主力内容

**⑤ 今日古诗词配运势**（仪式感·文化内核）
- 选一首与今日干支意象相关的古诗（木日=春/生发类，水日=冬/沉淀类）
- 一句白话连接诗词与今日能量
- 海外华人情感共鸣点：远离家乡，古诗是文化锚点

**⑥ 明日预告钩子**（FOMO·拉次日回访）
- 「明天是[节气名/月相名/特殊干支日]，对你的[命盘维度]意味着[悬念]——明天来看」
- 会员免费看预告，非会员看到锁定提示

### 2.2 会员 vs 免费分层

| 内容 | 免费用户 | 会员（$14.99/月）|
|---|---|---|
| 今日干支×命盘关系（①）| ✅ 简版（1句话）| ✅ 完整（200字）|
| 今日宜忌（②）| ✅ 各2条 | ✅ 各5条 + 时辰精确版 |
| 幸运信息（③）| ✅ 完整 | ✅ 完整 + 流年叠加分析 |
| 情绪调频一句话（④）| ✅ 完整 | ✅ 完整 |
| 今日古诗词（⑤）| ✅ 完整 | ✅ 完整 |
| 明日预告（⑥）| ❌ 锁定 | ✅ 解锁 |
| 本周运势概览 | ❌ 锁定 | ✅ 解锁 |
| 节气/月相特别版完整版 | ❌ 锁定（见预告）| ✅ 解锁 |
| AI 追问（「今天签合同好吗？」）| 3次/日 | 无限 |

**设计原则**：免费用户获得真实价值（不是乞丐版），付费用户获得深度和预见性。免费足以形成习惯，会员提供不回去的理由。

## 3. 仪式感每日刷新设计

### 3.1 「今天不一样」的五个机制

**机制一：内容真的每天不同（最基本，Moonly 的核心）**
- 今日干支 60甲子 × 个人命盘 → 内容实质不同，不是换皮
- 节气日（24次/年）、月相日（约24次/年）内容有特别版本（见第4节）
- 防重复：同一用户同一天只生成一次内容，缓存24小时，保持一致性（现有 `seed` 机制已实现）

**机制二：每日解锁感（视觉仪式）**
- App 打开动画：当日日期以毛笔书法字渐入（「甲子」「丙午」）
- 今日运势卡从折叠态展开（类似拆信封/展开卷轴）
- 节气日：特别开场动画（立春=枝芽破土/冬至=雪花落定）

**机制三：时间窗口稀缺**
- 今日宜忌显示倒计时（「今日内容剩余 XX 小时」）
- 昨日内容变灰可翻阅，但无法互动（形成「今天不看就过了」的 FOMO）
- 会员专属：「今天 09:00-11:00 黄金时段」→ 具体时间窗口制造紧迫感

**机制四：「今日命历」积累感**
- 用户每次打开，历史日历有一个小点（打开过=亮色/未打开=暗色）
- 连续打开 streak 显示（「你已连续查看 7 天天机」）—— 不是核心功能，是后台默默跑，不强推
- 年底推出「我的 2026 命历回顾」→ 召回沉默用户

**机制五：「今天你不一样」的个性化语言**
- 所有文案里有用户的「日主」称谓（「你的庚金今天……」）
- 不是「亲爱的用户」，是「庚金日主的你」
- 人格叫「玄机」（参考竞品 Moonly 的 Luna AI）：每天早晨「玄机」给你说一句话

### 3.2 早安卡 / 今日签 · 视觉规格

每日运势卡的视觉设计（复用现有宣纸山水渲染管线）：

**版式：竖版 9:16（小红书/IG Stories 友好）**
- 底图：宣纸山水（已有 ComfyUI 管线，根据今日五行选调色——木日青绿/火日朱红/水日墨蓝）
- 顶部：日期（阳历 + 农历 + 干支）+ 今日月相图标
- 中部：今日主题词（「蓄势」「扩张」「收敛」）+ 宜忌各2条
- 底部：情绪调频一句话 + Runae logo + runae.net
- 生成机制：后端根据今日五行选 5 种底图模板之一（木/火/土/金/水），无需实时 ComfyUI

**分享钩子**：用户可一键「保存今日早安卡」→ 小红书/IG 分享 → 带 Runae 水印的品牌曝光

### 4.2 月相触发（约 24 个/年）

| 月相类型 | 频率 | 命理意义 | 特别版内容 |
|---|---|---|---|
| **新月（朔）** | 12次/年 | 开始·播种·意图设定 | 「新月之夜·今晚该许下什么愿」+ 12个月的新月日期提前公布给会员 |
| **满月（望）** | 12次/年 | 收获·释放·顶点 | 「满月能量最强·你[日主]今天的能量叠加是…」+ 释放仪式建议 |

**月相 × 八字的个性化**（Runae 独有）：
- 新月在什么宫位（根据用户上升星座，但更深层用日支所在宫位）
- 对用户日主的影响（水月新月对水日主 = 极旺，对火日主 = 被克）
- 本月该着重什么（感情/事业/健康）

**月相特别版推送文案示例**：
- 新月：「[日主]，今晚新月来了。对你来说，这一轮月是[X]——你今晚该做一件事：[具体]。」
- 满月：「满月了，[日主]的你今晚能量[Y]。释放：[X]。今晚 22:00-23:00 是最佳时窗。」

### 4.3 节气 × 月相重叠的稀有节点（年均约 2-3 次）

当节气日 ≈ 新月/满月（相差 ≤ 2天），标注为「稀有天象日」，推送力度翻倍：
- 「今年最特别的一天——节气与满月同日，对你意味着[命盘分析]」
- 历史上最近一次：2026 年冬至 + 满月重叠（约 12/21，具体以天文历为准）

### 4.4 全年触发节点汇总

| 类别 | 数量 | 触发间隔 |
|---|---|---|
| 24节气 | 24 | 约每15天一次 |
| 新月 | 12 | 约每29.5天一次 |
| 满月 | 12 | 约每29.5天一次 |
| 稀有重叠节点 | 约2-3 | 不定期 |
| **合计** | **约50-51个** | **平均每7天一个特别版** |

> 平均每7天就有一个「今天不一样」的特别版——这正是 Moonly 日活飞轮的核心密度。Runae 做到这个频率后，用户不敢断签。

## 5. 日活驱动 × 续费飞轮

### 5.1 每日推送策略

**推送频率**：每日一条（用户自选时间，默认早 8:00）

**推送分层**：

| 推送类型 | 触发条件 | 文案角度 | 预期打开率 |
|---|---|---|---|
| 每日早安推送 | 每天（用户允许推送）| 「[日主]，今天[干支日]，你的黄金时段是…」| 25-35% |
| 节气特别推送 | 24节气前一晚 | 「明天是立春·今年你的[运势维度]有特别天机·明天来看」| 45-55% |
| 月相特别推送 | 新月/满月当天 | 「今晚满月·[日主]今晚能量[X]·限时仪式建议」| 50-60% |
| 大运切换提醒 | 用户命盘大运年 | 「你今年进入新大运·十年磁场在改变·来看怎么走」| 70%+ |
| 流年更新推送 | 每年立春 | 「新流年开始了·你的[年份]运势报告已就绪」| 60%+ |
| 沉默召回 | 7天未打开 | 「你已经 7 天没看天机了·这 7 天[日主]经历了[节气/月相]变化」| 20-30% |

**推送合规**：
- 不恐吓（禁「今天不看会有[X]」）
- 走「有更新/有变化/你的时机」正向框架
- 用户可随时关闭推送，不强迫

### 5.2 Streak 打卡机制

**设计哲学**：Moonly 做隐性 streak（积累感，不强制），不学 Duolingo 的强迫打断感。

**实现**：
- 每日打开 = 记录一个「查看记录」点（现有 `updateStreak()` 已实现）
- 连续7天：「你连续 7 天查看天机，你的[日主]正在稳定……」（轻提示）
- 连续30天：解锁一个「命历月报」（AI 汇总上月宜忌执行情况）—— 会员专属
- 断签：不责怪，只说「欢迎回来，这几天你错过了[X节气/月相]，来补看一下」

**Streak 不是核心**，是锦上添花。核心是内容本身每天有价值。

### 5.3 每日运势 × 会员续费绑定

**关键原则**（来自 CMO 文档）：每日运势是会员的专属高频内容，但不蚕食单报告。

**免费给：** 今日干支概要 + 宜忌（简版）+ 情绪调频一句 + 古诗词 — 真实有用，建立习惯

**会员给（不可替代）：**
- 完整每日解读（200字 vs 50字）
- 明日预告（非会员看到锁定）
- 节气/月相完整特别版
- 本周运势概览
- 大运 / 流年年度更新（天然续费理由：每年立春换流年→续费就有新内容）
- AI 追问无限次（「今天适合去面试吗？」→ 结合命盘当日实时回答）

**续费情感钩子**（非功能列举，参考竞品文案改法）：
- 续费前：「你明年有[X]个命理师标注的关键节点，会员到期后将不再收到提醒」
- 到期后：「你的[日主]在这个月进入了[大运/流年]的新阶段，来看看接下来会怎样」
- 不用折扣码，用「你命盘里有个未解锁的时间节点」

## 6. 技术复用与新增评估

### 6.1 现有可复用资产

| 资产 | 位置 | 复用方式 |
|---|---|---|
| 每日运势主端点 | `server/routes/daily.js` · POST `/api/daily` | **直接复用**，已实现六大模块中文/英文/韩文版，已有免费次数门控（3次/日）+ 会员无限 |
| 明日运势悬念预告 | `server/routes/divination.js` · GET `/api/daily-teaser` | **直接复用**，已实现悬念式预告，可扩展为节气/月相专属文案 |
| 八字命盘引擎 | `server/lib/bazi-engine/index.js` · `computeBaziChart()` | **直接复用**，可算出用户日主、五行强弱、大运流年 |
| 今日干支计算 | `server/routes/daily.js` 内 `seed + 今日元素` 逻辑 | **已有基础**，但仅用于 `seed` 而未输出真实干支名——需扩展为完整60甲子日柱计算 |
| Streak 记录 | `server/routes/daily.js` · `updateStreak()` | **直接复用** |
| 推送服务 | `server/routes/push.js` | **直接复用**，需增加节气/月相触发逻辑 |
| 宣纸山水渲染管线 | `scripts/` ComfyUI 管线 | **复用底图模板**（5种五行底图）→ 每日卡片直接套模板，无需实时生图 |
| 月相计算（西方占星）| `server/routes/divination.js` · `chart.moonPhase` | **已有**，复用到每日运势卡的月相图标 |
| 语言多语言框架 | `daily.js` 内 ZH/EN/KO 三语言 | **直接复用** |

### 6.2 需要新增 / 扩展

| 功能 | 复杂度 | 说明 |
|---|---|---|
| **今日真实干支算法** | 低 | 当前 `seed` 只算五行倾向，未输出「甲子日」「丙午日」真实干支名。需用60甲子轮算今日真实日柱（纯算法，无 AI，可复用 `calcBazi(today)` 思路） |
| **日主 × 今日干支关系判断** | 中 | 判断用户日主与今日天干的生克冲合关系（「木克土」「金生水」等），用于个性化解读 prompt。纯算法，10行代码可实现五行生克表 |
| **24节气日期表** | 低 | 静态数据（2026-2028 年节气精确日期），已有前述竞品文档中的示例日期，可直接硬编码或引入 `lunar-javascript` 库 |
| **月相精确日期** | 低 | 月相已有 `chart.moonPhase` 计算，需封装为「今天是否是新月/满月」的判断函数（误差±2天接受） |
| **节气/月相特别版 prompt 库** | 中 | 24个节气 × 5个五行日主类型 = 120个 prompt 变体（可用 LLM 批量生成，人工审核）|
| **每日内容24小时缓存** | 低 | 同一用户同一天第二次请求直接返回缓存，不重新调 LLM，节省 token 成本 |
| **每日早安卡图片生成** | 中 | 5种底图模板（木/火/土/金/水）× 今日宜忌文字叠加 → 可用 Canvas/PIL 实现，无需 ComfyUI 实时生图 |
| **推送：节气/月相触发规则** | 低 | 在 `push.js` 里加节气/月相日期判断，触发专属推送文案（提前24小时） |

### 6.3 不需要新建的（省力关键）

- **命盘存储**：用户生辰已在 `/api/bazi` 调用时存入，`getReadingsByUser()` 可取出 → 每日运势直接用，不需要用户重新填
- **会员门控**：`memberTier()` + 免费3次/日 门控已实现，直接沿用
- **多语言**：ZH/EN/KO 框架已在 `daily.js` 实现

## 7. 变现设计（每日运势的付费漏斗）

### 7.1 免费 → 付费的三个插入点

**插入点 A：明日预告锁定（转化最高）**
- 位置：每日运势卡底部
- 免费用户看到：「明天是[节气/月相日]，对你的[日主]意味着[悬念词]——」然后模糊遮罩
- CTA：「解锁明日完整天机 · 成为会员」
- 转化逻辑：用户已经养成今天看的习惯，明天的悬念让他们不愿意断

**插入点 B：节气/月相特别版深度内容锁定**
- 位置：节气/月相特别版页面（约每7天一次）
- 免费用户看到：特别版开场（「今天是立春，你的命盘说……」）+ 前100字 + 锁定
- CTA：「立春是今年命运转折点之一，解锁完整分析」
- 转化逻辑：特别版本身稀缺（一年只有24个节气），用户不愿意错过

**插入点 C：AI 追问额度耗尽**
- 位置：用户追问第4次时
- 免费用户看到：「你今日3次免费追问已用完——会员可无限追问」
- CTA：「今天有个关键问题没问完？会员无限追问」
- 转化逻辑：用户已经在对话中投入，中断最痛

### 7.2 不蚕食单报告的边界

每日运势 **不包含、也不替代**：
- 八字完整人生报告（$29）：每日运势只看「今天」，人生报告看「一生格局」
- 流年深度报告（$59）：每日运势提流年影响，不给流年全文
- 真人复核（$99）：AI 运势之后，「这个问题你想听真人命理师怎么说？」

单报告的位置：每日运势页面的固定入口 → 「你的八字人生报告：今天的运势只是起点——看你一生的格局」

### 7.3 会员年订阅的续费钩子（防蚕食的同时制造留存）

会员 = 「每天都有理由打开」的时效内容包：
- 每日完整运势（高频，天天有）
- 流年年度更新（每年立春，天然续费理由）
- 节气/月相完整特别版（约50次/年的高质量内容）
- AI 追问无限（高频使用场景）

续费卡点前 30 天推送：「你的会员到期前还有 [X] 个节气特别版，和 [Y] 次月相版——到期后将不再收到推送」

## 9. MVP 切法（分阶段上线）

### Phase 0 · 立即可上线（0 新代码）

**当前 `/api/daily` 端点已实现**：
- 六大模块中文版（宜忌/五行/幸运色/情绪调频/古诗词/Affirmation）
- 会员门控（3次/日免费，会员无限）
- 中英韩三语言
- Streak 记录

**只需做**：
- 在前端首页添加「今日天机」入口，调用现有 `/api/daily`
- 确认前端展示样式（卡片展开/折叠）

**这不是 MVP，这是已有的——今天就能给用户用。**

### Phase 1 · MVP · 建议2周内上线

**目标**：让每日运势从「存在」变成「有仪式感且个性化」

1. **真实干支日柱输出**（当前只有种子计算，未输出「甲子日」）
   - 用 `calcBazi(today)` 或简单的60甲子周期公式，算出今日真实日柱名
   - 在 prompt 中注入：「今日干支：[甲子日]，与用户日主[庚金]的关系：[相克]」

2. **用户命盘自动注入**（个性化的关键）
   - 用户若之前算过命盘，`getReadingsByUser()` 取最近一次生辰信息
   - 自动填入 `/api/daily` 请求，不需要用户重新填
   - 若无历史记录：在每日运势页展示「填写生辰获得专属运势」引导

3. **节气/月相标注**（内容层差异化）
   - 硬编码 2026-2028 年节气日期 JSON
   - 每天检查：是否在节气前后3天 / 是否是新月满月
   - 是：在 prompt 中注入「今天是[节气名]，命理含义：[X]」，内容自动变特别版

4. **明日预告升级**（续费钩子）
   - 现有 `/api/daily-teaser` 加入节气/月相感知
   - 节气前一天预告：「明天是[节气]，对你的[日主]意味着……」（非通用悬念）

5. **每日内容缓存**（成本控制）
   - 同用户同日期：第一次调用 LLM，结果存入 `_M` 内存（带过期时间至午夜）
   - 第二次直接返回缓存，节省 token

### Phase 2 · 3-4周后 · 仪式感完整版

1. **早安卡图片生成**：今日五行选底图模板 + 宜忌文字叠加 → 可分享图（PIL 实现）
2. **节气/月相特别版页面**：独立 UI 模板，开场动效
3. **推送节气/月相提前24小时**：在 `push.js` 加节气/月相触发规则
4. **Streak 可视化**：历史日历点图，连续记录展示
5. **命历积累**：用户查看记录 → 年底「我的2026命历回顾」数据准备

### Phase 3 · 6-8周后 · 完整飞轮

1. **大运切换提醒**：根据用户命盘计算大运更换年，提前推送
2. **流年更新**：每年立春触发「你的新流年报告已就绪」
3. **节气/月相特别版 prompt 库**：24个节气 × 5类日主 = 120个专属 prompt 模板
4. **「玄机」人格强化**：每日推送改为「玄机 · 今天的天机已备好」
5. **AI 追问与今日运势联动**：追问默认带入今日干支上下文

## 11. 合规护栏

- 所有运势内容结尾加免责声明（现有 `DISCLAIMER_ZH/EN` 已实现，继续使用）
- 节气/月相特别版不承诺具体事件：「可能影响」而非「一定发生」
- 大运切换推送：「进入新磁场」而非「命运改变」
- 推送文案不恐吓：禁「不看会……」格式，只走「有更新/有天机」框架
- 不在用户端暴露 AI 模型名：统一为「玄机智能推算」
- 凶日/不利推送：必须先安抚（「这几天能量有挑战」）再给行动建议，禁止纯负面
