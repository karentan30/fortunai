# 善缘 · 韩国「祭祀代行 + 线上追思」市场调查（0730）

> CEO 顶回"韩国也能做祭祀"——调查证实：**能做，但不是烧纸那套。** 中国"烧纸钱/冥器/代烧直播"在韩国=零。真机会=**벌초/성묘 대행(代客清坟扫墓)+视频证据 + 온라인 추모관 + 遗照AI复原**。

## 一句话结论
第一步只做一个：**추석(阳历9末-10初)前的 성묘/벌초 대행，拍全程照片/无人机视频给海外/远方子女看**。全年现金最集中、痛点最尖、竞品最烂的入口。사주主线负责获客+信任，祭祀代行做旺季变现+情感留存。**代拜、烧纸、冥币一律不做。**

## 1. 文化在衰退+简化=机会（不是阻力）
- 차례参与率 2014年71% → 近年~40%；2024中秋仅**41%**打算行제사
- 성균관调查：**55.9%成年人今后不打算再行제사**；放弃第一理由="应简化/改家庭聚会"(41.2%)=需求转向外包
- **성균관2022官方发"차례상简化案"**(煎饼不用炸/9道够/基础6样)——**儒教权威亲自给"简化外包"背书**，文化敏感天花板被抬高
- 负担主力=**女性·40代**=清晰客群：被祭祀压垮、想外包又怕被说不孝的中年女性

## 2. 现成竞品与价格（真实市场已存在）
**A. 벌초/성묘 대행**（成熟但分散土气）：산림조합10-15万원/기 · **조상님복덕방/이발소(最像样竞品)148,500원/기·卫星图测面积+作业前后多角度拍照给远方家属+透明报价** ← 照片证据模式已被验证。价格带 **10-20万원/기**，峰值100%集中추석前2-4周。
**B. 제사 대행**：主要是祭品/布置代做(상차림)~21万원/桌。⚠️**"代替本人行礼/磕头"几乎无商业化，文化红线，不碰。**
**C. 온라인 추모관**：政府 **e하늘免费**(3D纪念馆/遗照/视频/共享)=公共品，商业馆必须明显更好才有人付；민영+**宠物追思是最活跃付费细分**。
**D. AI追思/遗照复原**：딥브레인 Re;Memory 建馆1.2-2.4万美元+每次对话1200美元(CES奖)——**韩国人对"AI+故人"付费天花板极高**；遗照AI复原=低门槛高情感甜点。

## 3. 大盘（很大且在涨）
- 상조(丧葬互助)加入者 2015年404万→**2024年892万**；预收款→**9.45万亿韩元(~500亿RMB)**。为身后事/追思付钱=国民级消费，善缘从"追思+代行"侧翼切入不碰重资产殡葬。
- **재외동포约700万**：祭祖做不了/回不去是真痛点，但⚠️**无量化数据，是假设，上线小投放验证，别当已证实**。
- 超高龄+1人家庭+双职工=结构性长期推动祭祀外包。

## 5. 该做什么（优先级）
1. **【第一步主打】추석/설날 성묘·벌초 대행 + 视频证据包**：竞品只发手机照片→善缘做**无人机航拍+前后对比+短视频+卫星图透明报价**，卖给回不了乡的首尔/海外子女。추석前3周=现金机器，설날/한식第二波。
2. **【留存】온라인 추모관**（与代行捆绑不单卖）：每次代行自动生成数字纪念馆，一次交易→年度复购+情感锁定，要明显强过免费e하늘。
3. **【引流甜点】遗照AI复原/追思短视频**：低价高情感获客钩，衔接善缘AI能力（本机ComfyUI）。
4. **【谨慎】제사祭品/布置代办**：只做置办+布置，**绝不代拜**。

## 与사주主线配合
사주获客+信任(高频低敏感易传播) → 추석前代行收钱(高客单) → 追思馆留存。**同一画像：关心祖先/家庭/运势的中年女性。**

## 风险（诚实）
1. **代拜红线**：接受代割草/代置办，抵触"外人替本人磕头"。碰=翻车。
2. **宗教分层**：~30%基督/天主教不祭祀但做追모→追思馆/遗照对他们成立、祭祀代行不成立，别套错话术。
3. **中国血统敏感**：善缘露"中国祭祀出海"标签有反噬→**彻底本地化品牌/韩语韩国面孔/不提任何中式元素**。
4. **政府免费替代**（e하늘/地方벌초补贴）压低低端付费→别拼价格，拼体验+情感增值。
5. **旺季极端集中**：全年现金压추석前一个月→产能/人力调度是运营命门。
