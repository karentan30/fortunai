## 优先级（先做精哪几个）

排序依据：**用户量（引流主力）× 定价支撑（独有可视化的震撼度）× 复用现成资产的成熟度**。

### 先做精 Top 5
1. **面相/手相** — 资产最成熟（`mianxiang-*` 现成）+ 用户照片叠加 = 个性化最强、最抗"AI 泛泛"质疑，直接支撑高价。引流也最广（面手页是投放主力）。
2. **八字**（已在做）+ **紫微斗数** — 东方主力盘，后端已有真实结构化数据，12 宫命盘 SVG 是"看得懂的棋盘"式钩子，中文核心盘定价基本盘。
3. **西方占星** — 海外主力，圆形星盘是全球用户对"专业"的默认预期，engine 数据齐全，不做精会显廉价。
4. **合婚** — 客单价天然高（两人 + 情感刚需），双人对照 + 评分环 + 五年时间轴视觉冲击强，转化好。
5. **祈福供养** — 唯一"报告即商品"的变现闭环，圣地网络图 + 价目卡现成，季节放大器（对齐收入战略：代烧=季节冲量）。

### 第二梯队
塔罗（需先定牌面方案 A/B）、风水/阴宅（九宫飞星组件可与九星复用）、六爻/奇门/大六壬（局盘组件三方共用，一次做三个）。

### 第三梯队（低成本快速铺）
玛雅/吠陀/藏历/卢恩/九星/おみくじ/灵签、前世、地域 —— 独有件多为低成本 CSS/现成图，套通用精装件即可上线，用于扩品类广度而非主力变现。

## 给实现方的三条注意
1. **组件复用图**：飞星九宫（风水 / 阴宅 / 九星）共用一个；圆环评分（合婚 / 占星元素 / 面相五官）共用一个；卷轴卡（おみくじ / 灵签）共用一个；时间轴（八字大运 / 紫微大限 / 合婚流年）共用一个。**先建这 4 个基元，25 方法 80% 独有件即拼装完成。**
2. **生图只在两处**，且都要走出图门控 + 预算审批（memory 铁律）：塔罗路线 B（22 张大阿卡纳，一次性）、前世新场景插画。其余全部 [代码] 或 [现成]，成本 ≈ ¥0。
3. **防 AI 泛泛**：每种方法的独有可视化必须吃后端**真实排盘数据**（ziwei gongs / 占星 engine / 六爻 hexLines / 奇门九宫都已有），不要画装饰性假图——这是 $29–99 定价与 9.9 元竞品的分界线。
