# ShenYuan Phase 1 一页纸版

**项目**：三语报告页对齐（CN/EN/KR） | **周期**：7 周 (8/10-9/27) | **投资**：~200k 开发时间

---

## 为什么现在做

| 痛点 | 影响 | 解决后 |
|------|------|--------|
| 中文报告是前端假数据（Math.sin）| 用户不信 → 付费率低 | 真数据 + 分级显示 → 付费率↑20% |
| 英文版只是复制中文（80% 重复代码）| 无法针对西方用户讲八字 | 英文 Prompt 重写（与西方占星对标） |
| 韩文样张 9.6/10 但无支付流程 | 韩国春节（신년운세）峰无法变现 | 完整流程打通（支付→报告→KakaoPay）|

---

## 核心交付物 (3 件)

### 1️⃣ 后端 API 三语对齐
- `/api/bazi` (中文，优化 prompt)
- `/api/bazi-en` (新增，英文 prompt)
- `/api/bazi-kr` (新增，韩文 prompt)
- 报告分级：basic (4柱+五行) vs full (大运+流年+运势)

### 2️⃣ 前端一份代码支持三语
- 删除 70% 重复代码（从 63KB → 40KB）
- 创建 i18n 系统 (i18n.js 8KB)
- 创建 report-unified.css（三语共用，font-family 变量切换）
- 智能路由：`lang=cn/en/kr` 自动调用对应端点 + 显示对应价格（USD vs KRW）

### 3️⃣ 三语质量评审
- EN Prompt：母语 agent 校对，≥4000 词，无西方占星冲突
- KR Prompt：维持现有 9.6/10，补"温柔陪伴"韩式措辞
- CN Prompt：加 AIGC 标注 + 免医疗化 + 去宿命论

## 用户视角（使用流程）

```
1. 打开 shenyuan.app/pages/bazi.html?lang=en （自动检测或手选）
2. 输入生日 + 性别 + 时辰 → 点"Generate Report"
3. 等待 (Hexagram 转圈, 30-60s, 显示进度：Calculating... Analyzing... Generating...)
4. 看报告：
   ✅ 四柱盘（4 个方块，日干高亮）
   ✅ 五行分析（条形图）
   ✅ 日干卡片（解释）
   ⚠️ 下半部分锁定（"Unlock Full Reading"）
5. 点 Unlock → 跳 Stripe 支付页
   - EN/CN: $9.9 (full) / $6.9 (member)
   - KR: ₩9,900 (full) / ₩5,900 (member)
6. 支付成功 → 返回自动刷新，显示完整报告
   - 大运 (10 年周期)
   - 流年 (今年-2030)
   - 运势详解 (事业/财运/情感/健康)
```
