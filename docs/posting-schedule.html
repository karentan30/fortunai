发布前检查清单（每平台5条）

📕 小红书发布前

  1. 封面大字是否在手机竖屏能完整看到？
  2. 正文有没有"算命/保准/改命"等禁词？
  3. 标签是否3层：精准词+中量词+大量词？
  4. 结尾是否有明确CTA（评论/收藏/点击）？
  5. 配图第1张是封面，其余按干货→产品→CTA顺序？

⬛ TikTok发布前

  1. 封面是否用真人截帧或高冲击画面（非纯AI图）？
  2. 前3秒有没有强钩子（问题/冲突/反常识）？
  3. 字幕完整且无错别字？
  4. BGM是否选平台内流行音乐（提升推流）？
  5. 正文有没有3-5个当周热门话题标签？

🌸 Instagram发布前

  1. 英文内容是否请母语检查过（无翻译腔）？
  2. 图片是否1:1或4:5比例（Feed最优）？
  3. Caption前两行是否钩子够强（展开前显示）？
  4. 海外华人时区是否正确（20:00北京时间）？
  5. Story是否24小时内跟发（扩大触达）？

📈 核心指标（每条帖子看这5个）

  • 小红书：收藏率 > 点赞率（收藏=真价值）
  • TikTok：完播率 > 50% = 推流信号
  • Instagram：保存数 + 分享数（>点赞更重要）
  • 评论区有没有"怎么用/在哪里/多少钱"= 购买意向
  • 每项目每周新增粉丝数（目标: +100/周冷启动期）

🔄 爆款复制机制

  • 单篇点赞 >500：下周换角度再发一条
  • 单篇收藏 >200：做成系列（第2集/第3集）
  • 评论区高频词：下周做一条专门回答
  • 竞品近期爆款：分析结构，换成自己内容套用
  • 每月底：爆款TOP3整理进内容库供新人复用
