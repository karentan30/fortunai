## 三大传统背景（谁在"教"这套知识）

**西藏命理（Kartsi 卡尔齐）**
源于印度吠陀占星（公元7世纪传入西藏），与苯教本土传统融合，由历代达赖喇嘛和噶举派大师传承。核心：60年干支轮（源自中国）+ 九宫飞星（源自印度） + 五大元素（木火土铁水）。

**印度吠陀占星（Jyotish 乔蒂什）**
《梨俱吠陀》时代（公元前1500年）起源，"Jyoti" = 光，Jyotish = 星辰之光的知识。四大传统：Parashara（Brihat Parashara Hora Shastra）/ Jaimini / Nadi / KP。月亮星座和月宿（Nakshatra）是核心，而非西方的太阳星座。

**玛雅卓金历（Tzolkin）**
玛雅文明（公元250-900年古典期）的260天神圣历法，由20个神圣符号（Nawal）× 13个音调组成。尤卡坦半岛的 Itzá 和 Quiché 祭司传承，现代由 José Argüelles 在1987年"谐波汇聚"后向全球传播。
