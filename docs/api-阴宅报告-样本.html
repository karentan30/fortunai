4.1 龙脉（72/100）

A墓地背靠的小山丘，属阿巴拉契亚山脉向东延伸的余脉（相对高差约30-50米）。山势自西北蜿蜒而来，至墓地位置微微顿起成"突脑"，然后缓落，止于水景之畔。风水称此为"平冈龙"——龙脉虽小但有来有去，土色鲜润，草木茂盛，为活龙之象。

4.2 穴位（75/100）

穴位位于山丘南麓微微隆起之处，左右有天然土埂形成"砂手"护卫，前方50米为半月形水景弯抱穴场。风水称此为"半月照潭"之局——后靠青山，前抱绿水，左右有护，明堂开阔而不空旷。土色黄褐，下层砂质，无石块无树根穿穴，吉相。

4.3 砂手（70/100）

左方（青龙方）有缓坡约2-3米高延伸30米，形如手臂环抱；右方（白虎方）地势略低，矮树篱护卫，符合"青龙宜高，白虎宜低"法则。前方明堂宽约80-100米，远处稀疏树林作为案山。

4.4 水法（72/100）

前方50米人工水池（约60×15-20米），半月形弯抱穴场，形成"玉带水"之象，主财禄。水为静水，力量较弱，但弯抱有情，聚气作用尚佳。

⚠ 选此地须注意
  • 避免正对公墓主路（气口对冲）
  • 避开邻墓尖碑正对本墓（砂箭相冲）
