## 📢 博主赋能增长策略（新战略）

Karen 提出：让算命博主用善缘平台给粉丝生成报告，博主看起来更专业、我们给他们赋能。

**执行方案**：
1. **博主版 API 或子账号**
   - 博主输入粉丝生日 → 生成白标报告（带博主名字 or 善缘联名）
   - 博主卖报告（可以比我们定价高），给我们按销售额分成
   - 这比博主做我们的 affiliate 更深绑定

2. **快速启动方案**（不用改代码）
   - 博主直接用我们的 admin token / 邀请 token
   - 或者给博主一个固定邀请码 `ref=博主名` 带来的订单他们拿 20%

3. **目标博主类型**
   - 小红书/抖音算命账号（10w-100w粉）
   - YouTube华人命理讲解（海外华人市场）
   - TikTok 水晶/风水 account（印度/韩国/东南亚）

4. **博主赋能 Pitch**
   - "你给粉丝算命，报告是你手工写的？我们有 AI，能生成万字深度报告，成本$0，你卖$20-$50，你只需要带流量"

## 📦 产品卖家合作策略

### 目标合作方
1. **Amazon FBA 中国卖家**（品类：feng shui bracelet, crystal bracelet）
   - 搜索关键词：「black obsidian Pi Xiu bracelet」「healing crystal bracelet」
   - 联系方式：卖家主页 → 联系按钮
   - 谈判要点：我们有精准流量（看完命理报告后的买家），20-30%分成

2. **AliExpress 精品卖家**（有自己品牌的优先）
   - 用 CJ Affiliate 或直接联系卖家

3. **Etsy 中国珠宝卖家**
   - 图片质量通常很好
   - 很多有Etsy内建的Affiliate

4. **广州批发直采**（Karen已有资源）
   - 荔湾广场 / 广州珠宝城
   - 建议先采样 20-30 件，拍高清产品图
   - 成本 ¥15-50，售价 $15-35，毛利80%+

### 关于产品图
- **短期**：从 AliExpress 找已有好图的SKU做dropship，图直接用
- **中期**：让广州供应商发货，我们拍或请摄影师拍高质量产品图
- **最优**：统一风格"开光"场景图（禅意背景+手串+少量文字说明）
