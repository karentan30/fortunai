## 设定 A ·「算命博主」（脚本 1/2/3/5 · 全年基本盘）

**角色定位**：不是网红，是"刚发现一个准得发毛的东西、想拉你一起看"的邻家女生。真实感 > 精致感。

### 人物一致性档案（锁人硬字段）
| 字段 | 锁定值 |
|---|---|
| 族裔 | East Asian / Han Chinese（东亚汉族脸，非东南亚） |
| 精确年龄 | **28**（不给区间） |
| 脸型/骨相 | 微圆鹅蛋脸；颧骨中等不外扩；下颌线柔和；下巴略短圆 |
| 五官锚点 | 平眉偏淡；内双眼、眼距标准偏开；**深棕虹膜**；鼻梁中等高度、鼻头圆润；唇偏薄中等；**裸耳无耳饰、无明显耳洞** |
| **记忆点特征** | 左鼻翼下方约1cm 一颗小痣（AI 靠它钉住同一张脸） |
| 肤色明度 | Fitzpatrick III，暖黄中调，健康不苍白 |
| 体型 | 身高感 162–165，肩窄，脸颊适中略丰 |
| 发型（锁死·不给"或"） | **披发不扎**；发长到锁骨下 2cm；无刘海中分；自然黑棕色不挑染；发丝允许自然飞散 |
| 妆容 | 裸妆/无妆感，唇色近原生唇；禁浓妆/美瞳/假睫/磨皮 |
| 服装（可复现） | 燕麦色麻花针织**圆领**毛衣；长袖略宽松廓形；可见麻花织纹；袖口罗纹收口 |
| **手部（屏录必入镜）** | 裸甲、短圆修剪、无美甲；无戒指；右手腕一条极细银链；针织袖口自然堆叠到手腕 |

### 环境/布光/色彩（跨镜复用）
- 暖色居家室内、木质调、窗光为主
- 左后暖钨丝 2800K 轮廓光 + 右侧窗光 5000K 柔和补光；**禁环形灯**
- **catchlight**：右侧窗光形成的柔和**方形**眼神光（明确来源，防 AI 脑补环形）
- 色彩：Kodak Portra 400，暖肤色、提亮暗部、轻微颗粒

### 定妆图锚点
正面中近景 50mm、手持手机于胸前、表情不笑沉着；出**正脸 + 3/4 侧脸 + 手持手机手部特写 + 一张浅笑露齿的表情基准**（锁齿列）。
**复审追加锁定**：耳部=裸耳、无耳饰、无明显耳洞；牙齿=齿列整齐自然、非漂白假白。

**负面词**：`ring light, beauty filter, smooth AI skin, influencer smile, heavy makeup, colored contacts, false lashes, dramatic lighting, stock photo, neon, logo, manicure, nail art, rings, southeast asian features`

## 设定 B ·「中元哀思人」（脚本 6 · 中元代烧 8/18–8/20）

**角色定位**：外婆走了三年、已哀悼完，剩下平静的接受与"我只能做到这些"。不能哭、不能悲情表演，反向诚实是最强说服力。

### 人物一致性档案（锁人硬字段）
| 字段 | 锁定值 |
|---|---|
| 族裔 | East Asian / Han Chinese |
| 精确年龄 | **33**（够沉不显老态） |
| 脸型/骨相 | 清瘦长鹅蛋脸；颧骨略显；下颌线清晰；下巴略尖 |
| 五官锚点 | 平眉深色；双眼皮偏窄、眼距标准；**深棕虹膜**；鼻梁中高；唇中等、自然唇色；**裸耳无耳饰**；**圆额发际线、无美人尖** |
| **记忆点特征** | 右眉尾一处极淡旧疤（眉毛一侧有个小缺口） |
| 肤色明度 | Fitzpatrick III，中性偏冷但**健康非病态苍白** |
| 体型 | 身高感 160–163，肩略窄，脸颊清减 |
| 发型（锁死） | **深黑色**、中长发到肩、**低松散马尾扎起**、无刘海、少量碎发垂落、发际线自然 |
| 妆容 | 几乎无妆、冷调不暖；禁泪妆/红眼眶特效 |
| 服装（可复现） | 藏青色纯棉**圆领**长袖薄衫；合身廓形；平织无明显纹理 |
| **手部（点灯镜必入镜）** | 裸甲自然、无美甲；**无婚戒**（定为未婚外孙女读解）；无手腕饰品；袖口平整 |
| **固定信物** | 外婆留下的旧素圈银戒，戴**右手无名指**（非婚戒位）；`plain thin silver band, matte, no gemstone`；作为情感锚点固定入镜，不换物件 |

### 环境/布光/色彩
- 室内近窗、背景完全虚化（只留暖室内暗示；**禁蜡烛/暗黑背景/鬼怪氛围**）
- 纯阴天窗光 6000K、无人工补光、冷匀柔
- **catchlight**：左前方一小块窗提供柔和**竖形**眼神光（明确来源，防 AI 给病态死眼/环形光）
- 色彩：去饱和、整体偏冷、肤色保留但不暖、参考冬日午后光

### 定妆图锚点
85mm 中近景、正面直视镜头、不哭不笑平静接受、第 2 秒缓慢眨眼；出**正脸 + 戴信物的手部特写 + 一张平静闭唇口型基准**（锁齿/口型）。
**复审追加锁定**：发际线=圆额、无美人尖；牙齿=闭口为主、齿列自然。

**负面词**：`tears, dramatic grief, theatrical expression, smiling, candle in frame, dark background, horror mood, heavy shadows, ghost aesthetic, warm tones, festive clothing, sickly pale, manicure, ring light, southeast asian features`
> 注：**已删 `wedding ring`**——素圈银戒与婚戒视觉同物，留着会把信物戒指抹掉。婚戒读解靠"戴右手无名指非婚位"区分，不靠负面词。

## 一致性生产铁律（8→10 的关键·冲满分必守）
- **定妆图定稿后，后续所有分镜不靠纯文字生成**：把 Karen 点头的那张正脸定妆图当**参考图/主体一致性(reference/subject)** 输入，配**固定 seed**，再叠该镜动作/景别 prompt。纯文字每镜必漂，参考图+锁种子才能把同一张脸带过全片。
- 每个角色定一个 **master seed**，正脸/侧脸/手部/表情基准五张共用，选出最好的一张作为"黄金参考图"，锁进档案后所有分镜引用它。
- 选片标准：痣/疤方位对、齿列一致、瞳色深棕、无美瞳无环形灯——四项任一不对即弃图重生。
- **黄金参考图入档前必须人工比对痣/疤方位与文字定义一致**（A 左鼻翼痣 / B 右眉尾疤）；Seedream 做 3/4 侧脸/镜像增强时极易左右翻转，**翻转的参考图直接弃，不作 seed 源**。
- **B 瞳色防冷光脱色**：冷光 6000K+去饱和下深棕易发灰偏浅，正向加 `dark brown iris retained even under cool desaturated light`，避免误判弃掉本来对的图。
- **B 信物戒指**：正向强写 `plain thin silver band on right ring finger, matte, no gemstone`；B 负面词已删 `wedding ring`（勿加回），否则戒指被抹。

## 生图执行硬提醒（造型导演复审追加·生 prompt 时照做）
1. **记忆点必须每张 prompt 显式写死方位 + 选片逐张核对**：A「mole on left side, always visible」/ B「scar on right brow tail」——AI 不会自动守跨角度一致，这是定妆图之后跨分镜头号杀手。
2. **手部张单独出、单独设负面词**：B 的信物「plain thin silver band, right ring finger」要**正向强写**，并把 `wedding ring` 从**手部张**负面词里移走（只在脸部/全身张保留），否则模型会把戒指抹掉或生成花哨戒指。
3. 引擎=**火山引擎 Seedream 5.0**；只生 5 张定妆图（A 3 张 + 表情基准 / B 2 张 + 口型基准），给 prompt 先看、跑完即停、不开批量。ARK 出图脚本待写。
