## 核心定位（一句话战略）

**Runae = 灵性旅游伴侣 + 命理长期陪伴。**
把"一次算命"升级成"一段旅程 + 一整年的关系"。旅游是**最强获客场景**（自带高情绪、自带传播欲、自带地理关键词蓝海），命理/流年/祈福是**最强留存引擎**（天然有随时间刷新的复访节点）。两者用"解签"这颗螺丝钉咬合：**旅游拜庙 → 抽签看不懂 → Runae 解签 → 指引拜什么/念什么 → 回不去就代祈福续缘。** 这条链是 Karen 洞察出的、Runae 独有的场景闭环。

# A. 旅游 × 寺庙 GTM：灵性旅游伴侣

## A.1 三段闭环（旅游前 / 中 / 后）设计成产品 + 内容

灵性旅游是一条**有明确时间轴**的用户旅程。把产品钩子精准埋在每一段的"用户此刻在想什么"上。

### 旅游前 —— "该去哪拜 / 什么时候去 / 拜了求什么"

| 用户此刻 | 产品钩子（免费/低价引流） | 内容角度 |
|---|---|---|
| 在订机票、做攻略 | **免费排盘 + 流年吉方**：今年你的喜用神在哪个方位？该往哪个方向走运？ | "出行前先看流年，别硬闯弱运年"（已有条7） |
| 纠结去哪个城市/国家 | **吉方旅行地图**：把流年吉方叠在世界地图上，推荐"对你有利方位"的圣地 | "你今年的旺运方向在这里，顺便去拜这几座庙" |
| 想拜但不知拜什么 | **拜佛指引预告**：按你的命盘缺口（求财/求姻缘/求平安）→ 推荐该拜哪位菩萨/神明 | "去清水寺求姻缘要拜谁？按你的八字缺口定" |

> 产品动作：在免费排盘报告里**新增一个"旅行/出行"模块**（流年吉方 + 出行时机 + 对应可拜神明），把排盘从"看命"扩展成"行动指南"。零新引擎，复用现有流年 + geo 逻辑。

### 旅游中 —— "抽了签看不懂 / 该拜什么 / 念什么咒"（**转化核心段**）

| 用户此刻 | 产品钩子（付费转化） | 复用 |
|---|---|---|
| 在庙里抽到签看不懂（繁体/日文/古诗） | **拍照/输签号解签**：真谱兜底 + 结合所问之事白话解读 ¥9.9/$6.9 | `PRD-解签服务.md` P0 |
| 站在佛像前不知怎么拜 | **拜佛指引**：这位菩萨/神明的正确参拜方式 + 该默念什么、求什么最灵验（文化礼仪，非效果承诺） | 复用 deity-guide 端点 |
| 想念咒但不会 | **念咒卡**：对应心愿的经咒（大悲咒/心经/文殊咒…）+ 白话释义 + 音频跟念 | 轻量内容卡，可白嫖引流 |

> **这是整条链的付费转化引爆点**：用户在现场、情绪最高、痛点最急（"我大老远来了，这签到底吉还是凶？"）——转化率天然最高。解签必须支持**当场 3 秒出结果**（输签号 P0，拍照 P1），慢一秒就流失。

### 旅游后 —— "回不去了，怎么续这份缘"

| 用户此刻 | 产品钩子（高客单 + 订阅） | 复用 |
|---|---|---|
| 回国/回住地，想继续拜但去不了 | **代祈福 / 代上香**：让当地师父替你续香火 $25–58 | `PRD-全球祈福供养平台.md` 引流款 |
| 抽到好签想还愿 / 抽到凶签想化解 | **还愿代供 / 温和化解代祈福**（凶签绝不恐吓，走"传统心意"框架） | 解签结果页二段钩子 |
| 想把这座庙的缘分留住 | **供灯年供订阅** $65–650/年：那座你去过的庙，一盏为你常年点着的灯 | 供灯年供（天然年度订阅） |

> **旅游后段 = 把一次性旅游客转成订阅用户的黄金窗口**。用户对"那座去过的庙"有真实情感锚点，"在你亲自去过的庙里，留一盏长明灯"的说服力远高于冷启动推销。**把供灯订阅和用户去过的具体寺庙绑定**，是这段的杀手锏。

# B. 裂变（Referral / Viral）

命理/灵性产品的裂变优势：**结果自带社交货币**（晒命盘、晒签、晒运势是天然的分享欲），且**多人玩法自带拉新刚需**（合盘、组队祈福必须拉人）。设计 5 个机制，标注第一个该上的。

### B1. 合盘 / 合婚裂变（拉对方）—— ⭐ **第一个该上**

| 要素 | 设计 |
|---|---|
| 触发点 | 用户想看"我俩合不合"，但合盘**必须有对方生辰** → 系统提示"发链接让 TA 填，填完你俩的合盘就解锁" |
| 奖励结构 | 双方都得：邀请方解锁合盘报告；被邀方得一份自己的免费排盘（顺势变新用户）。合盘基础免费，深度合断走 $59 双体系。 |
| 病毒系数逻辑 | 每次使用**强制**产生 1 次定向拉新（不是可选分享，是功能刚需）。被邀方带着"看我俩合不合"的强动机进来，转化质量高。K 值天然 > 0，因为拉人是完成功能的必要步骤。 |
| 防薅羊毛 | 被邀方必须填真实生辰 + 完成排盘才算有效邀请；同一设备/IP 批量填假生辰不计入奖励；奖励发"解读额度"而非现金，无套现价值。 |

> **为什么第一个上它**：①现有内容包已有大量"异地合盘/感情"选题（条4），流量入口现成；②它是**唯一一个"拉人"内建在核心功能里、不需要额外说服**的机制——用户不是为了奖励去分享，是不分享就用不了；③海外华人异地恋/异地感情是超高频痛点，动机极强。**开发量最小（合盘功能多半已存在），只需加"发链接邀对方填生辰"的分享流。**

### B2. 替朋友求签 / 解签（社交礼物裂变）

| 要素 | 设计 |
|---|---|
| 触发点 | 用户解完自己的签 → "帮朋友也测一支？"/"把这支签的解读分享给 TA"。或旅游时"帮没来的朋友求一签"。 |
| 奖励结构 | 分享解签结果卡（美图，隐藏付费全文）→ 朋友点开可免费看签文 + 吉凶预览，解全需自己付费或注册。分享者得解签额度 or 追问次数。 |
| 病毒系数 | 解签结果是**天然可晒的内容**（好看的签诗卡 + 悬念"吉凶"），每次解签 = 一次潜在分享。旅游场景下"帮朋友求签"是真实社交行为。 |
| 防薅 | 奖励=功能额度不可套现；被分享者需注册才领免费额度；限制单用户每日可发起邀请数。 |

### B3. 晒签 / 晒运势社交货币（内容裂变，非直接 referral）

| 要素 | 设计 |
|---|---|
| 触发点 | 出报告/解签后自动生成**小红书级美图卡**（命盘图/签诗卡/今日运势卡，复用 `reference_runae_report_render_pipeline`：宣纸山水底 + 定制排版），一键存图/分享。 |
| 奖励结构 | 分享本身是软性的（社交货币驱动），图上带 `runae.net` 水印 + 二维码即品牌曝光。可叠加"晒单返额度"轻激励。 |
| 病毒系数 | 不保证定向拉新，但**放大内容分发**（用户帮你做免费小红书素材）。每张美图 = 一个品牌触点。玄学内容在小红书/IG 分享率极高。 |
| 防薅 | 若做"晒单返额度"需人工/规则审核真实分享（截图+链接），否则易刷；建议先做无奖励纯社交货币版，跑通再评估激励。 |

### B4. 组队祈福 / 拼团代烧（多人成本分摊裂变）

| 要素 | 设计 |
|---|---|
| 触发点 | 高客单代烧/法事（$220–950）→ "组家庭祈福团，人越多人均越低"/"为全家点一盏灯，家人各自加入"。 |
| 奖励结构 | 拼团价：3 人成团人均降价；发起人可享额外供灯月份或家庭祈福年卡折扣。复用 `PRD-全球祈福供养平台` 家庭祈福年卡设计。 |
| 病毒系数 | 高客单商品用拼团降低决策门槛 + 强制拉家人/朋友。海外华人"为全家祈福"动机强，一个发起人可带 2–4 个家庭成员。 |
| 防薅 | 拼团为真实付费行为，无套现风险；注意合规——文案走"服务费·文化心意"框架，**禁"捐款/功德钱/必灵"**（见祈福平台 PRD 1.4）。 |

### B5. 报告部分解锁分享（内容 gate 裂变）

| 要素 | 设计 |
|---|---|
| 触发点 | 免费报告看到关键一段（如"你今年最该注意的月份"）被锁 → "分享给 1 位好友即可解锁这一段"（轻量），或引导付费。 |
| 奖励结构 | 分享解锁小段落（低价值段用分享解锁引流，高价值段留付费）。**注意别用它替代付费**——只解锁引流性内容，核心付费内容仍走 $29/$59。 |
| 病毒系数 | 中等；靠"差一点就看到"的心理驱动分享。适合作为付费墙之外的第二转化路径。 |
| 防薅 | 只解锁引流段，不触及付费核心；限制分享解锁次数；分享链接需真实点击。 |

### 裂变优先级排序

1. **B1 合盘拉对方（第一个上）** —— 内建刚需、开发最小、动机最强
2. **B2 替朋友解签** —— 与旅游场景 + 解签功能天然咬合
3. **B3 晒签美图社交货币** —— 复用现有渲染管线，几乎零成本放大分发
4. **B4 拼团代烧** —— 高客单 + 家庭裂变，等祈福平台上线后叠加
5. **B5 报告分享解锁** —— 辅助转化路径，谨慎防蚕食付费

# C. 续费 / 留存（Retention）

命理/灵性是**天然高复访品类**——命盘随流年/大运刷新、节日/忌日周期性触发、祈福需要长期"续缘"。关键是把这些天然节点**产品化成回访 + 续费理由**。

## C.1 为什么用户会回来（复访驱动力）

| 驱动力 | 天然节点 | 产品化 |
|---|---|---|
| 流年会变 | 每年立春/元旦流年更新 | 年度"新流年报告"推送 → 续费/复购 |
| 大运会换 | 命盘每 10 年换大运（个体化时点） | 到大运切换年主动推送"人生进入新阶段"报告 |
| 每日/每月运势 | 天天/每月 | 会员每日运势 → 高频打开习惯 |
| 节日/节气 | 春节/清明/中元/本命年/生日 | 节日专属运势 + 祈福提醒 |
| 未决之事 | 求职季/感情节点/考试 | 追问功能 + 择时提醒 |
| 祈福需续 | 灯需常年点、忌日需年年祭 | 供灯年供订阅、忌日自动代祭 |

## C.2 会员续费钩子（防蚕食单报告）

> **定价铁律（复用定价专家结论）**：会员**不能是"无限报告"**——那会蚕食 $29/$59 单报告主收入，把高价值一次性报告白送。会员卖的是**"持续更新的陪伴 + 特权"，不是"报告批发"**。

**会员（$14.99/月 · $99/年）应该包含（复购型、时效型内容）：**

- ✅ **每日 / 每月运势**（高频复访钩子，单报告没有的时效内容）
- ✅ **流年年度更新**（每年新流年解读，天然续费理由）
- ✅ **大运刷新提醒 + 报告**（命盘随大运刷新的个体化节点）
- ✅ **AI 追问额度**（对已有报告持续对话，非重新出报告）
- ✅ **解签不限次 + 多签系 + 多语言**（旅游高频场景，会员刚需）
- ✅ **节日/节气专属运势 + 择时提醒**
- ✅ **会员折扣**（代烧/祈福/深度报告的会员价）

**会员明确不包含（守住单报告价值）：**

- ❌ 无限量深度万字报告（八字/紫微/占星深度报告仍走 $29/$59 单卖，或会员每月**限量 1 份 credit**而非无限）
- ❌ $99 真人复核（真人成本高，永远单独收费）

> 会员定位 = **"每天/每年都想看的时效内容 + 全场折扣"**，单报告定位 = **"人生大问题的一次深度精算"**。两者不重叠 → 不蚕食。这正是 `审计-报告质量×定价×设计-0818` 里指出"会员/单报告价值边界模糊"要解决的问题。

## C.3 祈福"续缘"订阅（长期留存 + 高 LTV）

复用 `PRD-全球祈福供养平台.md`：

- **供灯年供 / 月供自动续费**（$65–650/年）：一次获客多年续费，年留存目标 60%+。是灵性产品里**最天然的订阅载体**——灯要一直点着 = 天然持续付费理由。
- **忌日 / 清明 / 中元自动代祭**：按用户日历（逝者忌日、清明、中元、本命年）**主动触达 + 一键续单**，情感强度极高、复购率高。
- **家庭祈福年卡**：为父母/子女/配偶代祈福，单用户 LTV × 家庭成员数。
- **旅游后续缘**（承接 A.1 旅游后段）：把订阅锚定在"你亲自去过的那座庙"，说服力最强。

## C.4 解签后的复访路径

解签是**高频入口**（每次旅游/每次抽签都可能用），要把一次性解签转成留存：

1. 解签结果页 → **"存到我的签库"**（历史签记录，形成个人资产，用户会回来看"上次那支签")。
2. 抽到凶签 → 温和化解建议 → 代祈福/供灯（旅游后段承接）。
3. 抽到吉签 → 还愿提醒（"记得回来还愿"）→ 代还愿服务 or 下次旅游再用。
4. 解签额度用完 → 引导会员（解签不限次是会员刚需卖点）。
