## 概览

善缘（ShenYuan）是一个 AI 驱动的命理风水综合平台，提供八字命理、印度吠陀、玛雅历、风水评测、阴宅风水五大诊断模块。用户完成诊断后，AI 报告直接推荐匹配的商品、服务和场所。我们的推荐是**场景内嵌入**，非广告横幅，用户接受度极高。

**目标合作方向：**
1. 开运摆件 / 风水商品零售商
2. 家具品牌（五行属性匹配）
3. 公墓 / 殡仪服务运营商
4. 房产 / 地产中介

## 通用条款（适用全部合作类型）

### 数据与追踪标准

| 参数 | 说明 |
|------|------|
| `utm_source` | 固定值：`shenyuan` |
| `utm_medium` | 报告类型：`bazi-report` / `fengshui-report` / `yinzhai-report` / `maya-report` |
| `utm_campaign` | 品类：`kaiyu-products` / `furniture-wuxing` / `cemetery` / `realestate` |
| `ref` | 合作方唯一编号：`SY` + 3位数字（如 `SY001`） |

所有点击数据由善缘后台记录，每月 3 日前向合作方发送上月数据报表（含点击量、留资量、转化率）。

### 品牌使用规范

- 善缘在报告中只推荐**当前该品类最多 2 家**合作方，保证稀缺性
- 合作方不得在自身渠道声称"善缘官方指定""唯一合作"等排他表述（需单独签排他协议）
- 善缘有权对推荐文案进行调整，以保证报告整体阅读体验

### 快速启动流程

1. 双方确认合作意向 → 签署 1 页简版合作协议
2. 合作方提供：品牌 Logo、商品/服务介绍、专属折扣码或联系方式
3. 善缘完成报告集成测试（3 个工作日）
4. 上线后首月数据追踪，满意后续签长期协议
