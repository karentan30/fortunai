# 善缘 · 韩国 MVP PRD（0730·基于竞品分析）

> 依据 `docs/韩国市场调查-0730.md`。功能全部从**竞品缝隙**推导。
> 目标：**12月前上线吃 2027 신년운세第一波**。首发只做 사주+궁합+AI深报告+신년운세；祭祀走本地化另案（见韩国祭祀调查）。

## 竞品缝隙 → 我们做什么
| 竞品 | 他们的强项 | 他们的缺口 | 善缘对策 |
|---|---|---|---|
| 점신 Jeomsin | 广告免费日运·流量最大 | 只有短卡片·无深度·广告打断体验 | 我们免费日运引流，但**用无广告+深报告**拉开档次 |
| 포스텔러 Forceteller | 订阅深报告+IP·有英文版 | 报告仍偏模板·궁합浅 | **AI万字深报告 + 궁합30年大运深度**超越 |
| 천명 Cheonmyung | 真人连线 | 贵(5-30万韩元)·慢·非即时 | AI 即时+便宜(9,900-19,900韩元)先满足大众 |
| 헬로우봇 HelloBot | 角色chat有趣 | 娱乐化·不深 | 我们主打"真排盘非编故事"的专业感 |
| **共同缺口** | — | **没人主打"AI万字深度报告"** | ← **善缘核心差异化武器** |

## MVP 功能清单（P0 首发·按优先级）
1. **사주 기본운세 + 오늘의운세（免费引流）** — table stakes，人人有，我们无广告体验更好
2. **AI 심층 리포트（AI万字深报告）★核心差异化** — 事业/财运/애정/健康/流年·麦玲玲风格(给具体时间点+数字+先难后解)·**温柔陪伴语气(重情 jeong)非冷技术流**·付费主力
3. **궁합（合婚）★最强付费+双人裂变** — 按**韩式30年大运同步**逻辑重做·必须两人各测=天然 K>1 裂变
4. **신년운세 + 토정비결★季节峰必备** — 12-2月最大流量·토정비결是韩国独有标配(缺了不地道)
5. **오늘의운세 push 订阅** — 每日推送养日活+订阅现金流(对标포스텔러)

## P1（第二波）
- **작명（起名）** — 八字补五行选汉字·明确付费品类
- 真人 상담(连线) — 对标천명·后期·复用 Lumee Agora
- 韩国本地化祭祀（성묘/제사 대행·온라인 추모）— 待韩国祭祀调查结论

## 本地化清单（上线前必过·否则被当"中国货"）
- [ ] 全韩语原生 UI（非机翻）
- [ ] 术语韩式：**십성/신살/용신/일간**（不直译中文）
- [ ] 궁합按**韩式30年大运同步**重做呈现
- [ ] 加 **토정비결**模块（三柱144卦）
- [ ] **만세력**历法/节气边界按韩国惯例校准
- [ ] 接 **KakaoPay / NaverPay / Toss**
- [ ] 语气改**温柔陪伴·重情(jeong)·自我反思**（不吓唬·MZ求安抚）
- [ ] 加"오락/참고용"（娱乐/参考）免责（应对2026 AI法）
- [ ] 品牌**去"中国感"**·定位"정통 사주(正统四柱)"

## 定价（对标市场·冲动消费带）
- 오늘의운세/기본 사주：免费（引流）
- **AI 심층 리포트：9,900–19,900원**（比线下便宜·比长尾AI贵一档·用"万字深度"撑价）
- **궁합：4,900–9,900원**
- 월 구독（订阅）：对标포스텔러·可选

## 复用（照现有别重造）
- **善缘八字引擎**（사주内核同源·排盘直接用·改术语层）
- **Lumee 军师引擎**（三轴 prompt·已有韩系K-drama原型+EN版=韩语命理师有基础·见 `docs/Lumee移植清单-0730.md`）
- **Lumee 钱包/affiliate/OTP登录/境内支付**（Karen：Lumee现成不用新做）
- 遗照修复/纪念（본机 ComfyUI 免费出图）→ 온라인 추모관复用
