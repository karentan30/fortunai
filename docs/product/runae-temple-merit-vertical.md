## 0. TL;DR

- **品类已经在起量，不是空想**。年轻人涌向寺庙 → 代开光/代请/代拜/代祭已成规模化生意，小红书话题量级到亿（#雍和宫手串# 1.4亿浏览、#灵隐寺十八籽手串# 6100万浏览）。清明代客祭扫套餐 ¥188–1000+，视频连线额外收费——**"视频证明"已经是这个品类的标配卖点，正好命中善缘的连麦引擎优势**。
- **海外华人需求真实存在且已有玩家**：湄洲妈祖代拜（mazublessing.com）、台湾聚宝堂线上代客贡香、香港东华三院观音庙代客参神、易祈福 App。目标人群明确锁定"旅居海外无法亲赴的华人信众"。
- **老板亲测锚点**：五台山烧替身 ¥2000（转移厄运的替身仪式）——高客单仪式类是这个 vertical 的利润核心。
- **最该先上 3 个 SKU**：① 代祈福/代上香（引流低客单）② 烧替身/消灾法事（¥2000 档利润核心）③ 开光物代请（雍和宫/灵隐寺手串，复购高、供给现成）。
- **信任模型一句话**：寺庙实地录像 + **师父跟用户 Agora 视频连麦全程看直播念经祈福并对话**（复用善缘大师连麦引擎，对象换成师父）+ 定制照片 + 书面回向凭证。
- **最大的雷**：跨境宗教资金 + 中国宗教事务强监管。**只收服务费、绝不代收/代捐香火钱**，全程"文化/心意/纪念"框架，禁任何"必灵/改运/治病"承诺。
- **第二大坑**：白牌供应商假视频骗子。**每个供应商必须先小额真测（¥50–200）验证真录像真连麦，再放量**。

## 3. 🔑 信任模型（核心 · 老板方案）

**目标：把"我们代办"从"感觉像骗子"变成"看得见、可对话、有凭证"的正规军。**

### 四层信任叠加

1. **寺庙实地录像**
   - 每单在真实寺庙/道观实地拍摄仪式全过程视频，画面含可辨识的寺庙标识/环境，避免"棚拍/换背景"质疑。

2. **师父跟用户视频连麦对话（复用善缘 Agora 连麦引擎）** ⭐ 最强差异化
   - **直接复用善缘现有大师连麦那套**（`server/routes/video-call.js` + `server/lib/agora-integration.js`），把连麦对象从"命理大师"换成"寺庙师父/主法居士"。
   - 用户**全程实时看直播**：看师父上香/念经/焚烧替身，仪式中/仪式后与师父视频对话（师父可为用户口头祈福、说明仪式含义、答疑）。
   - 这一步是善缘 vs 白牌代烧的护城河——白牌只能事后发一段可能造假的视频；善缘是**实时、双向、可对话**，造假成本极高、用户在场感极强。市场已验证"视频连线"是加价项，善缘把它升级成实时连麦。

3. **定制照片凭证**
   - 含用户姓名/祈福对象手写牌位的近景照 + 仪式关键节点照，交付到账户中心留存（复用现有 offering/账户中心基建）。

4. **书面回向凭证 + 真实反馈**
   - 电子回向文书（含日期、寺庙、师父署名——**中性署名，不打任何 IP/名人牌**）。
   - 累积真实用户反馈/评价（参考湄洲妈祖那套"用户感谢+寄送影像记录"）。

### 交付时序（用户视角）
下单 → 约仪式时间 → **连麦看直播 + 师父对话** → 收到照片/视频 → 账户中心留存回向凭证。

## 4. 供给 / 履约

### 供给来源（按优先级+可靠度）

1. **寺庙客堂 / 知客僧直连**（最正规、最可信）——直接联系寺庙客堂/知客僧谈代办合作，正规名额、正规师父。合规与信任最优，但拓展慢。
2. **老板本地熟人**——五台山等已有关系（老板亲测过烧替身），可作首批冷启动供给。
3. **淘宝/闲鱼/小红书现成白牌代办**——市场上已有大量代请/代烧/代拜白牌（本研究已证实活跃）。起量快，但**造假风险最高，必须严格核验**。
4. **善缘现有代烧寺庙关系延伸**——`daishao.html`/`gongfeng.html` 背后的现有寺庙关系，直接延伸到代祈福/供灯/法事。
5. **跑腿（简单上香/献花）**——极简 SKU 可用本地跑腿网络，成本低、适合引流款。

### ⚠️ 供应商核验（防假视频骗子）· 铁律

- **每个新供应商上架前必须小额真测**（¥50–200 下一单代上香/代请），亲验：
  - 是否真实地录像（非库存/换背景视频）；
  - 是否能配合**实时 Agora 连麦**（不能连麦的不进高客单 SKU）；
  - 照片/牌位是否含指定信息、是否按约定时间执行。
- 通过测试才可放量；高客单 SKU（烧替身/法事/超度）**只用能连麦、能实地直播的供应商**。
- 建供应商评级 + 抽检机制，长期防"混单/批量假视频"。

## 5. 商业模型

- **只收服务费 / 管理费——绝不代收或代捐香火钱**（合规命门，见 §6）。用户付的是"代办服务费"，不是"捐款"，善缘不碰宗教资金池、不做"代捐减抽成"。
- **定价 = 供应商成本 + 服务费 markup**；高客单仪式（烧替身/法事/超度 ¥1288–2888）是毛利核心。
- **地理定价**：海外华人版可上浮（复用善缘现有地理定价思路），对标湄洲妈祖/聚宝堂的海外定价。
- **LTV / 复购载体**：
  - **供灯/长明灯年供订阅**（¥199–1999/年）——最天然的年度订阅。
  - **节日/忌日复购**：清明、中元、忌日、本命年、除夕祈福——按用户日历主动触达（善缘已有忌日/纪念人概念）。
  - **年度祈福订阅**：把一次性仪式产品化成"全年 N 次代祈福+供灯"套餐（对冲季节波动，参考善缘代烧"年度祭祀订阅"思路）。
- **交叉导流**：八字算命 → 检出"流年不利/犯太岁" → 导流烧替身/消灾法事（内容框架必须娱乐/文化，见 §6，禁"必须化解否则……"式恐吓）。

## 6. 合规红线（最高优先级）

> 中国宗教事务受强监管；跨境宗教资金极敏感。以下为不可逾越红线。

1. **绝不代收/代捐香火钱、功德钱、捐款**。只收"代办服务费"。做"代捐款减抽成"= 直接触碰跨境宗教资金红线，**禁止**。
2. **禁任何"必灵/改运/消灾必成/治病/转运保证"claim**。全部用**文化传承 / 心意寄托 / 心理慰藉 / 纪念**框架。烧替身=文化仪式与心意，不是"科学改命"。
3. **超度类文案最谨慎**：定位为"表达思念与心意的传统仪式/心理慰藉"，不承诺"往生/超脱"结果。
4. **全站免责声明**：明示服务为文化/民俗/心意性质，效果因人而异、不作任何功效保证；参考善缘现有免责与合规框架。
5. **中性署名**：回向文书/师父署名一律中性（如"寺庙师父""主法居士"），**不打麦玲玲或任何名人/IP**（与善缘既定 IP 红线一致）。
6. **支付合规（Stripe / Apple）**：
   - Stripe：宗教/募捐类可能触发风控——**务必以"服务费/文化服务"入账，避免任何"donation/捐款"措辞**，否则易被冻结。
   - Apple IAP：若做 App，实体/线下履约的代办服务通常走**外部支付**（非数字商品，不走 IAP），需按 Apple 政策界定；上架前单独审。
7. **海外先跑**：优先海外华人市场（合规压力小于大陆直接经营宗教服务），大陆侧从严。
8. **未成年门槛 + 数据合规**：付费前年龄门；祈福对象姓名等按 PIPL 处理。
