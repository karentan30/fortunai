## 2. 📊 收入战略定型（CMO + CFO + Karen 三方收敛 · 见记忆 project_shenyuan_revenue_strategy）
**核心决策：算命（报告+订阅）= 稳定基本盘；代烧/祭祖 = 季节放大器，不是主力。**

- **算命为什么是基本盘**：人人想算自己、365天可售、覆盖生老病死全人生问题、同八字引擎切N个报告近零成本扩品、可复购可订阅、~90%毛利、可规模化。Fatetell 已证明光算命报告就能盈利。
- **代烧为什么不是主力**：强季节性（清明+中元+忌日，一年仅**3-5周**有效销售，47周淡季）、几乎零复购、40-60%毛利被真人跑腿吃掉、心电图式现金流。$199代烧客一年买1次 vs $15/月订阅一年$180可预测可复利。
- **CFO 纠 CMO 两点**：①代烧当"主力"是财务误判（应是季节放大器）②月订阅被低估（唯一可预测 MRR+90%毛利+最高估值倍数=第一梯队）。

**收入三桶（成熟期占比）**：A 稳定基本盘=订阅+算命报告+纪念人（50-55%）／ B 季节放大器=代烧祭祀冥器法事（20-25%）／ C 高毛利实物+高客单=水晶电商+真人咨询（20-25%）。**原则：A交房租·B冲峰值·C拉客单。**

**执行顺序**：纪念人/免费八字合婚**引爆获客** → 订阅+算命报告**承接成经常性收入** → 代烧清明中元**季节冲量**。

**聪明落地**：①代烧产品化成"年度祭祀订阅"$99/年含清明+中元+忌日3次=把脉冲拉成经常性 ②淡季用"每月初一十五平安灯/纪念人"填谷 ③收入目标拆 MRR vs 一次性两条线考核（Month6 $510K/月客单$85 被季节性拉高·可能虚）。

**剔除**：高考志愿从主线剔（纯大陆+季节性+撞海外华人战略）。无差异化塔罗/紫微=凑品类别投钱。
