## 二、大厂AI工具的问题

| 问题 | 说明 |
|------|------|
| ❌ 算法不透明 | 同一分数不同App推荐结果重合率不到30% |
| ❌ 缺乏个性化 | 只看分数，不看学生的兴趣、性格、命理 |
| ❌ AI幻觉 | 推荐不存在的专业/学校，需要人工核实 |
| ❌ 没有深度指导 | "连问题都不会问的人，怎么办呢？"——张雪峰 |
| ❌ 没有情绪价值 | 家长更相信"人"的建议，而不是冷冰冰的数据库 |

**大厂不靠这个赚钱**，而是作为流量入口。所以他们的产品不会做到极致。
