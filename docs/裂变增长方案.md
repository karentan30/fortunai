## 1. 邀请返佣机制

### 1.1 邀请链接结构

#### 邀请码生成 & 存储
```
ref_code = base36(user_id) 或 6位 nanoid
存储位置：user.ref_code（用户表）
生成时机：注册成功后自动生成
验证规则：6位字母数字，不重复，case-insensitive

示例：
user_id: 1001 → ref_code: "sky42"
share_url: https://myfortuneai.vercel.app?ref=sky42
          https://myfortuneai.vercel.app/bazi?ref=sky42
```

#### 邀请追踪路径
```
新用户点击 ?ref=sky42
↓
注册时 POST /api/auth/register { email, password, ref_code: "sky42" }
↓
Store: referrals["sky42"] = [new_user_id, ...]  // 追踪关系
Store: user[new_user_id].invited_by = "sky42"   // 被邀方记录
↓
第一次付费 → grantReferralReward(邀请人_id)
```

#### 技术实现（已在 server/lib/store.js）
```javascript
// 邀请关系表
const referrals = new Map(); // { ref_code → [invited_user_ids] }
const rewards = new Map();   // { user_id → total_earned }

// 核心函数
function createReferral(inviter_id, invitee_id) {
  const inviter = users.get(inviter_id);
  if (!inviter.ref_code) generateRefCode(inviter_id);
  
  referrals.set(inviter.ref_code, [...(referrals.get(inviter.ref_code) || []), invitee_id]);
  users.get(invitee_id).invited_by = inviter.ref_code;
}

function invitedCount(user_id) {
  const user = users.get(user_id);
  return referrals.get(user.ref_code)?.length || 0;
}
```

### 1.2 返佣比例 & 上限

#### 返佣规则（保守版）
```
邀请人 → 邀请新用户 → 新用户首次付费
         ↓
       邀请人获得返佣

返佣比例：
├─ 冷启动（首 100 邀请人）
│  ├─ 被邀用户付款 $39.99 报告 → 邀请人获 $5.99（15%）× 2 倍奖励
│  └─ 共 $11.98 / 人，限前 100 人，总额 $1,198
│
├─ 常规期（Day 1+）
│  ├─ 被邀用户首笔订阅（$14.99/月 或 $39.99 报告）
│  │  → 邀请人一次性获 $2-3
│  │
│  └─ 被邀用户首年内持续订阅 / 续费
│     → 返佣不叠加（避免诱导）
│
└─ VIP 命理师（Phase-2）
```

### 1.3 提现规则

#### 提现流程（演进路线）

**Phase-0（8月-9月）**：社交媒体兑现（不涉及真金白银）
```
返佣不直接提现 → 转为：
- 订阅时长延期（$20 → 1 个月免费会员）
- 报告打折券（$20 → $39.99 报告金额 75 折）
- 限量数字徽章 / 排行榜高亮

优势：
✓ 降低支付复杂度
✓ 提升复购转化
✓ 避免洗钱/反洗钱合规风险
```

**Phase-1（9月+）**：实现提现通道
```
条件：
- 余额 ≥ $20
- 已绑定支付宝/微信/PayPal
- 通过人工身份验证

流程：
1. 用户 POST /api/referral/withdraw { amount, method: 'alipay'|'wechat'|'paypal' }
2. 后端记录提现申请 / 标记为 pending
3. 每周一运营人员批量处理（通过支付宝/微信转账）
4. 确认后用户可见交易记录

时间：3-5 工作日到账
手续费：提现金额 2%（由平台承担，用户看到净额）
```

**Phase-2（明年+）**：自动化提现（集成 Stripe Connect）
```
用户开通 Stripe Connect 账户
→ 返佣自动周结 → 直接到用户银行卡
→ 支持美国/欧洲/亚洲
```

```sql
ALTER TABLE users ADD COLUMN (

CREATE INDEX idx_invited_by ON users(invited_by);

```

#### Referrals 表（追踪邀请关系）
```sql
CREATE TABLE referrals (
  id INT PRIMARY KEY AUTO_INCREMENT,
  inviter_id INT NOT NULL,                        -- 邀请人 user_id
  invitee_id INT NOT NULL,                        -- 被邀人 user_id
  referral_code VARCHAR(10),                      -- 用于追踪的邀请码
  status ENUM('pending', 'confirmed', 'rewarded') DEFAULT 'pending',
  reward_amount DECIMAL(10,2),                    -- 返佣金额
  reward_granted_at TIMESTAMP,                    -- 返佣给予时间
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  confirmed_at TIMESTAMP,                         -- 被邀人付费确认时间
  
  FOREIGN KEY (inviter_id) REFERENCES users(id),
  FOREIGN KEY (invitee_id) REFERENCES users(id),
  UNIQUE KEY (inviter_id, invitee_id),            -- 防止重复邀请同一人
  INDEX idx_status (status),
  INDEX idx_created_at (created_at)
);
```

#### Referral Rewards 表（返佣账户）
```sql
CREATE TABLE referral_rewards (
  id INT PRIMARY KEY AUTO_INCREMENT,
  user_id INT NOT NULL UNIQUE,
  balance DECIMAL(10,2) DEFAULT 0,                -- 可提现余额
  pending_balance DECIMAL(10,2) DEFAULT 0,        -- 待结算（用户付费确认中）
  lifetime_earnings DECIMAL(10,2) DEFAULT 0,      -- 历史累计
  withdrawn_amount DECIMAL(10,2) DEFAULT 0,       -- 已提现累计
  tier_upgrade_bonuses DECIMAL(10,2) DEFAULT 0,   -- Tier 升级奖励
  last_withdrawal_at TIMESTAMP,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  
  FOREIGN KEY (user_id) REFERENCES users(id),
  INDEX idx_user_id (user_id),
  INDEX idx_tier (user_id)  -- 查询 Tier 排行
);
```

#### Share Cards 表（分享卡片追踪）
```sql
CREATE TABLE share_cards (
  id VARCHAR(50) PRIMARY KEY,                     -- share_id（用于 og:image）
  user_id INT NOT NULL,
  report_type ENUM('bazi', 'hehun', 'tarot'),
  card_data JSON,                                 -- Canvas 生成数据
  qr_code LONGBLOB,                               -- QR 二维码图片
  og_image_url VARCHAR(255),                      -- 社交媒体预览图链接

  views_count INT DEFAULT 0,                      -- 点击次数追踪
  conversions INT DEFAULT 0,                      -- 转化数（来自此卡片的注册）
  
  FOREIGN KEY (user_id) REFERENCES users(id),
  INDEX idx_user_id (user_id),
  INDEX idx_created_at (created_at),
  INDEX idx_views (views_count DESC)
);
```

#### Referral Withdrawals 表（提现历史）
```sql
CREATE TABLE referral_withdrawals (
  id INT PRIMARY KEY AUTO_INCREMENT,

  transaction_id VARCHAR(100),                   -- 支付宝交易号
  reason VARCHAR(255),                           -- 失败原因
  created_at TIMESTAMP,
  completed_at TIMESTAMP,
  
  FOREIGN KEY (user_id) REFERENCES users(id),
  INDEX idx_user_id (user_id),
  INDEX idx_status (status),
  INDEX idx_created_at (created_at)
);
```

### 4.5 反作弊和风控规则（Middleware）

```javascript
// middleware/referral-antifraud.js

const ANTI_FRAUD_RULES = {
  // IP 黑名单
  ipLimit: {
    max_accounts: 5,
    window: 24 * 3600, // 24 小时
    penalty: 'block_new_accounts'
  },
  
  // 设备指纹
  deviceFingerprint: {
    same_device_max_referrals_per_day: 50,
    penalty: 'freeze_referral'
  },
  
  // 邀请行为异常
  referralBehavior: {
    max_invites_per_hour: 20,
    max_invites_per_day: 100,
    penalty: 'rate_limit'
  },
  
  // 付费风险
  paymentRisk: {
    refund_within_days: 14,
    reversal_penalty: 'clawback_reward'
  }
};

// 示例函数
async function checkReferralFraud(req) {
  const ip = req.ip;
  const deviceId = req.body.device_id || req.headers['user-agent'];
  
  // 检查 IP 是否已有太多账户
  const ipAccounts = await db.users.countByIP(ip, 24);
  if (ipAccounts > ANTI_FRAUD_RULES.ipLimit.max_accounts) {
    return { fraud: true, reason: 'ip_limit_exceeded' };
  }
  
  // 检查设备今日邀请数
  const deviceInvites = await db.referrals.countByDevice(deviceId, 'today');
  if (deviceInvites > ANTI_FRAUD_RULES.referralBehavior.max_invites_per_day) {
    return { fraud: true, reason: 'invite_limit_exceeded' };
  }
  
  return { fraud: false };
}

module.exports = { checkReferralFraud, ANTI_FRAUD_RULES };
```

## 7. 常见问题 & 操作指南

### 7.1 邀请人 FAQ

**Q: 邀请码怎么获取？**
A: 登录后进入「我的邀请」tab，自动生成 6 位邀请码。无需申请。

**Q: 怎样证明我的邀请有效？**
A: 「我的邀请」页面会实时显示：
- 已邀请人数（通过你的链接注册）
- 其中付费的人数（已产生返佣）
- 可提现余额（确认的返佣）

**Q: 返佣什么时候给？**
A: 被邀人注册后 30 天内首次付费 → 返佣立即计入可提现余额。
（无需等待，但 14 天内退款则返佣撤销）

**Q: 可以提现多少次？**
A: 无限制。只要余额 ≥ $20，随时申请提现。
一般 3-5 工作日到账。

**Q: 返佣有上限吗？**
A: 有。每用户每月返佣上限根据 Tier 设定：
- Tier 0-1: $50/月
- Tier 2: $200/月
- Tier 3 VIP: $500/月

**Q: 怎样升级到 Tier 2？**
A: 邀请 ≥ 20 人且 ≥ 10 人付费 → 自动升 Tier 2。
升级后权益立即生效。

**Q: 邀请官排行榜每周怎么更新？**
A: 每周一 00:00（UTC+8）自动重新排名。
排名基于邀请人数（新邀请数最多的排前）。

**Q: 我能自己用自己的邀请码吗？**
A: 不行。自己账户注册时无法使用自己的邀请码。
这样做是为了防止刷单。

### 7.2 邀请官运营 FAQ

**Q: 我如何最大化邀请转化率？**
A: 建议：
1. 诚实分享自己的使用感受（而不是硬推）
2. 用分享卡（配图 + 二维码）比纯文字效果好 3 倍
3. 在合适的场景分享（朋友圈/小红书/微信群 各一套文案）
4. 跟进已邀请但未付费的朋友（「你试过了吗？」）

**Q: 什么样的内容分享效果最好？**
A: 根据我们的数据：
- 情感故事型（「这份报告改变了我...」）→ 转化 65%
- 数据背书型（「用户好评 98%」）→ 转化 45%
- FOMO 型（「朋友圈都在算」）→ 转化 52%

建议混合使用，避免刷屏。

**Q: 我已经升 Tier 2，下一步呢？**

2. 申请邀请官联盟（和其他邀请官合作）
3. 获得官方的内容创意奖励（写得好的分享文案有额外 $20-50）
4. 参与月度邀请官沙龙（学习运营技巧）

**Q: 我的邀请码被人冒用怎么办？**
A: 立即联系官方（在 app 内反馈）。
我们有反作弊系统，会自动检测异常账户并回收返佣。

## 9. 风险管理 & 缓解

| 风险 | 影响 | 缓解方案 |
|------|------|--------|
| **返佣吸引力不足** | K < 0.3 | 冷启动 2 倍返佣 + 快速升 Tier 奖励 |
| **邀请质量差（都是僵尸账户）** | 高退款率 | IP/设备反作弊 + 支付风险评分 |
| **邀请官刷单** | 成本溢价 + 法律风险 | 设备指纹 + 每日限额 + 人工审核 |
| **邀请官留存差（邀几个就停）** | K 下降 | 月度挑战赛 + 排行榜激励 + 等级权益 |
| **提现通道风险** | 无法兑现承诺 | Phase-0 用折扣/会员兑换 + Phase-1 分批提现 |
| **监管（洗钱/诱导消费）** | 平台被禁 | 实名认证 + 返佣上限 + 透明规则 + 合规文档 |
