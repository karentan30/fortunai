## 二、玩法详解：输入→输出机制

### 明星脸匹配
```
用户上传自拍/头像
     ↓
人脸检测（关键点提取）
     ↓
与明星脸库做向量相似度比对（Embedding比较）
     ↓
输出：
- 最相似明星姓名
- 相似度百分比（如"87%像Lisa"）
- 4-step渐变动画（Gradient专利玩法）
- 可分享的对比图/合图
     ↓
社交分享 → 新用户流入
```

### 黄金比例/颜值打分
```
用户上传自拍
     ↓
人脸关键点检测（MediaPipe 478点）
     ↓
计算多项黄金比例指标：
  - 脸宽/脸长比
  - 眼间距/脸宽比
  - 鼻宽/嘴宽比
  - 上唇/下唇比
  - 下颌角/颧骨宽比
  - 五官对称性评分
     ↓
输出（分层）：
  [免费] 综合分 + 1-2项指标
  [付费/邀请解锁] 逐项分 + 改善建议 + 对比分析
     ↓
改善建议挂钩：护肤品/彩妆/医美机构推荐（变现）
```

| 变现方式 | 代表产品 | 收入规模 |

黄金比例分析后给出"改善建议"→自然挂接护肤品/彩妆/遮瑕/高光推荐，是国内最成熟的变现路径。美图秀秀月活1亿用户的主要变现之一就是美妆电商导流。**善缘可与护肤/命理相关产品绑定**（如"你的命盘显示木命，搭配绿色系彩妆反而运气更旺"这类内容钩子）。

## 五、可抄爆款点 + 坑/空白

### 可直接抄的爆款动作

1. **Gradient的"渐变动画"**：把结果从"静图"升级为"你的脸渐变成XX明星"短动画→截图变截视频→传播力翻倍
2. **Umax的"结果模糊门"**：免费看综合分，逐项分模糊→邀请3人/付费解锁→病毒系数k直接内置
3. **"你像X%的XX明星"格式**：数字+明星名天然适合分享（"我87%像Jennie！"）
4. **CapCut的内置滤镜路径**：在平台内 native 而非跳出App—— **对于善缘，可做微信小程序内原生体验**，摩擦最低
5. **Umax的"改善建议+产品推荐"**：每个低分指标挂一个护肤/医美推荐

### 市场空白

1. **命理维度切入**：没有产品把"黄金比例"和"八字面相"打通。善缘独有机会——"你的面相对应木命人，鼻梁高挺是财运旺的象征" 这种结合给分数赋予命理意义，完全差异化
2. **韩国사주 + 面相**：韩国"관상"（面相）文化浓厚，没有产品做한국어 明星脸+관상结合，善缘已有韩语报告基础
3. **正向积极框架**（而非评分焦虑）：现有产品普遍低分→焦虑→付费，缺少"你的脸是什么命格，这是天赋不是缺陷"的正向叙事

### 坑（必须规避）

1. **明星授权/肖像权**：使用明星图片做脸库需要授权或规避（用"风格相似"而非真实明星名字是一种规避路径）
2. **ZAO前车之鉴**：深度换脸（deepfake）= 隐私/监管红线，微信会封，中国《AI深度合成管理规定》明确要求标注
3. **Gradient的暗坑**：免费试用绑卡→用户不满→差评+退款风险。善缘应改为直接订阅或邀请解锁，不用绑卡
4. **Star by Face的"冒犯性匹配"**：如果明星脸库质量差，输出结果用户觉得被侮辱（"匹配到一个她认为丑的明星"）→差评病毒

## 六、容貌焦虑合规风险 + 规避策略

### 风险全景

| 风险 | 来源 | 严重程度 |
|------|------|---------|
| 小红书/抖音限流"容貌焦虑"内容 | 平台内容治理 | 中（可绕过） |
| 未成年用户打分→心理健康影响 | 心理学研究+媒体压力 | 高（需主动管控） |
| 中国外貌歧视担忧 | 社会舆论 | 中（无明确法规，但合规意识需强） |
| 欧美"looksmaxxing app"监管压力 | 心理健康专家+媒体 | 上升中（Yahoo Finance、Mount Sinai等机构报告） |
| 肖像权/明星授权 | 法律 | 高（不处理直接违法） |

**looksmaxxing apps 已被心理学家公开点名**（Yahoo Finance / Icahn School of Medicine at Mount Sinai）认为加重青少年心理健康危机，YouTube已限制比较外貌内容推荐。这是全球趋势。

### 规避策略（5条铁律）

**1. 改"打分"为"发现"框架**
- 不说"你的颜值得分67分"
- 改说"你的面部黄金比例接近XX类型，这与命理中的X命格天然契合"
- 正向叙事：每项指标都有命理正向解读，没有"差"只有"不同命格的特征"

**2. 强制未成年门**
- 进入功能前问"你是否满18岁" 
- 18岁以下不显示任何评分，只显示"你的脸型属于X美学特征"描述性内容

**3. 免责声明 + AI标注**
- 结果页显著位置："本分析基于数学美学模型，仅供娱乐参考，不代表真实颜值或医学评估"
- 遵守《互联网信息服务深度合成管理规定》：AI生成内容必须标注

**4. 明星脸用"能量/气场类型"代替真实明星名**
- 不说"你87%像刘亦菲"（肖像权风险）
- 改说"你的面部气质属于'仙气灵秀'型，与小红书热词'刘亦菲感'高度相近"（描述性，规避直接使用肖像）
- 或者只做海外明星脸库（授权风险相对可控），国内不做具名匹配

**5. 改善建议正向赋能而非制造焦虑**
- 不说"你的鼻翼过宽，可以通过整形改善"
- 改说"你的面部轮廓适合X类发型/妆容，以下是你的专属美妆方向"（挂带货）

## 七、技术门槛评估

### 黄金比例计算

**善缘已有 MediaPipe 478 关键点原型——技术门槛基本过了。**

| 组件 | 难度 | 现状 |
|------|------|------|
| 人脸关键点检测（MediaPipe Face Mesh） | 低 | 善缘已跑通 |
| 黄金比例计算（数学公式） | 低 | 纯数学，任何语言10行内实现 |
| 前端可视化输出 | 低-中 | H5 Canvas即可，参考现有报告页风格 |
| 分项指标+命理解读内容 | 中 | 需要内容设计（最核心护城河） |

### 明星脸匹配

| 组件 | 难度 | 说明 |
|------|------|------|
| 人脸Embedding提取（ArcFace/FaceNet） | 中 | 预训练模型开源可用，但需部署GPU或API |
| 明星脸库构建 | 中-高 | 需要收集合法明星图片，建向量索引 |
| 相似度搜索（FAISS或类似） | 低-中 | 开源工具成熟 |
| 肖像权处理 | 高（非技术门槛） | 法务/产品设计问题 |
| 渐变动画效果（Gradient效果） | 中 | 需要face morphing技术，有开源库 |

**建议路径**：先做黄金比例（技术已通，风险低），用命理角度差异化；明星脸匹配用"气质类型"代替具名明星，规避肖像权。

### API替代方案（省自建成本）

- **美图 AI 开放平台**：提供颜值分析/脸型检测API，按次计费，适合MVP阶段直接接
- **Face++ / SenseTime**：企业级人脸识别API，有颜值分析接口
- **OpenAI GPT Vision**：Umax的技术路线，灵活但成本较高（约$0.01-0.02/次）

## 八、结论：值不值得做？

### 结论：**双钩子都值得做，优先黄金比例，明星脸第二阶段**

**为什么做：**
- 市场数据明确：Gradient一周$100万，Umax 6个月$600万ARR，爆发速度快
- TikTok / 小红书话题常青，用户自发分享内容，获客成本极低
- 善缘已有MediaPipe原型，技术门槛最低的部分已过
- **命理+黄金比例是市场真空**，无直接竞品，护城河天然存在

**优先顺序：**
1. **P0**：黄金比例 + 命理解读钩子（技术最快，差异化最强，合规风险最低）
2. **P1**："气质类型"明星脸（规避具名肖像权，做气质标签匹配）
3. **不做**：真实明星姓名精确匹配（肖像权风险 + ZAO前车之鉴）

**关键护栏（必须做）：**
- 18岁未成年门
- 正向"发现"框架，不做评分焦虑
- AI内容标注合规
- 命理解读代替纯颜值评分（善缘差异化 + 法律更安全）
