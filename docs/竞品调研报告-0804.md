## 最值得抄的 UI 设计（优先级排序）

1. **命卦数字中途揭晓** — 输入生日后、创建账号前就展示命卦，大幅降低流失
2. **拍照 → 评分徽章 → 问题卡片** — 圆形金色评分缓缓计数，下方3-5张问题卡，付费按钮在同屏（不跳转）
3. **八卦八角形房间导航** — 用户点击方位 → 该房间的问题/吉位 badge
4. **飞星九宫格显示** — 山星+向星+年星叠加，色块区分
5. **方位有煞气 → 内嵌解决方案卡片** — 在报告里直接嵌入产品图+价格+"2026年专属化解"标签
6. **单问题逐屏引导** — Co-Star模式，无进度条，最后一步才要注册
