# PRD · Runae 独角兽重构(3 页压缩 + AI 顾问 + 真人高端层)· 0910

> 依据:硅谷 CEO 产品审查 + bazi/hehun 页审 + 页面清单审 + 竞品(FateTell/AstroTalk)+ 创始人方向。
> 目标:从"48 个各自为政的小产品/185 页"→ **一个越用越离不开的 AI 命理顾问**,3 页流程,能撑起订阅 + 真人咨询的独角兽 LTV。

## 0. 一句话产品
输一次(生日+可选面相/手相照+想看方向)→ 选想算的 → 得一份整合报告;它**记得你、每天更新、能对话**,想更深可约**真人命理师**。

## 1. 诊断(为什么重构)
- 现状 = 48 个方法端点、76 页各自重问生日、每页一套配色、报告页 20-30 屏 jargon dump、框套框 3-4 层。
- 市场在涨(20%/年),跌的是"静态每日运势"(Co-Star)。赢家(FateTell 订阅 / AstroTalk 真人咨询 $140M)靠的是**关系与复购**,不是一次性计算。
- 创始人洞察:用户用同一静态工具会腻→流失。解药 = 记忆 + 动态 + 对话 + 真人,不是"更多方法"。

## 2. 范围:砍到 7 个方法
**留**:八字 · 西方星座 · 塔罗 · 面相 · 手相 · 合婚 · 每日运势(依据:搜索量 + 复用同一份收集数据 + 变现/留存价值)。
**砍(从入口移除,引擎归档)**:紫微(降级为八字报告内"进阶交叉印证"付费模块)· 六爻 · 奇门 · 大六壬 · 九星 · 玛雅 · 藏历 · 印度吠陀 · 求签 · rune · 风水 · iching。
**剥离(独立业务线,移出主流程)**:代烧/祭祀 14 页。

## 3. 三页架构(核心:收集一次·全复用)
**地基 = profile 存储层**(localStorage + 后端 `/api/profile`),收集页写入,选择页/报告页全读同一份。这是治"乱"和"76 页重问"的根。

**① 收集页 `/collect`**(一屏·渐进)
- 生日【年月日】必填 · 时间可选(带"不知道时辰")· 出生地城市搜索(自动经纬度,**去掉手填 lat/lng**)· 性别
- 面相照 / 手相照 = **可选**(选了才解锁对应方法,不强制,降门槛防流失)
- 想看方向 = 事业 / 爱情 / 财运 / 健康(多选,决定报告重点)

**② 选择页 `/pick`**(一屏·7 张同款卡)
- 同一组件:图标 + 名 + 一句"你会得到什么" + 所需数据角标
- 按①的方向智能高亮(选"爱情"→合婚/塔罗置顶);缺数据的卡置灰"补 X 解锁"→点了只回补那一项

**③ 报告页 `/report`**(单栏·渐进披露·**一个**付费墙)
1. 一句话结论(免费钩子) 2. 核心图/牌/盘(一个视觉锚点) 3. AI 解读按方向分段(免费给第一段) 4. ——单一付费墙—— 5. 完整解读 + 进阶交叉印证(紫微加购) 6. 一个 upsell
- 砍:十神/藏干/纳音原始表藏进"进阶"折叠;中途 cross-sell 全去掉

## 4. 独角兽留存层(变现阶梯)
免费 aha → **AI 报告 $9.9** → **AI 顾问订阅**(记忆 + 每日流年动态 + 深聊追问)→ **真人命理师咨询(最高端)**
- **记忆**:记住你的盘和历史提问,越用越懂 = 护城河 + 回访理由
- **动态**:每日/流年更新 = 天天有理由回来(治"用腻")
- **真人层**:**只需几位**(创始人 + 2-3 位合作),定位高端一对一/真稀缺,简单预约+付款流,不建市场。先 AI 跑量,有需求再上真人。⚠️ `masters.html` 现为 6 个虚构命理师,上真人前必须换真人真资质,在此之前不露假的(合规红线)。

## 5. 设计统一(治"又丑又乱")
- 一套 design token(色/字/间距/圆角)+ 一套组件库(卡/按钮/表单/报告块)
- 浅色暖米白 + 单一金色点缀(对齐已定的 saju-report 浅暖调),7 张卡 + 报告模板视觉全同
- 灭:框套框、每方法一套配色、emoji 撒标题、过度玄学文案、打字机仪式

## 6. 后端收敛(否则前端合=假复用)
- 报告生成收敛为一个共享入口按 method 分发,不再每方法一个 `/api/xxx` 各写一套
- profile 层后端化,支撑记忆/订阅

## 7. 分期执行(排死序)
1. ✅ 删死文件(已做,-10.4K 行)
2. **建 /collect + profile 存储层**(地基)
3. design token + 组件库(7 卡 + 报告模板)
4. 选择页只留 7 卡 + 报告页统一模板 + 单付费墙
5. i18n 合并(-en/-kr 20+ 页→运行时语言开关)
6. 代烧线剥离
7. 接 AI 顾问订阅
8. 真人咨询高端层(几位起步)

## 8. 成功指标
- 页面:185 → 30-40;方法端点:48 → 7
- 免费→报告转化、报告→订阅转化、订阅留存(D7/D30)、真人咨询客单价
- aha 到达时间 < 5s(渐进已达标)
