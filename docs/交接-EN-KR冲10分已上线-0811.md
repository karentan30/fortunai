## ⚠️ 部署红线（下次务必看）

**不要对本仓库直接跑 `deploy.sh all`**：
1. `deploy_all()` 里有 `git add -A && commit && push` —— 会把**另一条线未提交的活**一起卷进 commit 推走。
2. `deploy_backend` 会 scp **整个 server/** —— 会把另一条线**半成品后端**（index.js/email.js/geo.js/email//config/）推上生产，可能 MODULE_NOT_FOUND 崩服。
3. `deploy_frontend` 只推 `index.html`（**不含 root `en.html`**）+ 全部 `pages/*.html`（含别人改的 account.html/bazi.html）。

**安全做法**（本轮用的）：`scp` 精确文件到 `/opt/shenyuan/`，不动 backend、不做 git 操作。前端是静态文件，无需 pm2 restart。
