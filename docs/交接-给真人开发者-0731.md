## 一、项目是什么

善缘是一个 **AI 八字命理 / 东方灵性平台**，面向**海外华人**（中文主站）+ **韩国**（韩语 Phase-0）。

**核心商业模式**（CEO+CMO+CFO 三方 0730 拍板）：
- **A 基本盘（50-55%）**：算命报告 + 会员订阅 —— 365 天可售，90% 毛利，可预测 MRR
- **B 季节放大器（20-25%）**：代烧祭祀/冥器 —— 仅清明+中元 3-5 周有效，**不是主力**
- **C 高毛利实物（20-25%）**：水晶电商 + 真人咨询

**一句话定位**：用户输入生辰 → AI 生成八字命理报告（免费基础版/付费完整版）→ Stripe 收款 → 会员订阅解锁全部。

## 四、核心业务逻辑（务必读懂再改）

### 1. 数据存储（防丢单红线）
```js
const _M = { users:[], tokens:[], orders:[], readings:[], subs:[], referrals:[], chatUsage:{}, feedbacks:[], _id:{...} };
```
- 所有数据在**内存** `_M`，每次写操作 `_persist()` **去抖 500ms 原子落盘**（tmp→rename）到 `server/data.json`
- 启动时从 data.json 快照回读
- **改代码时绝不能破坏这个落盘机制**，否则 PM2 重启丢单

### 2. 付费墙（收入命门）
- `hasFullAccess(req, keys)`：检查用户订单里是否有**精确匹配**的完整产品（`UNLOCK_BY_CATEGORY` 白名单，勿改回子串匹配——那个被审计出漏洞）
- 订阅类产品（`member_*`/`daily_sub`）检查 `expires_at` 到期，**到期后自动停止解锁**
- 未付费用户 `tier:'basic'`, `locked:true` → 前端挂付费墙 → Stripe → `?paid=1` 回流 → 带 token 重拉完整报告

### 3. 韩国支付（KRW）
- `create-checkout` 传 `region:'kr'` → KRW + 卡支付（KakaoPay 需 `KR_PAY_METHODS` env 开启，需香港 Stripe 商户）
- 韩元价在 `PRODUCTS.amountKrw`（bazi_full 9900 / bazi_vip 19900 / hehun 4900）

### 4. AI 聊天免费额度
- 免费 5 条/天（按 IP+日期，`_M.chatUsage`），会员无限
- `/api/chat/quota` 返回真实剩余，前端对齐
- 未给生辰前命理师必须先温和询问（防瞎编）
