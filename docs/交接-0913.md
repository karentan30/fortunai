## 1. 这轮做了什么（三句话）

1. **堵住「没人能收到货」的根**：三条下单通道原先允许匿名建单，而发货只认 `user_id`，
   匿名订单＝钱收了、没有任何人能解锁。现在报告类商品没登录直接 401 + 前端带表单快照去
   登录页、登录完回原页接着付（代烧/供奉/预约这类人工交付商品仍允许匿名）。
2. **阴宅/风水接上真付费**（你 0913 批准的那条）：阴宅 $99 / ¥299、风水 $29 / ¥59，
   含国内微信扫码。顺手修掉对抗审计查出的两处断点（见第 2 节）。
3. **价格要一致**：两批共动了 39 个页面文件 + 目录（含 7 个补挂 common.js 的），
   一律以**实收价**为准改展示，没有动任何人的钱；
   `displayed-price-matches-catalog.test.js` 加了钉子防漂回。
