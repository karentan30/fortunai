## 💡 Pro Tips (操作时记住这些)

### 文件编辑
```
✅ DO:   在 /Users/karen/projects/shenyuan/legal-CN.html 编辑
❌ DON'T: 在 .claude/worktrees/xxx/legal-CN.html 编辑
结果会不同！
```

### SCP上传
```
✅ 确保上传后生效：
   1. scp legal-CN.html root@47.242.80.65:/opt/shenyuan/
   2. 刷新浏览器 (Ctrl+Shift+R)
   3. 打开网页检查
❌ 上传失败常见原因：
   - SSH密钥权限不对
   - 服务器路径不对
   - 网络超时
```

### 支付测试
```
✅ DO:   使用 Stripe 官方测试卡 4242 4242 4242 4242
❌ DON'T: 用真实信用卡测试（会实际扣款！）

✅ DO:   用一次性邮箱测试 (如 test@example.com)
❌ DON'T: 用你的真实常用邮箱

✅ DO:   测试后查看后端日志验证
❌ DON'T: 只看网页，不查后端是否真的记录了
```

### Webhook配置
```
✅ DO:   在 Stripe Dashboard 检查 webhook 状态
         同时在后端日志中验证 "WEBHOOK received" 字样
❌ DON'T: 只看 Stripe 显示 Sent，不确认后端实际处理了

✅ DO:   如果显示 Failed，先检查服务器是否在线
         然后检查 webhook secret 是否匹配
❌ DON'T: 重复"重新发送"，这不会解决根本问题
```
