## 🔴 先读：小红书导流合规打法(v1 最大的坑)

小红书对「笔记正文硬导流站外链接」打击极重，工具号每条都喊"主页链接"会被判营销号、整号压权重。所以**导流分三层，别只会挂链接**：

| 层级 | 姿势 | 用在哪 |
|---|---|---|
| **主(最安全)** | **让用户搜品牌词**「彩镜测色」找到你 | 前 5 条笔记主用这个 |
| **次** | **评论区扣暗号 → 私信发链接** | 互动高的笔记 |
| **辅(节制)** | 主页挂链接，但正文不反复喊 | 账号有权重后再用 |

**带货澄清(评审这里有个误判，我校正)**：
- ✅ **阿里妈妈口红转链放在「彩镜落地页」上完全合规**——那是我们自己的站，不是小红书的事。用户在小红书被种草 → 去测色 → 在我们页面看到适配色号并下单，佣金正常结。
- ❌ **不能做的**：在小红书笔记正文/评论里直接贴阿里妈妈外链(双跳外链，必被折叠)。
- 🟡 想在小红书**站内**卖：开「薯店」挂购物车走小红书联盟，或走「蒲公英」接品牌合作——这是后期，第一批先别碰。

**其他合规铁律**：不用「显老/显黑/衰老」等容貌焦虑词(降权)；不用「最/第一」绝对化词(广告法)；「免费」每条正文只出现 1 次且不进标题；金额一律模糊("几百到上千")不写精确数；免责用温和诚实语气不用法律腔；肤色受光线影响必提。

## 〇、飞轮机制(为什么这套能跑)

彩镜是你 19 个产品里**唯一自带传播基因**的：

```
小红书种草(制造"我也想测") → 用户搜「彩镜测色」→ 免费测出四季型
      ↑                                                ↓
   朋友看到"我也要测" ←── 晒带皇冠的扇形卡 ←── 出结果+适配色号(在我们页面带货)
```

别人花钱买流量把人拉进来；彩镜是**用户帮你发出去**。所以内容唯一 KPI = **看完就想测 + 测完就想晒**。

**楔子(用户为什么选彩镜)**：线下测色报价上千 → 彩镜 0 成本；ChatGPT 测色要会写 prompt 还常胡说 → 彩镜拍脸 30 秒；海外 App 无中文要订阅 → 彩镜中文直接给色号。
