# PRD：AI 面部黄金比例 + 气质类型匹配模块
**产品 #2 · 独立 AI 美妆/形象品牌（非 Runae）**  
版本 v1.0 · 2026-08-18  

---

## 0. 文档说明

本 PRD 描述独立 AI 美妆形象产品中的核心病毒拉新模块：**面部黄金比例分析 + 气质类型匹配**。

技术复用善缘/Runae 已跑通的 MediaPipe 478 关键点原型 + ArcFace/FaceNet 人脸 Embedding 基础设施。变现路径：免费病毒钩子 → $9.90 完整报告 + 彩妆带货。合规红线：容貌焦虑为最高优先级约束，贯穿全文。

## 1. 一句话定位 · 目标用户 · 核心痛点

### 1.1 产品一句话定位

> **"上传一张自拍，30 秒发现你的面部命格——专属彩妆方向随即解锁。"**

定位刻意回避"颜值打分"框架，改用"命格发现"叙事，与命理调性天然契合，同时规避容貌焦虑。

### 1.2 目标用户

| 用户层 | 画像 | 核心动机 |
|--------|------|---------|
| **核心用户** | 18-32 岁女性，小红书 / TikTok 重度用户 | "想知道我像哪类气质明星 / 我的脸离黄金比例差多少" |
| **次核心** | 18-35 岁男性，关注 looksmaxing / 自我形象 | "想知道自己的面部优势在哪" |
| **带货转化用户** | 上述人群中有彩妆/护肤消费习惯 | "给我适合脸型的妆容方案" |

**明确不服务**：18 岁以下未成年人（功能层硬门控）。

### 1.3 核心痛点

1. **好奇心痛点**："我到底像哪类明星气质？"—— TikTok `#whatcelebritydoilooklike` 数亿次播放证明需求真实常青。
2. **认知痛点**："我不知道自己的脸有什么优势，不知道适合什么妆容发型。"—— 通用美妆建议不如个性化建议有说服力。
3. **病毒痛点**："我拿到结果想晒但又想让朋友也来看自己的结果。"—— 社交比较驱动分享，分享驱动新用户流入。

## 3. 免费钩子 vs 付费点（病毒 K 值设计）

### 3.1 设计原则：结果模糊门是病毒机制的一部分，不是阻碍

参照 Umax $600 万 ARR 核心机制：**付费门 = 邀请门二选一**，让每个想解锁的用户天然成为传播节点。

| 层级 | 内容 | 目的 |
|------|------|------|
| **完全免费** | 命格类型名 + 综合匹配度模糊数字 + 1 项优势描述 + 分享卡片 | 激发好奇 + 触发分享 |
| **邀请解锁（免费）** | 邀请 3 人完成分析 → 全解锁 | 直接内置 K>1 的裂变 |
| **付费解锁（$9.90）** | 即时全解锁完整报告 | 无耐心用户直接转化 |
| **付费报告内容** | 逐项指标 + 气质对标 + 彩妆发型建议 + 带货推荐 | 留存 + 变现闭环 |

### 3.2 模糊化设计规格

- 综合匹配度：显示 "██ %" 马赛克遮挡后两位数字（仅显示十位），保留数字感但激发焦虑的"最后一步"
- 逐项指标：以灰色色块覆盖具体数值，但保留指标名称（用户知道有什么不知道自己多少分）
- 气质对标：显示"你的命格类型气质接近…… [解锁查看]"
- 彩妆建议：展示色卡缩略图（模糊不可读）+文字全遮挡

### 3.3 分享卡片设计要求

- 尺寸：1080×1920（竖版，适配小红书/Instagram Story）
- 内容：命格类型大字 + 面部轮廓线条图（非真实照片，线条风格保护隐私）+ 品牌标识
- 文案：`"我是 [命格类型]，你是什么命格？→ [链接]"`
- 无需付费即可下载分享卡片（分享卡本身是免费获客工具）

## 4. 变现闭环

### 4.1 主变现路径

```
黄金比例分析结果
       ↓
命格类型（如"暖韵大气型" / "仙韵清冷型" / "甜酷街潮型"等）
       ↓
专属彩妆方向建议（按命格类型输出色系/质地/妆效偏好）
       ↓
带货推荐区（附联盟 / 自营商品链接）
```

### 4.2 带货品类策略

| 优先级 | 品类 | 逻辑 |
|--------|------|------|
| P0 | 口红/唇釉 | 最直接与嘴型黄金比例挂钩；SKU 丰富；高频复购 |
| P0 | 眼影/眼线 | 与眼型指标直接挂钩 |
| P1 | 腮红/高光/修容 | 改善骨骼感知；面部轮廓相关 |
| P1 | 隔离/粉底 | 肤色均匀度指标延伸 |
| P2 | 发型产品（造型喷雾/护发） | 发型建议延伸 |
| **不做** | 医美导流（填充/手术） | 合规红线，明确禁止 |

### 4.3 联盟收益参考

- Sephora / Ulta 联盟：约 3-5% 佣金
- 小红书好物推荐（国内）：挂商品链接，品牌返点 8-15%
- 自有选品店（二期）：定价权更高

### 4.4 命理钩子加成（差异化）

利用善缘/Runae 已有命理 IP，在彩妆建议中融入命理维度，形成独特内容护城河：

示例：
> "你的面部命格为'仙韵清冷型'，在东方命理中对应木命清气。木命人适合冷调绿棕/裸灰系彩妆，能强化天然气场而非压制它。以下是你的专属色系…"

这一叙事角度全球无竞品复制，既规避颜值焦虑，又提高内容可信度和分享欲。

## 6. 技术方案

### 6.1 黄金比例分析（MVP 核心·技术已通）

**计算逻辑（基于 MediaPipe 478 关键点）**：

| 指标名 | 计算方式 | 关键点索引参考 |
|--------|---------|--------------|
| 三停五眼比例 | 发际线→眉心→鼻底→下颌各段落距离比 | 点 10, 8, 1, 152 纵轴 |
| 眼间距比 | 两眼内眼角距离 / 脸宽 (理想 ≈ 1/5) | 点 133, 362 / 234, 454 |
| 鼻翼宽比 | 鼻翼宽 / 嘴宽 (理想 ≈ 0.7-0.8) | 点 49, 279 / 61, 291 |
| 唇形比例 | 上唇高 / 下唇高 (理想 ≈ 1:1.5) | 点 0, 13, 14, 17 |
| 面部对称性 | 左右对应关键点坐标差的均值 | 全部左右对称点对 |

**输出层设计**：
- 每项指标计算后映射到"命格类型权重矩阵"，非直接输出分数
- 最终输出为命格类型 + 各类型亲近度权重，而非 0-100 分

**命格类型示例（需内容专项设计）**：

| 命格类型 | 面部特征偏向 | 命理对应 | 彩妆方向 |
|---------|-----------|---------|---------|
| 仙韵清冷型 | 眼间距宽·鼻梁挺·下颌感强 | 木命清气 | 冷棕/裸灰/浅灰烟熏 |
| 暖韵大气型 | 颧骨宽·嘴型丰润·脸型圆融 | 土命贵气 | 砖红/橘调/大地裸色 |
| 灵动妩媚型 | 大眼比·唇型立体·脸型精巧 | 火命灵气 | 玫瑰/珊瑚/粉紫系 |
| 甜酷街潮型 | 对称感强·鼻翼窄·下颌线锐 | 金命锐气 | 深酒红/焦糖棕/哑光 |
| 秀美知性型 | 三停均匀·整体比例接近 phi | 水命文气 | 莓调/复古玫瑰/裸粉 |
| 霸气御姐型 | 颧骨突出·下颌宽·眉弓明显 | 金木混命 | 正红/深棕/金古铜 |

（以上为示意，正式上线需内容专项设计 + 用户研究验证）

### 6.2 气质类型匹配（二期·Embedding 方案）

**方案选择**：

| 方案 | 优点 | 缺点 | 推荐阶段 |
|------|------|------|---------|
| **ArcFace 自部署 + FAISS** | 成本低（推理本地）·可控 | 需 GPU 或云推理，冷启动慢 | 二期 |
| **美图 AI 开放平台 API** | 接入快（1-2 天）·有颜值分析接口 | 按次计费（约 ¥0.1-0.2/次）·数据出境 | MVP 可用作备选 |
| **OpenAI GPT Vision** | 灵活描述输出 | $0.01-0.02/次·成本高·延迟高 | 不推荐 |

**MVP 阶段不做精确人脸 Embedding 明星匹配**，改为：
- 基于黄金比例特征向量 → 映射到预定义的"气质风格库"（6-8 种类型）
- 气质风格库由人工策划，每种类型关联"该类型面部特征描述"+ "代表明星的风格词"（非姓名）

**二期 Embedding 方案具体路线**：
```
用户人脸 → ArcFace 提取 512 维 Embedding
                ↓
与气质类型代表图集 Embedding 做余弦相似度
（图集：每类型选 50-100 张公开授权图，建向量索引）
                ↓
输出：最近类型 + 相似度分布（非具名匹配）
```

## 7. 容貌焦虑合规红线（最高优先级约束）

以下 5 条铁律必须在代码上线前逐条 QA 验证，任何一条未达标不得上线。

### 铁律 1：改"打分"为"发现命格"框架（产品层）

- **禁止**出现"你的颜值得分 XX 分"、"你的鼻翼不够完美"、"你低于黄金比例"等负向评分语言
- **必须**使用："你的面部命格属于 XX 型"、"你的面部具有 XX 特征"
- 每一项指标结果，无论数值高低，均配有正向命理解读（没有"差"，只有"不同命格的天赋特征"）
- 技术验收：产品文案全文 grep `"分"` `"低"` `"差"` `"缺"` `"不足"` `"改善"（仅涉及外貌场景时禁用）`，逐条审核

### 铁律 2：18 岁强制门控（功能层）

- 进入分析功能前，展示年龄确认弹层："本功能面向 18 岁以上成年用户"
- 用户选择"未满 18 岁"：
  - 硬跳出分析流程
  - 仅显示："你的脸型属于 [X 美学特征] 类型"（描述性，无评分，无比例数字）
  - 带货区不展示
- **不能依赖用户自报年龄豁免**：UI 层必须有清晰的双选按钮，不能只是"同意协议即通过"
- 技术验收：QA 测试未成年路径，确认全程无任何分数/比例数字出现

### 铁律 3：AIGC 标注 + 免责声明（合规层）

**每个结果页必须包含**：
```
[AI 生成内容] 本分析基于数学美学模型与命理风格理论，
仅供娱乐与形象参考，不代表真实颜值评价或医学评估。
```
- 字号不得小于 12px，颜色对比度符合 WCAG AA 标准
- 中国境内用户：符合《互联网信息服务深度合成管理规定》（2022）
- 标注不得在分享卡片中省略（水印或角标形式保留）

### 铁律 4：明星脸用"气质类型"代替真实姓名（法务层）

- **绝对禁止**："你 87% 像刘亦菲 / Lisa / Jennie"（肖像权风险）
- **必须**使用描述性语言："你的面部气质属于仙韵清冷型，这一风格在近年审美热词中对应'刘亦菲感'类气质"（描述现象，不指向具体人物）
- 或：不使用任何明星关联词，仅使用风格词（仙气感·御姐感·甜酷感）
- 向量相似度数据库即使内部使用明星图集，**前端输出层严禁输出真实姓名**
- 技术验收：API 响应 JSON 中不得出现任何人名字段传至前端

### 铁律 5：改善建议接彩妆/发型，不接医美（变现层）

- 带货推荐区：口红、眼影、粉底、发型产品 ✅
- **明确禁止**：玻尿酸、整形机构、医美导流、瘦脸针、填充类内容 ✗
- 文案标准：
  - ✅ "你的唇形适合渐变口红，以下是专属推荐"
  - ✗ "你的上下唇比例偏离理想，可以通过填充改善"
- 技术验收：带货商品库上线前需人工审核，排除所有医美类目

## 附录 A：C 端增长 PM 视角挑刺

### 最弱 3 点及补救方案

**弱点 1：命格类型系统是最大未知风险，却没有验证计划**

现状：PRD 假设 6-8 种命格类型能覆盖用户期待且用户认可正向框架；但这是内容团队的主观设计，尚无用户验证。Umax 的失败案例之一是部分用户认为"算法给了低分而被侮辱"——哪怕框架改了，用户仍可能把命格解读成高低排名。

补救：
- **M0 阶段增加用户访谈**：招募 10-15 名目标用户（18-28 岁女性），做纸面原型测试，验证"命格类型"叙事是否被接受为正向而非评分
- **AB 测试文案**：软上线阶段对比"你是仙韵清冷型"vs"你的黄金比例与仙韵清冷型高度吻合"两种表述的分享率
- **设置用户反馈按钮**在结果页，追踪"你觉得这个分析准确吗"的情绪反应

**弱点 2：邀请 3 人门控的摩擦可能过高，损失有效转化**

现状：PRD 设计邀请 3 人解锁，但没有设计好友接受率的预期和回退路径。实际场景：用户分享给 3 个朋友，但朋友可能都不完成分析，用户等不到解锁就流失。Umax 的邀请机制之所以有效，部分原因是他们的分享内容本身也制造了同伴好奇心——当朋友看到你的结果想知道自己的。

补救：
- **显示实时邀请进度**：" 已完成 1/3 ，还需 2 人"，进度条可视化减少放弃
- **降低门槛选项**：邀请 3 人 → 或者邀请 1 人 + $4.90（设计阶梯价格 A/B 测试）
- **分享内容设计强化好友好奇心**："我测出来是 XX 命格，你是哪种？"而非纯品牌宣传
- **邀请链接 72 小时有效期**提示，制造轻微紧迫感

**弱点 3：带货闭环在 MVP 阶段是静态映射，可能显得廉价影响付费意愿**

现状：PRD 规定 MVP 阶段彩妆建议用"静态规则引擎（按命格类型映射）"，即所有"仙韵清冷型"用户看到同一套推荐。这意味着付费 $9.90 的用户可能觉得推荐不够个性化，性价比存疑。

补救：
- **增加 1 个个性化维度**：在黄金比例分析流程中增加"肤色自测"（3 色色块选择，冷调/暖调/中性），命格类型 × 肤色 = 矩阵扩展到 6×3=18 组推荐，成本极低但个性化感知提升明显
- **文案个性化**：即使商品 SKU 相同，通过在报告正文中引用用户的具体指标数据（"你的眼间距比为 X，属于宽眼型，适合内眼角重点强调的画法"）让用户感受到"这是针对我的分析"
- **建立反馈机制**：结果页加"这个推荐适合我吗？👍/👎"，收集信号，二期迭代个性化算法
