# 善缘 · 韩国收款 决策备忘（0730）

> 一句话结论：**没有韩国法人的当下，用香港主体开 Stripe 最快合法收到 KakaoPay**——官方明确支持香港账户收 KakaoPay/NaverPay/Samsung Pay/PAYCO 且"无需韩国本地法人"。先用它验证市场，跑通再决定要不要落地韩国法人。

---

## 1. 核心事实（决定路线）

- **统一 API 存在**：韩国用 **PortOne（포트원/原 iamport）** 一次聚合 KakaoPay+NaverPay+Toss+卡+Samsung/Apple Pay。但 PortOne 只是编排层，底层仍要签一家真 PG，**且全部要求韩国营业执照(사업자등록증)**——对现在的我们是"目标态"不是"起步态"。
- **资质硬门槛**：直连任何韩国本地 PG（KG이니시스/NHN KCP/NICEPAY/Toss Payments）**强制要 사업자등록증 + 韩国结算账户**，外国公司会被直接拒。
- **你原点名的跨境 PG 全走不通**：Eximbay/Payletter/KCP Global 都是韩国本地商户专用、或无韩国钱包，不收海外公司。

## 2. 跨境方案对比（无韩国法人可用的）

| 方案 | 韩国钱包 | 收香港公司 | 备注 |
|---|---|---|---|
| **Stripe(香港账户)** ⭐首推 | KakaoPay/NaverPay/Samsung/PAYCO ✅ · **Toss ❌** | ✅ 官方列 HK、明确无需韩国法人 | 复用 Lumee 香港 Stripe 基建；KRW 计价 |
| Paymentwall | KakaoPay+**Toss**+PayCo ✅ | ✅ 称无需本地法人 | 要 Toss 时的补位，需小额实测 |
| KOMOJU / Tazapay | 韩国本地方式 ✅ | ✅ 无本地法人 | 费率需问销售 |
| Paddle(MoR) | KakaoPay/NaverPay ✅ · Toss ❌ | ⚠️ 需确认收中/港卖家 | 代收代缴税，省事但抽成高(~5%+) |
| PayPal | ❌ 无韩国钱包 | ✅ | 不匹配"KakaoPay为主" |

## 3. 推荐路线 + 步骤（香港 Stripe）

1. **主体**：香港有限公司（大陆主体开不了 Stripe，香港可以）
2. **开户审核**：提交香港公司注册证/董事身份/业务说明
3. **启用支付**：Dashboard 开 KakaoPay/NaverPay/Samsung/PAYCO，币种 KRW
4. **对接**：Payment Intents / Checkout，`payment_method_types` 加 `kakao_pay`/`naver_pay`/`kr_card`
5. **测试→上线**：test mode 跑通 → 真机小额 → 结算到香港账户

## 4. ⚠️ 上线前必须人工核实的 3 点（涉及真金白银）

1. 🔴 **Stripe 对"算命/占卜/心灵服务"的商户政策**——可能列入 restricted business，**开户前先查 Stripe restricted 列表或问客服**，别接完 API 才被封。这是最大不确定项。
2. **Stripe 韩国本地方式的确切费率%**——只在账户后台可见，未公开统一表。
3. **Toss 全网稀缺**——Stripe/Paddle/PayPal 都不支持；只有 Paymentwall 等少数明确支持，要 Toss 得单独实测补位。

## 5. 是否注册韩国法人

**短期不必。** 韩国 FDI 法人：最低注册资本 1 亿韩元(~7.5万美元)、3-6 周、对公户是瓶颈。只有当韩国成主力市场、要吃最低本地费率(KakaoPay 可低到 ~0.84%)、且必须原生 Toss 时才值得——**先用 Stripe 验证市场，跑通再决定**。
