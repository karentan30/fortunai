✨ 7大核心功能一览

1. 📊 实时KPI展示
   - DAU (日活用户数) + 环比变化
   - 付费用户总数 + 环比变化
   - GMV (成交金额) + 环比变化
   - AOV (平均客单价) + 环比变化
   - 转化率 + 环比变化
   - 邀请人数 + 环比变化
   
   文件位置: kpi-dashboard.html L50-80
   API: GET /api/kpi/metrics

2. 📈 A/B测试转化率排行
   - 8个落地页访问量、转化数、转化率排名
   - 实时状态标签 (winning/running/losing)
   - 趋势箭头 (↑ ↓)
   
   文件位置: kpi-dashboard.html L280-290
   API: GET /api/kpi/ab-tests

3. 👥 邀请排行榜
   - Top10邀请者排行
   - 邀请人数、转化数、转化率、返佣金额
   
   文件位置: kpi-dashboard.html L340-360
   API: GET /api/kpi/referrals

4. 💳 支付方式分布
   - 微信支付、Stripe、支付宝 占比饼图
   - 7日支付趋势对比曲线
   
   文件位置: kpi-dashboard.html L620-760
   API: GET /api/kpi/metrics (chart.paymentDistribution)

5. 📉 用户留存曲线
   - Day1/Day3/Day7 留存率折线图
   
   文件位置: kpi-dashboard.html L550-580
   API: GET /api/kpi/metrics (chart.retention)

6. 🚨 错误告警系统
   - 支付失败率 > 5%
   - Webhook异常 > 10次/小时
   - API响应时间 > 2000ms
   - 转化率下降 > 20%
   
   文件位置: kpi-dashboard.html L900-950
   API: GET /api/kpi/errors

7. 🌍 地理分布
   - 中国/海外/韩国用户占比柱状图
   
   文件位置: kpi-dashboard.html L690-710
   API: GET /api/kpi/metrics (chart.geographic)

+ 🔻 转化漏斗 (Bonus)
   - 访问 → 注册 → 首购 三层漏斗
   - ECharts 渲染
   
   文件位置: kpi-dashboard.html L770-800

🔄 实现细节

前端数据流:
  1. 页面加载 → init() 函数
  2. 调用 /api/kpi/metrics 等 API
  3. 解析 JSON 响应
  4. 更新 DOM (指标卡片)
  5. 初始化 Chart.js / ECharts 图表
  6. 启动 30秒 auto-refresh 定时器
  7. 离线时使用 LocalStorage 缓存数据

后端数据流:
  1. GET /api/kpi/metrics 请求到达
  2. 读取 data.json 文件
  3. 计算 metrics (DAU/GMV/AOV/CR 等)
  4. 构建 charts 对象
  5. 聚合 errors 告警
  6. 返回 JSON 响应 (< 200ms)
