## 三、今日完成的所有技术工作

### 3.1 年龄范围修复（全平台支持2026年出生婴儿）
bazi / bazi-en / geo-fortune / ziwei / zhiyuan 年份选择器全部从 2010 改到 2026。

### 3.2 SSE 流式输出修复（Caddy gzip 缓冲问题）
- **根因**：Caddy `encode gzip` 缓冲 SSE，导致大块输出而非逐字
- **修复**：三个域名的 Caddyfile 均改为 `@not_stream { not path /api/*/stream }` 排除流式路径
- **效果**：现在每个汉字单独 SSE chunk（已验证吠陀占星）

### 3.3 风水页面 v2 大升级
**前端新增**：
- 家庭成员命卦输入（户主必填 + 最多5人，自动计算命卦/东西四命）
- 图片上传区域（户型图1张 + 房间照片3张，折叠式）
- 所有数据传给服务器

**服务器新增**：

**命卦计算逻辑**：
```js
function calcMingua(birthYear, gender) {
  var n = birthYear;
  while (n >= 10) { var s=0,t=n; while(t>0){s+=t%10;t=Math.floor(t/10);} n=s; }
  var q = gender==='M' ? (10-n) : (n+5);
  if (q===5) q = gender==='M' ? 2 : 8;
  if (q>9) q -= 9;
  return q; // 东四命: 1,3,4,9 | 西四命: 2,5,6,7,8
}
```
