## 一、战略决策记录

### 为什么做多轨

用户画像中有一类高价值用户：**多轨信仰者**——同时信八字+塔罗+印度占星的人，付费意愿远高于单轨用户。目前市场上无竞争对手做跨体系综合。

### 产品路线图（两阶段）

**Phase 1（当前）：建4个单轨模块**
每个系统独立页面，各自收费，复用现有 AI 报告架构。

**Phase 2（单轨完成后）：多轨合读旗舰产品**
用户提一个问题，AI 同时跑 3 个系统，最后给出"三轨共识"结论。定价 $39.90–$49.90（3倍单轨价值 + 综合分析溢价）。

## 三、多轨合读（Phase 2 规划）

### 产品名候选
- **「命运三角」** — 三个宇宙系统同时读你的命运
- **「宇宙共识」** — 当东方、南亚、远古文明都说同一件事
- **「三轨合盘」** — 用户自选任意3个系统

### 技术实现
```
用户提问 → 同时调3个API（如：bazi + jyotish + maya）
→ 各自生成独立报告摘要（200字）
→ DeepSeek综合prompt："以下是同一个人的三份宇宙命理报告，找出共同主题、矛盾点、综合建议"
→ 输出：各系统2-3句要点 + 综合结论1段 + 实践建议
```

### 定价方案（Phase 2）

| 产品 | 价格 | 价值锚点 |
|------|------|---------|
| 单系统基础 | $9.90 | 现有价格 |
| 单系统深度 | $19.90 | 现有价格 |
| 双轨合读 | $24.90 | 省 $14.90 vs 分开买 |
| 三轨合读 | $39.90 | 省 $19.80 vs 分开买 |
| 三轨深度合读 | $59.90 | 旗舰产品，最强综合分析 |

**"占便宜"钩子**："单独买三份要 $59.70，三轨合读只要 $39.90，还多了AI综合解读"
