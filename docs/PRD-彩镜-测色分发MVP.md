## 目标与唯一指标
**阶段目标** | 验证分发能力（不验证产品、不验证变现）
**唯一指标** | 小红书单条笔记：互动率 / 收藏率 / 扫码打开率 / K因子（每用户引入新用户数）
**成功基线** | 1条测试笔记达到3K+互动，K≥1.2（用户自发分享给闺蜜）

---

## 核心用户流程
1. **入口**：小红书扫码/链接 → 打开纯静态页
2. **拍照**：前置摄像头自拍（支持重拍）
3. **实时分析**：MediaPipe WASM本地检测脸部478点 + 眼白/牙齿做白平衡 + 像素取色
4. **分类**：用规则代码（不用Prompt）→ 春/夏/秋/冬季型
5. **出卡**：
   - 季型名+英文+关键词标签
   - 脸部实际取色 + MediaPipe虚线标注
   - 4条滑块（冷暖/明度/纯度/对比）可调看效果
   - 推荐/避免色盘 + 五行开运色
   - 妆容色号（口红3档¥69/¥199/¥329）带淘宝联盟链接
   - 底部CTA："发给闺蜜测同款"
6. **分发**：用户截图/分享到小红书 → 扫码回流

## 算法准度路线（三层无Prompt）

**第一层（零成本·当前）**
- 眼白(巩膜) + 牙齿 + 嘴角作为参考白点做白平衡（治暖光偏色）
- 固定规则分类：冷暖比值 > 0.5 → 冷色（春/冬），否则 → 暖色（夏/秋）
- 明度/纯度用HSL分量分层阈值
- 结果稳定可重复，**不依赖Prompt**

**第二层（质量升级·周期内可做）**
- 收集50-100张已知季型脸部样本，用高斯混合模型调阈值
- 升级到专业12季型（春深/春浅等）
- 迭代误差<10%

**第三层（争议裁决·仅当需要）**
- Qwen-VL作"第二意见"，仅在冷暖模糊时做裁判（不当主判）
- 控制调用频率<20%，节省Token

## 红线（合规与伦理）
1. **措辞防容貌焦虑**：正向表达（"你的气质"而非"改善"），不打分、不残忍、不鼓励整容
2. **隐私**：照片仅在浏览器本地处理，不上传、不落盘、不二次使用
3. **带货标注**：所有淘宝链接标注"推广"或"联盟链接"，合规不踩线
4. **模型隐藏**：前端文案说"AI分析"不说"Qwen-VL"，用中性词隐藏实现细节

## 冷启动分发打法

**内容体裁**（抄林间霍普已验证爆款）
- 标题：`韩国色彩测试，不用素颜不用自然光，30秒出四季型+口红色号`
- 正文：
  - 痛点钩：素颜测色被光影骗，每次结果都不一样
  - 方案钩：我们的AI不挑光、不挑妆，想测几次就几次
  - 结果钩：出卡片直接搬小红书，你的颜色搭配就是这样
  - CTA：扫二维码 / 点链接，闺蜜测同款
- Hashtag：`#韩国色彩测试 #四季型人 #个人色彩诊断 #变美干货 #素颜拍照 #口红色号推荐`
- 素人视角、不过度修饰、真实反应（"我春型竟然穿了秋色的衣服"）

**种子策略**
1. 自己铺3-5条素人笔记（不用美图秀秀，用真实拍照），控制预期：粉丝<500，互动<500，作用是找BUG不是带量
2. 私信种子腰部美妆博主（1-3K粉）给白标额度：`把彩镜嵌入你的落地页，推荐给你粉丝，佣金我们给`
3. 监控数据：互动/收藏/分享/扫码漏斗

## 成功看板（给Karen）
跑完一周后给3条数据：
1. **单条笔记漏斗**：发布数 → 浏览 → 点赞 → 收藏 → 扫码打开（%）
2. **K因子**：有多少%的用户分享给了闺蜜（问卷或链接参数追踪）
3. **口红点击率**：卡片上的淘宝链接点击数 / 总打开数（%）

若漏斗在"扫码打开"卡住（<20%），说明分发钩子不强，需要改文案；若K<1说明用户没自发分享欲，可能是卡片不够"晒"。基于这个信息，Week 3 决策是继续加码还是踩刹车。
