## 功能详解

### 后端功能

#### 1. IP 地理位置检测 (`GET /api/geo/detect`)

```
优先级：
1. CloudFlare headers (最准确)
2. Vercel headers
3. 第三方 API (geojs.io / ip-api.com)

响应示例：
{
  "country": "US",
  "currency": "USD",
  "symbol": "$",
  "bazi_full": 9.90,
  "bazi_vip": 19.90,
  ...
}
```

#### 2. 定价查询 (`GET /api/geo/pricing/:country`)

```
返回指定国家的完整定价
支持 50+ 国家代码
```

#### 3. 价格验证 (`POST /api/geo/validate-price`)

```
防止 VPN 用户欺骗
允许 ±10% 汇率偏差
支付时自动调用
```

#### 4. Admin 查询 (`GET /api/geo/all`)

```
仅 Admin 可访问
返回所有国家定价
用于监控和分析
```

### 前端功能

#### 1. 自动初始化

```javascript
// 页面加载时自动运行
- 检测用户位置
- 获取定价
- 更新页面价格
- 缓存 24 小时
```

#### 2. 价格显示

```html
<!-- 简单标记 -->
<span data-price="bazi_full">¥99</span>

<!-- 自动更新为用户地区定价 -->
<span data-price="bazi_full">$9.90</span>  (美国)
<span data-price="bazi_full">¥99</span>    (中国)
<span data-price="bazi_full">€8.90</span>  (欧洲)
```

#### 3. 支付集成

```javascript
// 一行代码支持三种支付
GEO.createCheckout('bazi_full');

// 自动识别地区
- 中国 → 微信/支付宝
- 其他 → Stripe
- 韩国 → Stripe KRW
```

#### 4. 事件系统

```javascript
// 监听价格更新
document.addEventListener('geopricing-updated', (e) => {
  console.log('Prices updated for', e.detail.country);
});

// 手动切换国家
GEO.updatePricingByCountry('CN');
```

## 快速开始

### 部署步骤

#### 1. 验证后端

```bash
# 进入项目目录
cd /Users/karen/projects/shenyuan

# 运行测试脚本
node server/test-geo.js
# 输出：✅ 所有 25 个国家定价配置完整
```

#### 2. 启动服务器

```bash
# 启动 Express 服务器
npm start
# 或使用 PM2
pm2 start server/index.js --name shenyuan
```

#### 3. 测试 API

```bash
# 检测用户地理位置
curl http://localhost:3021/api/geo/detect

# 查询中国定价
curl http://localhost:3021/api/geo/pricing/CN

# 验证价格
curl -X POST http://localhost:3021/api/geo/validate-price \
  -H "Content-Type: application/json" \
  -d '{"country":"US","product":"bazi_full","amount":9.90}'
```

#### 4. 集成前端

在 HTML 落地页添加：

```html
<!-- 在 <head> 中 -->
<script src="/geo-pricing.js"></script>

<!-- 在页面中 -->
<span data-price="bazi_full">¥99</span>
<button onclick="GEO.createCheckout('bazi_full')">购买</button>
```

#### 5. 测试支付流程

```
测试用户:
- 美国 IP → 显示 $9.90 → Stripe 支付
- 中国 IP → 显示 ¥99 → 微信支付
- 验证成功后 → 显示成功页
```

## 管理工具

### CLI 命令（`server/cli-update-pricing.js`）

```bash
# 列出所有国家
node server/cli-update-pricing.js list

# 显示某国详细定价
node server/cli-update-pricing.js show CN

# 更新价格
node server/cli-update-pricing.js update CN bazi_full 129

# 批量更新汇率
node server/cli-update-pricing.js exchange EUR 1.1

# 备份
node server/cli-update-pricing.js backup

# 恢复
node server/cli-update-pricing.js restore pricing-backup-2025-08-10T12-30-45.json

# 导出/导入
node server/cli-update-pricing.js export > pricing.json
node server/cli-update-pricing.js import pricing.json

# 验证
node server/cli-update-pricing.js validate
```

## 支持与维护

### 常见问题

**Q: 如何修改某国定价？**  
A: 使用 CLI 工具或直接编辑 `server/config/geo-pricing.js`

```bash
node server/cli-update-pricing.js update CN bazi_full 129
```

**Q: 如何添加新国家？**  
A: 在 `geo-pricing.js` 中添加新配置，格式与现有国家相同

**Q: 支持哪些支付方式？**  
A: Stripe (海外), 微信支付 (中国), 支付宝 (中国), 支持 40+ 种货币

**Q: 定价多久更新一次？**  
A: 根据汇率变化，建议每周更新一次

**Q: 用户看不到价格怎么办？**  
A: 检查浏览器缓存，或在控制台运行 `localStorage.removeItem('sy_user_geo')`

### 监控告警

建议配置以下告警：

1. **地理检测失败率 > 5%** → 立即调查
2. **API 响应时间 > 2s** → 优化性能
3. **价格验证失败 > 10/小时** → 检查是否被攻击
4. **支付成功率 < 95%** → 检查支付网关
