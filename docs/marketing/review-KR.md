### 개선 대상 1: copy-crystal Suite 8 — 호안석 카피

**문제점**:
1. **제품명 오류**: "호랑이 눈석" → 한국에서는 **"호안석(虎眼石)"**이 표준 명칭. "호랑이 눈석"은 직역투로 한국 크리스탈/영성 커뮤니티에서 쓰지 않는 단어.
2. **동사 오류**: "호안석이 내 불안을 가르쳤어" → **"가르쳤어"**는 완전히 틀린 표현. 불안을 "가르칠" 수 없음. → "다스렸어" / "잠재웠어" / "달래줬어"로 교체 필수.
3. 전체적으로 번역투가 강해 크리스탈 커뮤니티의 자연스러운 감성과 맞지 않음.

```

[현재] 해시태그 없음 또는 오류
```

## 전반적 진단 (크로스파일 패턴)

### 잘 된 부분
1. **타로(copy-tarot)** 파일이 전체 최강. 한국어 감성, MZ 공감, 플랫폼 형식 3박자 모두 우수.
2. **기념인(copy-jinian)** 파일의 일부 세트(Suite 4, Suite 9)는 원어민도 구분 못 할 수준의 자연스러운 한국어.
3. **브랜드(copy-brand)** 파일의 Suite 9 "蛰伏期" 개념화는 MZ 여성 번아웃 공감에 탁월.
4. **제사(copy-jizu)** Suite 2 "가을이 오면, 당신을 그린다"는 시적 완성도 최고.
5. 전반적으로 "선연 = 솔직한 명리" 포지셔닝이 한국어에도 잘 전달됨.

### 개선 방향
1. **오탈자 정리**: "경경하게" → 경건하게 / "누건" → 누군 / "내동기" → 내적 동기. 제사/사주처럼 신뢰가 핵심인 카테고리에서 오탈자는 치명적.
2. **사주 전문 용어 강화**: 십성(식신/재성/관성 등), 일주(甲子, 乙丑 등), 대운 용어가 전반적으로 부족. 사주 전문 커뮤니티 독자에게는 얕아 보일 수 있음.
3. **크리스탈 명칭 한국화**: "호랑이 눈석" → 호안석 / "보라 물크리스탈" → 자수정 클러스터. 한국 영성 커뮤니티의 용어 기준과 맞춰야 함.
4. **풍수(copy-fengshui)** 파일은 한국어에서 사주 전문성 항목이 약함. "착한연" 해시태그가 반복적으로 등장하는데, 이는 브랜드 인지도가 낮은 단계에서 한국인 검색자에게 도달하기 어려운 태그.
5. **해시태그 검색량 기반 최적화 필요**: `#착한연` 대신 `#선연` / `#사주명리` / `#운세` / `#명리학` 같이 한국 사용자가 실제 검색하는 태그로 교체 권장.
