## 四、SEO 落地建议（零付费）

1. **先打海外华人特供 + 代烧长尾**（竞争极低+差异化），避开生肖泛词正面竞争。
2. Google Search Console + Bing Webmaster 都提交（市场方案已有部署基线）。
3. 每篇内容页内链到免费排盘/合盘工具页 + 报告页（环状结构养权重）。
4. 用 Google 自动补全 + 免费关键词工具验证搜索量，标题自然带长尾词。
5. LocalBusiness / 服务等 Schema 标注（本地截流 SEO 的基础，见地理截流文案）。
