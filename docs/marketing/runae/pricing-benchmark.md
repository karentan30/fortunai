## 三、具体定价建议（要不要调那几个数字）

作为新 entrant，核心策略：**免费段更慷慨勾人 → 单报告保持便宜做价值锚 → 会员抬价值感别抬价 → 堵住"无限聊天"白嫖漏洞。**

1. **完整报告 $19.90 → 保持不动。** 这是 Runae 最强的获客钩子（FateTell 一半价、含金量对标 $39.99）。新用户首单甚至可做 **$9.90 引流价（首报告限时）**，对标测测首月 ¥9.9 打法。不要涨。

2. **大师深度 $39.90 → 保持不动。** 精准锚在 FateTell 单报告价，用户会觉得"同样 $39.9，Runae 给的是大师深度而不是普通完整报告"——价值感碾压。

3. **月会员 $9.90 → 价格不动，但砍"无限聊天"。**
   ⚠️ **这是最该调的一处**：$9.90/月给"无限聊天 + 每月1报告"太慷慨，会养成白嫖（聊天=最大 token 成本）。建议改为 **"每月1完整报告 + 每日限量AI问答（如30条/天）或每月200条"**，把"无限"留给年会员或更高档。价格仍 $9.90 贴 Co-Star，但边际成本可控。

4. **年会员 $99 → 保持 $99，但强化"锚"。** $99 精准卡 FateTell Master $99.99 且比 Chani 便宜，位置好。建议**首年促销 $79（省20%）**做转化，续费回 $99——对标 Chani 年费"省25%"话术。别直接标 $49.99（那是 Nebula 走量打法，会掉 premium 档）。

5. **补一档"周订阅"做冲动转化（可选）。** 英语赛道（Nebula/FateTell/Astroline）都靠 **$4.99–7.99/周** 抓冲动用户。Runae 可加 **$4.99/周**（对标 FateTell Pro）承接"只想试一周深聊"的人，但话术要诚实、不搞暗扣（Astroline/Nebula 因暗扣口碑崩，这是 Runae 的品牌差异点）。

## 五、诚实结论（不掉档 premium）

- **Runae 整体不贵，反而偏亲民且价值感强**——单报告 $19.90 是全场最便宜的完整报告之一，大师深度/年会员精准锚在 FateTell/Chani 高端位。这是"有竞争力但不廉价"的健康结构。
- **占星/命理用户肯花钱**（Sanctuary 一次咨询 $20–60、Chani $108/年活得好、FateTell Master $99.99），**不要一味降价掉档**。Runae 该做的是**用更慷慨的免费段获客 + 更便宜的单报告做价值锚 + 会员靠"深度/无限"体现价值**，而不是比谁便宜。
- **唯一要调的数字级动作**：月会员 **$9.90 砍掉"无限聊天"改限量**（堵白嫖）；其余四个价保持，加一档 **$4.99/周** 冲动转化 + 首报告 **$9.90 引流价** + 年会员首年 **$79** 促销。
- **品牌差异化红线**：Astroline/Nebula 靠暗扣年费赚钱但口碑崩。Runae 走**透明、不暗扣、诚实免责**——这本身就是 premium 信任资产，别学激进套路。
