# 竞品流量渠道构成调研 — 找出"流量最大的地方"给 Runae 照抄

> 调研日期：2026-08-17 ｜ 仅公开信号（SimilarWeb 免费层 = 桌面 web，非 App 安装；Sensor Tower/data.ai 精确安装/收入数字在付费墙后）。凡估算/无数据处已标 **ESTIMATE / 无公开数据**，不编数字。
> 目的：给 Runae（善缘海外/多语盘）定英语 vs 韩语的渠道优先级，抄流量最大那家的具体打法。

---

## 一句话结论（先看这个）

- **英语盘流量最大的渠道 = 分两层**：
  - **原始安装量之王 = 付费投放 UA（Meta/Google + TikTok Ads）** — 因为品类最大玩家 Nebula/OBRIO 就是投流机器（几百条素材工业化测试→30M+ 用户 / $50M ARR），CEO 亲口说早期靠 Facebook/Google 起量，如今约一半仍是付费。证据：[tech.eu](https://tech.eu/2023/12/05/obrio/)
  - **效率/广度之王 = 自然流（TikTok/IG 短视频 + SEO/品牌词）** — Co-Star 桌面 web **60.28% 来自自然搜索**、~659K IG 全靠星座 meme；The Pattern 靠名人+口碑；Chani 零 VC 靠创始人社群；新锐 Astroscope/Starcrossed 靠 TikTok 图文（Astroscope 7000万播放/月）。证据：[SimilarWeb Co-Star](https://www.similarweb.com/website/costarastrology.com/)、[Plutus](https://growwithplutus.com/blog/astroscope-app-tiktok-strategy-breakdown)
  - **净结论**：付费投流赢头部绝对量，TikTok/IG 自然流 + SEO 赢广度和 ROI；ASO 到处都是转化层但很少是"来源"本身。

- **韩语盘流量最大的渠道 = App Store/Google Play 的 ASO（评论数护城河 + 每年生肖改名）**，其次是**春节 신년운세（新年运势）的 Naver + PR 季节性爆发**。韩国渠道权重和欧美完全不同（ASO + Naver + Kakao + IG 远重于欧美式付费社交/Google）。证据：점신 iOS **~11万条评分/4.7★**、App 标题每年改成生肖版"2026 점신…신년운세"；[App Store 점신](https://apps.apple.com/kr/app/id960571015)、[아시아경제](https://www.asiae.co.kr/article/2026021612042733160)

- **中式出海盘（FateTell/测测/Fatelink）流量最大 = 自然口碑 + 社交病毒（TikTok/Reddit），刻意不投付费。** FateTell 明说"无大规模营销，仅靠口碑"，自然流量→注册转化 ~60%，蹭 DeepSeek 算命热两周订阅翻三倍。证据：[newrank.cn](https://www.newrank.cn/article/detail/30163)、[sohu](https://www.sohu.com/a/1013810006_121478199)

## 四、Runae 渠道优先级（英/韩分开，含 ROI 理由）

### 英语盘优先级
1. **P0 — TikTok/IG 短视频自然流（图文 slideshow 为主）**：品类最高 ROI 广度打法（Co-Star/Astroscope 验证），善缘无需大预算即可起量；内容 = 每日星座/八字卡片 meme。
2. **P0 — SEO（免费八字计算器 + 程序化页面）**：抄 Cantian/FateTell 的免费工具→自然搜索→付费墙漏斗，Co-Star 60% 流量证明自然搜索是命理品类的地基。
3. **P1 — ASO（转化层）**：标题塞高意图词（bazi/chinese astrology/compatibility）、堆评论；是安装转化闸而非来源，必须做但不当获客主引擎。
4. **P2 — 付费投流（Meta/TikTok Ads）**：只在有了自然内容素材验证后再放量（Nebula 之路），否则烧钱。善缘默认只读/预算铁律 → 投流必先报预算经同意。
5. **P3 — 名人/达人 + Reddit 口碑**：The Pattern/FateTell 验证有效，低成本可试。

> 理由：善缘无 Nebula 级预算，硬拼投流是自杀；命理品类自然流（TikTok+SEO）ROI 最高且有大量可抄样板。

### 韩语盘优先级
1. **P0 — ASO（评论护城河 + 每年生肖改名）**：韩国安装第一闸，점신靠 11万评分 + 生肖版标题吃 신년운세 词。Runae 韩语 App 标题应含 사주/신년운세/타로/궁합/만세력。
2. **P0 — 春节 신년운세 季节 SEO + Naver + PR 爆发**：韩国年度最大流量脉冲，改标题+品牌联名+媒体稿。
3. **P1 — Instagram 内容飞轮（近每日卡片式运势）**：抄 포스텔러（韩125K/英112K），唯一自然低CAC顶部漏斗且可复用到英文盘。
4. **P1 — Kakao（频道 Plus Friend + Moment 广告）**：Kakao ~4100万 MAU，做留存/再触达的默认层。
5. **P2 — 万세력 高意图词独立 ASO 入口**：抄 포스텔러专门的 만세력 App 抢高意图搜索。

> 理由：韩国用户在应用商店和 Naver/Kakao 生态里决策，欧美式 Google/Meta 投流权重低；ASO+季节 SEO+IG 内容才是韩国 ROI 序。
