# 相生 Runae：免费内测到正式上线 PRD
版本：2026-11-05。状态：验收目标，不代表全部已实现或已上线。最新用户决定覆盖旧方案：先网页版、默认一张分享海报、暂不做小程序。
## 1. 产品和上线范围
相生是以日主、生肖文化偏好为入口的真实交友工具。主路径：测自己的日主 → 填写本人资料 → 生成单张海报与真实邀请二维码 → 好友扫码进入 → 测自己的日主 → 双方授权分析与申请认识 → 自愿交换联系方式。
日主/生肖是用户可修改的兴趣筛选，不预测婚姻成功、怀孕年份或财富。不得用AI照片、虚构高资产资料填充真实人库。

P0 免费内测：生日表单、注册登录、资料保存/编辑/撤回、个人页、单图导出、真实二维码、邀请上下文、双方申请接受、隐私/屏蔽/举报/删除、基础推荐、状态与错误提示。
P1 收费：服务端额度账本、月会员、年会员、单报告订单、支付通知校验、权益开通、退款、双方授权的真实报告交付。
P2：内置语音、场馆订位、多人活动、AI语音访谈、小程序、商家分佣。P0不承诺这些功能。

## 2. 页面与表单
首页极简：品牌“相生 · Runae”；“测测你的日主，认识五行合拍的人”；测日主主按钮；可辨识的虚构样例卡；生日表单。
表单：公历/农历明确选择，年月日中文标签；出生城市（支持境外）；小时分钟一起输入、无秒；时间不确定可选未知；真实出生信息与身份证登记日期可不同，身份年龄认证独立。未知时辰不制造时柱，完整报告标出影响。
访客可先填写；保存到后台前登录并单独确认保存/公开/匹配用途。拒绝公开不妨碍查看自己的结果。不得通过扫码自动把人加入公开人库。
个人资料：昵称、成年人确认、交友目的、城市、照片、年龄、身高、体重、学校学历、职业职务、个人年收入、个人净资产、家庭资产、房车户籍、爱好、双方偏好。收入资产允许不提供；“A9.3”等为自述标签，不能自动赋予核验标志。本人房产和家庭房产区分；有车与车牌区分。家庭住址首版不采集精确门牌。
样例：知远，29岁 / 180cm / 75kg，北京大学·博士，AI算法工程师；家庭资产A9.3。样例所有资料为虚构。个人资产不得混入家庭资产。
真实资料截图仅允许用户上传自己有权提供的资料；提取结果由本人逐项确认再保存。不是未经授权抓取第三方用户的入口。

## 3. 一张海报验收
照片右上；昵称与日主左上；想认识的日主；29岁·180cm·75kg同一排；学校学历和职业直接显示、不重复标签、不显示行业；年收入不重复“/年”；个人净资产/家庭资产分开；房车户籍短标签；一行两个活动；紧凑邀请入口。
取消长五行解释、泛化口号、重复爱好。图片是下载文件，不只滚动到表单。相册保存有长按兜底，手机不需要ZIP。

照片需本人许可；未经验证的财务等资料统一“本人提供”。公开卡片不得包括原始生日时分、完整命盘、私密问卷、精确地址、私人联系方式或内部用户ID。用户主动公开年龄或生肖可能让别人推测出生年份，不能承诺隐藏全部年龄信息；生肖默认隐私设置需与用户选择一致。

## 4. 扫码邀请与双人分析
公开个人卡二维码使用不可枚举的分享标识，不编码生辰。链接包含合法白名单来源和campaign用于聚合转化。
扫码后首屏展示邀请者公开名片与“测测我和TA的五行”；登录前保留邀请上下文，登录后回到原邀请，不错误绑定到其他人。
邀请者必须选择用途：公开认识入口/指定双人分析。公开分享码与双人授权令牌分离。撤回、过期、删除、屏蔽后入口不能继续泄露资料。
访客A/B均单独录入或授权自己的资料；仅在双方同意后生成指定范围的双人结果。先到者看等待状态，不能借报告推算另一方生日。撤回后禁止新生成和新分享，界面明确已下载内容无法远程删除。
两人都同意认识后才自愿交换微信；接受申请免费。付费不能跳过对方同意。重复申请不扣第二次，屏蔽后禁止互相推荐和申请。
完整报告和文化简版明确区分，不能把日主单一关系包装为完整合盘。样例页 pages/friends-report-sample.html 为虚构结构演示，不可当作实际用户计算结果。

## 5. 推荐规则与透明解释
目标规则：先双向必要条件（成年人、目的、性别偏好、年龄范围、城市），再排序用户明示的日主/生肖偏好、共同爱好和可用时间。当前实现仅基于已公开日主/生肖、共同爱好与认识目的排序，支持城市筛选；尚不能宣传已完成双向性别/年龄偏好筛选。偏好权重可调，不以五行判定人品/财富/生育。
拒绝、屏蔽、已认识、过期/停用、未授权公开的用户排除。没有候选就说明暂无，允许扩大偏好，禁止假用户或重复凑配额。
推荐理由来自可授权展示的字段，如同城、共同活动与对方愿意认识的类型，不能暗示已验证所有资料。质量指标为双向接受与满意反馈，不以注册量或伪造的“婚姻分数”代替。

## 7. Runae报告复用与内容契约
需先核实真实后端具备双人全盘计算能力，不把现有个人报告接口当作已支持双人。排盘是确定性计算；AI只按授权结构化事实生成可读文本。
输出：输入完整性与时辰不确定提示、双方可见字段范围、传统文化关系解读、真实相处共识/差异、10话题中待确认的问题、15分钟聊天提纲、3个共同活动、下一步建议、生成时间/版本。
10方向：家庭、生育与分工；财务；未来城市与规划；冲突沟通；关系边界；亲友；过往经历（自愿）；自我认识；兴趣；生活习惯。未答=未了解，不扣“人格分”。避免从家庭结构推断人格。
每条结论标来源类别：用户回答 / 文化规则 / 待确认；全盘尚未算或缺时辰必须显式缺省。无伪造概率、100分总分、必婚/必离、子女数量/孕期预测。原始答案是否逐条互看另授权，不能用报告间接泄露。
