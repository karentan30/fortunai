内容制作指南
每篇30分钟内完成
1
打开内容文件截图
Chrome 浏览器打开 docs/social-cards-v2.html → F12 开发者工具 → 切换手机模式（375px宽）→ 截图对应卡片 → 保存为 PNG

小红书卡片（3:4比例）截图后在手机相册裁为 1080×1440px
Instagram卡片（1:1比例）截图后裁为 1080×1080px
2
复制文案 + 个人化
从 HTML 文件中复制对应文案 → 加1-2句自己的真实感受或观点（让它更像真人写的）→ 检查 CTA 链接正确
3
发布 + 第一条评论
发布后立刻在自己帖子下留第一条评论，引导用户互动：
• 小红书：「测完了吗？你的日主是什么五行？评论区告诉我 👇」
• Instagram：「이 내용 공감되는 분? 본인 일주 댓글로 알려주세요!」
4
回复评论（发布后24小时内）
所有评论都要回复，哪怕只是「谢谢你的分享！你的情况我帮你看了一下…」— 这是算法最看重的信号，决定推流量级

增长钩子
Week 3 开始加入，引爆互动 → 带动算法推流
📕 小红书增长钩子
评论区开「八字互测」：让用户留生日，你在 APP 里测完截图回给他（前10个亲自回，之后带节奏就有人自发互测）
「合婚测试」活动：留评论「两人生日 → 我帮你测合婚分数」，每次选5个公开回复，其他人围观 = 自然种草
收藏引导：「点收藏这周穿旺运色，测完八字来对号入座」
隐藏问题 trick：发一道「八字题」，答对的人评论，错的人求解 = 讨论爆发
📸 Instagram KR 증가 훅
Story 투표：「사주 믿어요? 🙋 vs 😅」→ 投票后跳转 link，自然导流
댓글 유도：「내 일주 뭔지 아세요? 생년월일 남겨주시면 알려드려요 ✨」
