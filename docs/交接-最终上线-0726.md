## 四、技术架构

### 前端
- **技术栈：** 纯HTML/CSS/JS，无框架
- **设计系统：** 深色主题 #0e0a04 + 金色 #c9a84c + 玉绿 #5bbfa0
- **字体：** Noto Serif SC + Cormorant Garamond
- **布局：** mobile-first, max-width 390px
- **动画：** 星尘粒子背景 + 毛玻璃卡片 + 金色流光 + 可折叠报告
- **文件结构：**
  ```
  shenyuan/
  ├── index.html          -- 首页（分类导航+入口）
  ├── pages/              -- 35个功能页面
  ├── assets/css/         -- 全局样式
  ├── favicon.svg         -- 网站图标
  ├── sitemap.xml         -- SEO站点地图
  ├── robots.txt          -- 爬虫规则
  └── vercel.json         -- Vercel部署配置
  ```

### 后端
- **服务器：** HK 47.242.80.65:3021
- **运行时：** Node.js (v20) + Express
- **数据库：** SQLite (better-sqlite3)
- **AI模型：** DeepSeek v4-flash（api.deepseek.com/v1）
- **支付：** Stripe（Lumee账号，sk_live_51Q4uA5...）
- **进程管理：** PM2（开机自启）
- **安全：** scrypt密码哈希 + CORS白名单 + 速率限制（60次/分钟）

### 关键系统变量（.env on server）
| 变量 | 用途 | 位置 |
|------|------|------|
| DS_KEY | DeepSeek API | /opt/shenyuan/server/.env |
| STRIPE_PAY_SECRET_KEY | Stripe支付密钥 | /opt/shenyuan/server/.env |
| STRIPE_WEBHOOK_SECRET | Stripe webhook | /opt/shenyuan/server/.env |
| FRONTEND_URL | 前端地址 | /opt/shenyuan/server/.env |
