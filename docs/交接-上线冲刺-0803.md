### 2. 服务器重构（2808行单体 → 模块化）

**改动原因**：原 `server/index.js` 超过 2800 行，维护困难，路由逻辑混杂。

**重构结果**：

```
server/
├── index.js          → 165行（入口，路由注册，静态文件）
├── lib/
│   ├── store.js      → 384行（_M 数据层，hasFullAccess，PRODUCTS）
│   ├── utils.js      → 78行（hashPassword，sendEmail，generateToken）
│   └── llm.js        → 不变（DeepSeek 封装）
├── middleware/
│   └── index.js      → 138行（rateLimitMiddleware，authMiddleware）
└── routes/
    ├── auth.js        → 85行（/api/auth/*）
    ├── payment.js     → 546行（/api/create-checkout，/api/stripe-webhook）
    ├── divination.js  → 832行（所有AI算命端点）
    ├── daily.js       → 240行（/api/daily，/api/chat，/api/chat-history）
    ├── push.js        → 71行（Web Push 通知）
    ├── admin.js       → 94行（/api/health，/api/masters）
    ├── referral.js    → 45行（/api/referral/*）
    └── ab.js          → A/B 追踪端点
```

**注意**：`web-push` 已手动安装至服务器（`npm install web-push`），已补入 package.json。
