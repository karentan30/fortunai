# 相生 校园试点调研（2026-11-06，主推北京）

**结论**：团队留长春，北京**海淀学院路**选三校：北科大＋北语＋北林。三校步行可达，北科大偏工科、北语偏文科，男女可能互补（男女比例未核实）。

**三校规模**
- 北京科技大学：本科1.40万、研究生1.39万（官网，2025-12），学院路30号
- 北京语言大学：全日制约0.98万，其中本科7045人、国际生1510人（2023-24质量报告）。国际生多，适合做“语言交换＋爱好”局
- 北京林业大学：约2万人（第三方，年份未核实）。山诺会属北林（老报道，现状未核实）

**先找的社团**（具体名称和2025-26活跃度均未核实，大使入职第一周去微信/小红书逐个确认）：北科大户外/登山协会、北科大羽毛球协会、北林山诺会、北语桌游/剧本杀社、任一校心理协会（承接MBTI）。

**大使底薪**：查不到北京公开数据，未核实。仅见一例非北京的校园大使津贴200元/月；多数岗位写“面议＋奖金”。建议先按1500–2500元/月试，这个数是估算。

**规则与风险**
- 北林规定社团“原则上不接受校外资助”；中石大规定校外合作活动须提前7个工作日报团委审批。先走“社团活动免费工具”，别谈赞助
- 校外人员入校各校不同；清华2025年通报整治违规报备。活动由学生大使组织，地点放校内
- 命理在校园可能被视为“封建迷信”（未核实），对外主打MBTI加爱好

**长春（备选）**：东北师大（约3.4万人，官网）和吉林财经都在净月大街，比较集中；吉大约7.2万人（旧数据），校区分散。可当低成本对照组，测传播。
