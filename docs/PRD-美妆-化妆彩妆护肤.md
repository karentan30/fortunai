## 1. 一句话定位 + 目标用户 + 核心痛点

**定位**：拍一张脸，10 秒给出专属彩妆步骤 + 精选高佣品推荐——比博主测评更懂你，比自己摸索更省钱。

**目标用户**：
- **核心**：18-35 岁亚洲女性（黄皮/黄调肤色），化妆经验初中级，痛点是"买错色号/不知道适合什么妆"
- **次核心**：25-45 岁注重护肤的女性，换季/年龄段跨越时有护肤焦虑
- **潜力**：海外华人（英/美/澳），对中文美妆内容有需求，TikTok Shop 覆盖

**三大核心痛点**：
1. **色号地狱**：口红/粉底千种色号，买回来不适合，浪费钱且挫败感强
2. **护肤焦虑**：不知道自己肤质、不知道成分相克，跟风买了一堆用不上
3. **妆容教程不个性化**：博主的妆容技巧针对博主脸型，看完还是不会画

## 2. 用户流程

### 主流程：拍照→分析→输出→购买

```
[入口] 首屏一键拍照 / 上传近期自拍

[AI 分析层 — Qwen-VL + MediaPipe]

  • 肤质初判（油/干/混合/敏感——通过毛孔/光泽/纹理视觉特征推断）
  • 皮肤显性问题（毛孔粗大/暗沉/痘印/细纹/黑眼圈——仅描述视觉表现）
    ↓
[输出层 A：化妆建议]（所有用户免费）
  • 适合脸型的修容/高光方向（如"颧骨打斜阴影+额头T区提亮"）
  • 眼影色系推荐（冷肤推蓝棕/暖肤推橘棕，具体色系说明）
  • 口红色号方向（含 2-3 个具体色号参考，注：价格区间标注）
  • 粉底色号选择建议（黄调/中性调/冷调 + 遮瑕力建议）
  • 完整 5 步化妆顺序（适合该脸型的步骤拆解）
    ↓
[输出层 B：护肤建议]（所有用户免费，2-3 项）
  • 肤质对应早晚护肤骨架（几步、核心成分方向）
  • 本季护肤重点提示（换季/防晒/保湿）
  • 禁忌提示（如"敏感肌避免高浓度酸类同时使用"）
    ↓
[变现层：产品推荐卡片]
  • 每个品类展示 3-5 个精选 SKU（含品牌/色号/价格/短测评语）
  • 每张卡片带联盟带货链接
  • 国内用户：抖音精选联盟 / 淘宝联盟
  • 海外用户：TikTok Shop Affiliate / 亚马逊 Associates
    ↓
[付费钩子]
  • 免费版：3 项基础分析 + 3 个产品推荐
  • 订阅版（¥19.9/月）：解锁完整 8 项分析 + 月度护肤计划 + 无限次测评 + 专属色号档案
    ↓
[复购/留存]
  • 每月重测提醒（换季/生日/旅行前）
  • 订阅用户专属"当月爆款推荐"推送（高佣 SKU 精选）
```

## 4. 变现闭环（重点·最赚钱层）

### 4.1 三层收入架构

```
第一层：联盟带货佣金（立竿见影，冷启动即可启用）
    ↓ 第二层：订阅 MRR（稳定现金流，抗周期）
         ↓ 第三层：品牌 B2B 合作（高客单，需用户量积累）
```

### 4.2 联盟带货佣金率明细

| 渠道 | 类目 | 佣金率 | 优先级 | 接入门槛 |
|------|------|--------|--------|---------|
| **抖音精选联盟** | 美妆护肤 | **20%-30%** | 国内 P0 | 抖音达人账号 + 1000 粉丝 |
| **淘宝联盟** | 美妆护肤 | 8%-20% | 国内 P1（无粉丝门槛） | 注册即用 |
| **小红书带货** | 美妆 | 10%-20% | 国内 P1 | 小红书创作者账号 |
| **TikTok Shop Affiliate** | 美妆/护肤 | **15%-30%** | 海外 P0 | TikTok Creator Marketplace |
| **亚马逊 Associates** | Luxury Beauty | 10% / 普通 3%-6% | 海外 P1 | 需要内容平台，审核 1-3 天 |

**选品策略**（影响实际佣金收入最大的杠杆）：
- 优先佣金 > 20% 的 SKU：精华/安瓶/防晒/口红/眼影盘
- 优先复购率高品类：日用护肤（洁面/精华/防晒），月均复购，30 天 cookie 内二次购算佣金
- 避免低佣标品：洗发水/沐浴露/棉签（佣金 < 5%，不值得推）
- 国货平替优先：佣金高（国货品牌通常给 20%+）+ 内容天然有"性价比"传播性

**SKU 数据库建设**：MVP 阶段手动维护 100-200 个精选高佣 SKU，按脸型/肤质/肤色标签化，每张推荐卡匹配 3-5 个。

## 6. 技术方案

### 6.1 核心 AI 技术栈（最低成本）

| 功能层 | 技术方案 | 成本 | 说明 |
|--------|---------|------|------|
| 脸型识别 | **MediaPipe FaceMesh**（开源免费）| 零 API 费 | 468 个人脸关键点，判断脸型准确率高 |
| 肤色/肤质/皮肤问题分析 | **Qwen-VL**（通义千问视觉）| 极低（图片 token 计费）| 复用现有接入，无额外接入成本 |
| 化妆建议 + 护肤建议生成 | **DeepSeek/Qwen LLM**（文本生成）| 极低 | 基于分析结果用 prompt 生成个性化建议文字 |
| 产品推荐匹配 | 规则引擎（肤质×肤色×价格段 tag 匹配）| 零 | MVP 阶段不需要推荐算法，手动标签匹配 |
| 联盟链接管理 | 静态配置 JSON + 定期人工更新 | 零 | SKU 数据库初期 100-200 条，按季度更新 |

### 6.2 单次分析成本估算

Qwen-VL 图片分析：约 1000-2000 token（含图片 token + 分析文字输出）≈ ¥0.003-0.008/次
DeepSeek 文本生成（建议文字）：约 500 token ≈ ¥0.001/次

**单次完整分析总成本 < ¥0.01**，付费用户订阅 ¥19.9/月，毛利率 > 99%。

### 6.3 技术架构要点

```
前端（H5）
  ├── 照片上传（压缩至 800px 长边，减少 token 消耗）
  ├── MediaPipe.js（前端本地运行脸型识别，零 API 费）
  └── 结果展示页（产品卡片 + 带货链接）

后端（Node.js / Python，复用 Shenyuan 现有服务器）
  ├── /api/analyze：接收照片 → 调 Qwen-VL → 提取分析维度 → 调 LLM 生成建议文字
  ├── /api/recommend：基于分析标签匹配 SKU 数据库 → 返回带联盟链接的产品列表
  └── /api/subscribe：支付接入（微信/支付宝，复用 Shenyuan 现有支付基建）

数据库（复用现有）
  ├── users 表：账号 + 订阅状态
  ├── analysis_records 表：历史测评记录（JSON 存储分析结果）
  └── sku_catalog 表：高佣 SKU 数据库（品牌/色号/价格/佣金率/联盟链接/标签）
```

### 6.4 Qwen-VL Prompt 设计要点

分析 prompt 必须：
- 明确要求输出结构化 JSON（脸型/肤色/肤质/问题各字段）
- 避免使用"诊断/疾病/治疗"等词，全用视觉描述词（"T区可见光泽反光""毛孔视觉上较明显"）
- 要求置信度字段（低置信度时提示"光线不足，建议重拍"）
- 限制输出范围（只输出可见视觉特征，不推断皮肤健康状况）

## 7. 合规红线

### 7.1 核心红线（违反可能触发监管处罚）

| 禁止措辞 | 安全替代措辞 |
|---------|------------|
| 皮肤诊断 / 诊断肤质 | 皮肤视觉分析参考 / 肤质初步参考 |
| 治疗痘痘 / 改善湿疹 | 针对痘痘肌的美妆护肤参考建议 |
| 临床级准确率 | 基于 AI 图像分析的参考结果 |
| 医学级测肤 | 美妆参考测评 |
| 对皮肤疾病有效 | （任何疾病宣称一律禁止）|
| 皮肤科医生推荐 | 建议配合专业皮肤科医生意见 |

### 7.2 页面必显免责声明

每个分析结果页顶部或底部固定展示：
> "本测评结果由 AI 视觉分析生成，仅供美妆护肤参考，不构成医疗建议。皮肤健康问题请咨询专业皮肤科医生。分析仅基于上传照片的视觉表现，准确性受拍摄光线、角度影响。"

### 7.3 数据隐私合规

| 法规 | 要求 | 实现方式 |
|------|------|---------|
| 中国《个人信息保护法》| 人脸照片属于敏感个人信息，需单独授权 | 上传前弹出明确授权弹窗，用户勾选同意 |
| GDPR（欧洲用户）| 分析后立即删除原始照片 | 服务端分析完成后 24 小时内自动删除原图，只保留分析结果 |
| CCPA（美国用户）| 告知数据用途，提供删除权 | 隐私政策页明确数据用途 + 账号注销即删除 |
| 所有地区 | 不得将人脸数据用于训练第三方模型 | 合同/服务条款明确，不向 Qwen-VL 以外提供原图 |

**借鉴 L'Oreal Skin Genius 最佳实践**：明确在结果页写"您的照片在分析完成后立即删除，不作任何储存"——这是用户信任的核心卖点，要主动打出来。

### 7.4 带货合规

- 所有带货链接必须标注"此为推广链接，点击购买我们可能获得佣金"（各平台联盟协议要求）
- 品牌合作内容必须标注"合作/广告"（中国《互联网广告管理办法》要求，小红书/抖音均有强制标注机制）
- 产品测评文案不得虚假夸大（"100% 改善"类表述违反《广告法》）

## 附：电商/增长 PM 视角挑刺——最弱 3 点 + 补法

### 弱点 1：带货 SKU 数据库是静态的，会快速过期

**问题**：美妆爆款更迭极快（季节/节日/明星同款），手动维护 100-200 条 SKU 数据库半年后会大量失效，导致推荐出不可购买的商品，佣金链接失效，用户信任受损。

**补法**：
- 接入抖音/淘宝联盟 API（均提供商品列表接口，可按类目+佣金率筛选实时有货商品）
- 每周自动拉取"美妆类目佣金 > 20% 且销量 > 1000"的商品刷新库
- 人工只做一层"黑名单过滤"（排除质量差评品牌），其余自动化
- 最终目标：SKU 库实时化，推荐的永远是当前能买到的热销高佣商品

### 弱点 2：免费流程体验好但分享动机不足，冷启动获客慢

**问题**：AI 测肤工具本身并不稀缺，美图宜肤/YouCam 都有，用户没有强烈分享动机。冷启动单靠发内容积累粉丝，速度极慢。

**补法**：
- **结果页强化"稀缺感"文案**：不是"您的肤色是冷调"，而是"您是亚洲女性里 23% 的冷白调——这些色号不适合您，这 3 个才是您的色"（数字化+专属感）
- **分享激励机制**：分享测评结果图给 3 位好友，解锁 1 个付费功能（成分自查工具）免费体验——用功能而非积分做奖励
- **结果页设计极致"可截图"**：仿小红书种草卡片风格，用户自发截图分享小红书/朋友圈就是最好的免费投放
- **与明星脸/黄金比例拉新模块联动**：前面模块做了脸型分析，直接弹"查看你脸型专属化妆建议"——内部流量漏斗打通

### 弱点 3：订阅 ¥19.9 价格点感知价值不清晰，转化率有天花板

**问题**：用户为什么要付 ¥19.9？免费版 3 项分析已经够用，完整 8 项分析是"要更多数据"而非"要解决一个迫切问题"，价值感不强。

**补法**：
- **重新定义订阅价值**：从"完整报告"改成"每月帮你省 X 元"——订阅用户每月推送"本月最佳高佣好物"，强调"¥19.9 订阅费换来你用推荐链接购买节省 ¥X 的差价"（买一支精华省下的差价可能远超订阅费）
- **年度账单感知**：订阅 1 年展示"累计为你分析 X 次 / 推荐帮你省 ¥X"，让数字说话
- **加一个"订阅才解锁"的强欲望点**：比如"口红色号档案（可保存/可分享）"——女生会为保存和展示自己的专属色号付钱；或者"护肤黑名单（你买过但不适合你的成分）"——有高度个性化价值
- **试用降低门槛**：7 天免费试用完整订阅功能，再转付费；美图宜肤、YouCam 均采用此模式，是最有效的订阅转化路径
