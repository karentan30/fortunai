## 🎯 核心机制（四层金字塔）

### 第一层：邀请激励模型（用户→新用户）

#### 邀请链接结构

```
基础邀请链接：https://shenyuan.mylumee.cn/?ref=USER_ID&name=用户昵称
- ref: 邀请者用户 ID
- name: 邀请者显示昵称（为被邀人显示"张三邀请你"）

长链接（二维码）：
https://shenyuan.mylumee.cn/?ref=USER_ID&campaign=birthday&utm_source=wechat&utm_medium=share

前端解析：
- 读 ref 参数 → localStorage 存储 'invited_by': USER_ID
- 首页显示"张三邀请你来查八字"
- 后端：新用户付费时记录 invited_by 关系
```

#### 返佣与激励梯度

**方案 A：现金返佣（简单快速）** ← 推荐第一版

| 阶段 | 邀请数 | 激励 | 形式 | 说明 |
|---|---|---|---|---|
| 起步 | 1 | ¥5 / 人 | 微信/支付宝 | 每邀请 1 个付费用户得 ¥5 |
| 成长 | 3 | ¥3/人 × 3 = ¥9 + 免费 1 月 | 返佣 + 订阅赠送 | 邀请 3 人解锁"邀请伙伴"标签 |
| 加速 | 10 | ¥2/人 × 10 + ¥50 代金券 | 返佣 + 电商券 | 邀请 10 人可分享 ¥50 代金券×5 张给好友 |
| 顶级 | 50+ | "命理合作师"身份 + 25% 分成 | 身份 + 长期分成 | 邀请 50 人成为官方"认证合作命理师"（展示头部、获得 25% 平台分成） |

**方案 B：订阅赠送（降低现金成本）** ← 精准用户选择

| 邀请数 | 激励 |
|---|---|
| 3 人 | 免费使用 1 个月会员（订阅报告无限） |
| 5 人 | 免费 3 个月 + 限定头像框 |
| 10+ 人 | "邀请王"身份 + 全年免费会员 + 每月 ¥50 代金券 |

**建议采用混合方案**：
- 小用户（1-3 人）：现金 ¥5/人（转化主力）
- 中用户（3-10 人）：现金 ¥3/人 + 订阅赠送（激励升级）
- 大用户（10-50+ 人）：25% 分成 + 身份激励（打造内容联盟）

#### 支付流程（返佣提现）

```
用户邀请 3 人付费后：
1. 后端计算 Total Earned = ¥15（5×3）
2. 用户进入"我的邀请"页 → 显示"可提现: ¥15"
3. 点"提现"→ 输入微信/支付宝账号 → 后端发起提现申请
4. 管理员后台审核 → 发起转账（使用 Stripe Connect 或 企业转账 API）
5. 7 天内到账（微信/支付宝）

数据存储：
- users 表：add invited_by_count（邀请成功数）
- referrals 表：(referrer_id, referred_id, status, earned_amount, payout_status)
- payouts 表：(user_id, amount, payment_method, status, created_at)
```

## ⚠️ 风险及防控

### 风险 1：滥用邀请系统（刷单）

**症状**：某用户创建多个马甲账号自邀自付
**防控**：
- [ ] 同设备 max 3 个账号邀请关系
- [ ] 同支付卡 max 5 个账号邀请关系
- [ ] 72h 内大量邀请（>20 人）需人工审核
- [ ] 邀请者和被邀人的支付信息交叉验证

### 风险 2：返佣成本失控

**症状**：邀请链接口碑传播，邀请成本超预期
**防控**：
- [ ] 邀请返佣设置上限：每用户年度 max ¥500（50 人）
- [ ] K 因子监控：若 >1.8 则降档返佣（¥5 → ¥3）
- [ ] 成本预算月度 cap：¥10,000（超出则人工审批）

### 风险 3：邀请排行榜作弊

**症状**：用户刷屏排行、虚假数字
**防控**：
- [ ] 排行榜只显示"已支付完成"邀请
- [ ] 排行榜每周更新 1 次（不实时）
- [ ] 审计机制：CTO 月度检查 Top 20 用户的邀请质量

### 风险 4：社交平台封禁

**症状**：小红书/TikTok 视为垃圾营销内容
**防控**：
- [ ] 内容质量优先（9+ 分才发）
- [ ] 频率控制：3x/周（不超日均 1 条）
- [ ] 避免硬广：用户故事为主（80% UGC）
- [ ] 品牌账号独立（不依赖单一账号）
