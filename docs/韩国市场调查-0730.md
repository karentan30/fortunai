# 善缘 · 韩国算命/사주市场深度调查（0730）

> 出海韩国"第二城"决策依据。数据带来源。一句话：值得做，但打法要改（引擎同源、需深度本地化、祭祀线不上）。

## 1. 市场规模（值得做）
- 市场 **$3.7B / 约4-4.7万亿韩元**（含现金交易实际更高；线上可统计口径 InnoForest 2024 = 1.4万亿韩元）
- **66-70% 国民每年至少算一次命**；20-30代兴趣最高（青少年71.5%）
- 注册命理商户 10,950 家（2024，较2021+21%）；人均终身消费约 $370
- 增速：점신 2024营收+58%、포스텔러 MAU YoY+28%。规模已超韩国 webtoon 出口、碾压本土票房。
- 来源：Seoulz（superstition-economy / saju-industry）、Hankyung、EPNC、Seoul Economic Daily

## 3. 用户与季节
- 主力 **25-40岁女性**；MZ增长最快。动机=就业/住房焦虑下的**自我安抚**（非真信命）→ 语气要安抚+自我反思，不吓唬。
- 场景：恋爱结婚（궁합）/求职/人生转折。궁합是约会活动=天然社交传播。
- **季节峰：신년운세（新年运势）12月-2月最大（+20%用量）** / 수능高考11月 / 婚季。→ **必须12月前上线吃신년운세第一波**。
- 价格带：线下사주3-5万韩元·情侣궁합5-10万·真人5-30万；**AI사주~8000·AI궁합~$3**（AI把价打到冲动消费带）。
