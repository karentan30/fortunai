### 2. SSE 流式输出修复 — Caddy gzip 缓冲问题

**根本原因**：Caddy 的 `encode gzip` 设置会缓冲 SSE 响应，导致报告一大块一大块输出，而非逐字流式。

**修复方案**（已应用到三个域名的 Caddy 配置）：
```caddy
# 修改前
encode gzip

# 修改后  
@not_stream {
  not path /api/*/stream
}
encode @not_stream gzip
```

**效果**：现在所有流式报告真正逐字输出（已验证吠陀占星每个字单独 SSE 事件）。

### 3. 风水页面 v2 升级 — 家庭命卦 + 图片上传 + 具体摆件

**新增功能**：

**A. 家庭成员命卦分析**
- 户主（必填）+ 最多 5 位家庭成员
- 字段：称呼/性别/出生年（1920-2026）/月/日
- 客户端自动计算命卦：`calcMingua(birthYear, gender)` → 命卦数字 + 卦名 + 东/西四命
- 传给服务器的数据格式：`{ role, dob, gender, mingua, group }`

**命卦计算逻辑**（客户端 JS）：
```js
function calcMingua(birthYear, gender) {
  var n = birthYear;
  while (n >= 10) { var s=0,t=n; while(t>0){s+=t%10;t=Math.floor(t/10);} n=s; }
  var q = gender==='M' ? (10-n) : (n+5);
  if (q===5) q = gender==='M' ? 2 : 8;
  if (q>9) q -= 9;
  return q; // 1=坎 2=坤 3=震 4=巽 6=乾 7=兑 8=艮 9=离
}
// 东四命: 1,3,4,9 | 西四命: 2,5,6,7,8
```

**B. 图片上传**（可选，折叠式）
- 户型图：单张，base64 传给服务器
- 房间照片：最多 3 张，base64 数组
- AI 分析上传的图片（穿堂风/卫生间居中等格局问题）
