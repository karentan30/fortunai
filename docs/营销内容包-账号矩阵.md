统一格式：`SY_[账号号]_[桶]_[类型]_[主题]_[版本]_[日期]`

### 5.4 数据追踪（每周复盘看这些）

**每篇必记**：曝光 / 点赞 / 收藏 / 评论 / 分享 / 主页点击 / 涨粉。
**分桶看北极星**：
- 账号①③（引爆引流）→ 看**涨粉 + 分享率 + 导流点击**（CAC健康度）
- 账号②（承接变现）→ 看**收藏率 + 私信/付费问答转化**（收藏是内容价值信号）
- 账号④（季节冲量）→ 看**旺季下单量 + 客单价 + 内容→下单转化**
- 全局→ **邀请码带来的注册数**（裂变K因子，接已建的 share-card/invite）

**红牌指标**：任何一篇出现"焦虑/被吓到/像迷信"类差评立即下架复盘（红线守护）。

### 5.5 爆款复制流程（5步）

1. **抓爆款**：任一篇 收藏率>10% 或 分享>50 或 涨粉异常，标记为种子。
2. **拆结构**：拆它的钩子（前3秒/标题）+ 情绪点 + 互动引导，写成一句话公式。
3. **换壳复用**：同公式换主题批量产3-5条（如"复合3问"火→出"分手3问""表白3问"）。
4. **跨号迁移**：验证过的钩子迁到其他号适配（before/after公式→节气号的"墓地荒→修葺后"对比）。
5. **投放放大**：稳定跑出的爆款，**仅在旺季（12-2月运势季/清明中元）**加低成本DOU+/信息流放大，淡季靠自然流。
