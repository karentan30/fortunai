## 决策 #3: 韓國支付渠道 (选一个主力)

**背景**: Q4 季节峰推送·支付链路必须 OK。每天延1天 = ¥3K 损失。

### 三大渠道对比

```
选项 A: INICIS (推荐·市场占有率 40%)
  优: 最广泛·老牌·支持所有 BIZ 模式
  劣: 手续费 2.5-3.5%（较高）
  集成难度: 中等·有示例代码
  Karen 网: 无（Slim 用 Airwallex）

  优: 年轻用户最爱·一键支付快
  劣: 手续费 2.9%·初创企业审核慢（2-4周）
  集成难度: 容易·SDK 现成
  Karen 网: 无

  优: 支持 One-Time 和 Subscribe
  劣: 要求 Naver Store ID（复杂）
  集成难度: 难·文档韩文
  Karen 网: 无

```

⚡ 其次: KakaoPay (年轻用户重)
   理由: 转化率可能更高
   风险: 审核期长（立即申请）
