## 4. 规则（已和 Karen 定）
- **目的**：找搭子 / 交朋友·闺蜜 / 享受恋爱 / 认真结婚，可多选。交友卡显示本人公开的全部字段，不按目的筛。
- **默认公开**：基础项公开；收入、资产、房、车、户口默认仅自己。
- **未注册的人**：能刷到所有公开日主的人，只看到 日主、年龄段、城市、公开的类型和爱好；看不到名字、照片、微信、学校、收入。无开关。人少时用标明「虚构示例」的卡补，**绝不编人数和好评**。
- **相亲页**：登录才能看；照片、语音、家庭背景、想法标签互相认识后才可见。
- **核验 / 婚况**：人工审，审完删原件；结果只有会员可见；不写「自述」。
- **图鉴**：双方都接受认识才点亮；对方隐藏的属性不算；分享图只有类型和数量。
