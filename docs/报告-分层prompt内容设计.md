## A. 统一分层框架（对应定价阶梯）

四档分层从上到下依次开放更多维度。每档的共同结构规律：

```
温暖共鸣段（让用户觉得"被看见"）
→ 基于真实引擎数据的精准命中（具体数字/符文/星位/卦象注入，禁 AI 自算）
→ 可落地建议（具体年份/颜色/方位/物品，粒度细到可执行）
→ 结尾变现区（诚实推荐开运物/深度报告/旗舰套餐）
```

| 档位 | 别名 | 字数目标 | 内容边界 | 结尾规则 |
|------|------|----------|----------|----------|
| 免费预览 | basic / free | 500–800字 | 命盘/抽签结果展示 + 1-2 维度共鸣段 + 今年运势一段话 | 输出 `---LOCKED---` 后列出被锁章节名，引导付费 |
| $9.9 标准 | standard | ~2500字 | 核心 3-5 维度（财/情/事各一，年度流年，一段开运锦囊） | 结尾提 $49 完整版含哪些维度，1-2 句推荐 |
| $49 完整 | full | ~1万字 | 全维度（参照八字 16 维范式，各方法映射见下文） | 结尾推 $99 旗舰（多法合并印证） |
| $99 旗舰 | vip | ~1.5万字+ | $49 全维度 + 多方法交叉印证综述 + 逐月流月（24个月）+ 90天行动计划 | 无销售结尾，改为"命理师/占师终身叮嘱" |

### 免费预览通用句式（各方法共用 SYSTEM 后缀）

```
【免费版输出约束】
本次仅输出前 [N] 个维度（约 [字数]字）。
完成后输出一行：---LOCKED---
然后紧接着列出被锁维度（格式：💰 财运深度分析 · 完整版解锁），不展开内容。
结尾一行温暖引导："想看完整解读，点击解锁——[本方法的最值钱角度一句话钩子]。"
```

### 合规声明（每档报告尾部必须注入）

```
本报告由 AI 辅助生成，仅供参考娱乐，不构成医学、法律、投资或人生重大决策建议。
健康章节均为养生角度，非医疗诊断，如有健康疑虑请咨询专业医生。
```

## B. 各方法内容维度 + 分层设计 + Prompt 草稿

> **约定**：
> - `{ENGINE_BLOCK}` = 后端精确排盘/抽签结果注入块（模板变量，工程写入，LLM 禁自算）
> - `{QUESTION}` = 用户问题 / 关注点
> - `{LOCK_SUFFIX}` = 免费版锁定后缀（见 A 节）
> - 各 SYSTEM 末尾统一加合规声明指令
> - 语言默认中文；英文版在 SYSTEM 末尾加 `Output this report in fluent English.`

## D. 设计原则总结（写进每个 Prompt 的通用约束）

每个方法的 SYSTEM prompt 必须包含以下模块（顺序可调）：

1. **身份锚定**：方法传承、资历、语气风格定义
2. **数据约束**（关键）：`基于上方精确引擎数据，禁 AI 自算` — 对应具体注入块变量名
3. **输出格式**：Markdown / 总字数 / 各维度最低字数 / 标题格式
4. **健康章节软化**：按脏腑养生角度，禁点西医病名，不恐吓
5. **合规尾注**：娱乐参考免责声明 + 不替代医学/法律/投资建议
6. **语言声明**：中文默认；`lang=en` 时在 SYSTEM 末尾加 `Output this report in fluent English.`

**变现结尾通用模板**（标准档 $9.9 结尾）：
```
想看完整版深度报告？$49 完整版包含：[本方法全维度清单3条]。点击解锁，只需一杯咖啡的价格。
```

**结构顺序铁律（所有方法共用）**：
```
① 温暖共鸣（让用户觉得"被看见"）
② 精准命中（基于真实数据，含具体年份/数字）
③ 可落地建议（颜色/方位/时间/物品，当天可执行）
④ 变现区（诚实推荐，不夸大，不打包票）
```
