## 一、怎么不赔钱（单位经济 · 核心）

**一句话：只要不烧付费广告、堵住免费生成漏洞，单份报告毛利 ~80%+，天然不赔钱。产品是软件边际成本，赔钱只会赔在两处——① 无节制的免费AI生成 ② 亏本买量。**

### 成本结构（每份付费报告）
- 主成本 = 一次 LLM 生成（DeepSeek，深度报告约 8k tokens 输出）≈ **¥0.1–0.3 / 份**
- 图片（如出命理配图）= 最大变量，GPT-image/火山按张计费 → **付费墙内才生成**，免费层不出图
- 收款手续费 Stripe ~3% + 微信/支付宝 ~0.6%
- 服务器 = 固定成本（HK 一台已在跑，摊薄可忽略）

→ 定价 $9.90 / ¥19.9，毛利率 **80%+**。基本盘稳。

### 三个"漏钱洞"必须堵（否则赔钱）
1. **免费层无限调用 AI**：免费八字/每日天机若不限次 = 白送算力。
   - 对策：免费层每设备/每日限 1–2 次真生成（localStorage + 服务端 userId 双限）；重复请求走缓存不重新生成。
2. **无鉴权的生成接口**（历史地雷 `/api/generate-bg`）：任何人可直接 curl 烧图。
   - 对策：所有生成类接口加鉴权 + 频率限制 + 只在付费态触发。**上线前必查**。
3. **付费内容进 DOM 被白嫖**：报告全文若前端已下发只是 CSS 遮罩 → 扒源码即得。
   - 对策：付费正文服务端鉴权后才下发，不进未付费用户的 DOM。

### 免费→付费的"不赔钱"配比
- 免费给"**够爽但不够用**"：命格总论 + 五行 + 今年运势（钩子），足够种草、不足以替代付费。
- 付费才给：逐年流年、财官详批、择日、配图、合婚全文。
- 这样免费生成成本被"高转化"摊薄，不会因白嫖亏损。

## 二、怎么做广告不赔钱

**先说结论：现阶段（转化路径未跑通、无 LTV 数据）不要投付费广告。分发先用内容/SEO/裂变把 CAC≈0 的口子跑出量，等有了"每付费用户价值(LTV)"再考虑小额投放。**

### 为什么先别投
- **合规墙**：占星/命理在 Meta、TikTok 广告政策里属敏感类目，账号易被封、审核难过（TikTok 明确限制占卜/超自然承诺类投放）。硬投 = 烧钱+封号。
- **没有 LTV 就没有出价上限**：不知道一个付费用户值多少钱，就没法判断 CPA 多少算赚。盲投必赔。
- 参考记忆：婚恋/减脂买量都被合规堵死过——同一坑别再踩。

### 真要投，"不赔钱"的铁律
1. **先建 LTV**：先靠自然流量攒够数据，算出「每访客价值 = 付费率 × 客单价 + 复购/订阅」。只有当 **可承受CPA = LTV × 安全系数(0.3–0.5)** 时才开投。
2. **小额分渠道测**：每渠道 $20–50/天，跑 3–5 天，只看**注册成本 / 付费成本**，不看点击。
3. **硬性 Kill 规则**：单渠道付费CPA > 客单价 → 立即关。ROAS < 1（花的比赚的多）连续2天 → 关。
4. **落地页对齐**：广告说什么，落地页第一屏就给什么（免费八字）——不对齐=白烧。
5. **先再营销后拉新**：对已访问未付费的人做低成本 retargeting，比冷启拉新 ROI 高得多。
6. **别投倒计时/夸张承诺**：既违规又伤信任（已在报告页把假倒计时改真实）。

### 更省的替代（CAC 近 0）
- SEO/AEO（"free bazi reading" 零竞争，可被 AI 搜索引用）
- 小红书/TikTok 自然内容（脚本已备）
- 产品内裂变（见下）
→ 详见 `分发playbook-Runae.md`。

**核心：让"免费结果"本身就是最好的传播物——用户为了炫耀/自我认同而自发转发。**

### 最强 3 个分享钩子（已部分接线）
1. **日主命格卡**「我是甲木日主」一句话身份卡 → 自我认同最强，天然截图分享。

## 五、续费 / 留存到 10 分

**核心：先靠"每日粘性"让人回来，再靠"会员价值感"让人续。**

### 每日粘性（让人回来）——详见 retention 设计文档
- **个性化今日天机**：按用户真实八字+当日干支，客户端确定性生成"私人今日能量卡"（零API成本）。
- **连击 streak + 断签提醒**（Duolingo 式损失厌恶）。⚠️ 已修服务端 streak 的 IP 污染 bug（匿名用户不再互相串数据）。
- **明日预览模糊钩子** + **命理日记批注**（"今天验证了吗"）形成数据锁定。
- 待建：回访自动加载生辰（localStorage）→ 免重输，D2 留存预期从 ~5% → 35%+。**最高 ROI，优先做**。

### 会员续费（让人续）
- **价值感**（已改首页会员卡）：从"单次$9.90 vs 会员$9.90"（同数字困惑）→ "全品类不限次·每月无限畅算·比单次更划算·随时取消"。
- 待建到10：
  - [ ] **续费前价值回顾**：到期前推"你这月用了N次，省了$X"。
  - [ ] **Dunning/掉单挽回**：扣款失败自动重试 + 提醒（涉外 Stripe / 国内代扣资质待申请，先做提醒）。
  - [ ] **Win-back**：流失用户 7/30 天召回（邮件/站内），给"回来礼"。
  - [ ] **年费锚点**：$49/年 vs $9.9×12=$118.8，突出省钱（已有 upsell 弹窗，接实）。
