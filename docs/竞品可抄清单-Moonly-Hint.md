# 竞品可抄清单：Moonly + Hint/Nebula → Runae 落地版

> 研究日期：2026-08-18
> 研究对象：Moonly（月相·冥想·灵性日历）、Hint（真人占星师聊天）、Nebula（AI+真人·$700K/月）
> 参考背景：Co-Star、The Pattern、CHANI、Sanctuary
> Runae 现有资产：八字/占星/塔罗命盘引擎、Agora 真人连麦、$29/$59/$99 报告定价、海外华人受众

## 1. 每日 Engagement：月相·运势·仪式·推送

### 它们怎么做

**Moonly（日活钩子最强）**
- App 启动首屏直接显示当日月相图（不需登录）→ 当日能量提示（"满月扩张期，宜收尾，忌冲动决策"）
- 每日个性化：基于出生图的日运 + 宜忌提醒 + 当日手工/仪式建议
- 推送策略：早晨仪式提醒（用户自定时间）+ 月相变化前24小时提醒 + 冥想完成鼓励
- 内容层次：免费用户看月相日历 + 通用能量；付费看基于出生图的「今日专属建议」
- 连接功能：内置"梦境记录"→ 每日回访入口（写梦→AI解梦→生成专属图片）
- 22步 onboarding 后第一天就有完整仪式感内容可消费

**Nebula（$700K/月·内容钩子）**
- 每日免费：星座日运（通用，按太阳星座）
- 付费每日：基于完整出生图的专属运势 + 塔罗 + 掌纹
- 关键机制：每日内容仅24小时有效 → 制造"今天不看就过了"的稀缺感
- 月亮相位（新月/满月/逆行）推送 → 高打开率事件钩子

**Hint（人的温度）**
- 没有每日自动内容——用户需要主动发消息给占星师
- 弱点：没有被动 engagement，依赖用户自驱

### Runae 可抄什么（具体落地）

1. **"今日八字能量"首屏卡片**：用户打开 App 首页第一眼就是今日日干支+月相+当日五行能量分析（不需要点击任何东西）。格式：「今日 甲子日 · 新月 · 水旺」→ 宜：签约/学习 · 忌：动工/争论。免费用户看通用版，付费用户看基于个人命盘的专属版。
2. **月相推送节点**：每次新月/满月前24小时推送「[你的日主]逢新月，[具体影响]——明天是关键转化点」→ 打开率远高于通用推送。
3. **每日宜忌卡片分享**：生成一张精致的「今日宜忌」图（竖版，小红书友好），底部带 Runae logo。免费给用户当素材 → 裂变。
4. **梦境/日记入口**：在每日内容页下方加「今日记录」→ 文字框（"今天你的直觉是什么？"）→ 沉淀用户数据 + 增加留存。

**优先级：P0**（成本极低，只需命理引擎 API 调用 + 推送服务）

## 2. Onboarding：抓生辰 + 建期待 + 第一次 aha

### 它们怎么做

**Moonly（22步·行业最长但转化率最高）**
- 步骤：选择人生目标方向（6选1：人生目的/感情/财富/决策/平衡/精通）→ 输入姓名 → 出生日期 → 出生时间 → 出生地点 → 西洋星座揭示 → **关键时刻：同时揭示 Vedic 星座（和西洋不同！）→ 制造惊喜感** → 展示命盘亮点片段（遮罩，引起好奇）→ 付费墙
- 心理设计：每一步都"给一点信息" → 用户越填越好奇 → 到付费墙时已投入22步的注意力
- Paywall 位置：Onboarding 结束后立即出现 → 贡献 80% 的订阅
- 首次 aha：「你的西洋星座是处女，但你的 Vedic 星座是狮子——这解释了为什么你常常不像典型处女座」

**Nebula（情感切入·6步）**
- 步骤：选择关注领域（爱情/事业/灵性）→ 出生信息 → 展示"专属"命盘片段（大幅遮罩）→ 3天免费试用引导 → 付费
- 第一个 aha：看到命盘但被遮住 → 悬念 → 立即付费欲望

**Hint（6步·$0.52 入场）**
- 步骤：填写出生信息 → 选择困扰领域（感情/事业/自我/家庭）→ 承诺「我们已找到最适合你的占星师」→ 展示匹配占星师简介 → $0.52 试用付费入口 → 第一条占星师消息到达
- 第一个 aha：**真人占星师在10分钟内给你发了第一条个性化消息** → 超预期体验 → 情感投入形成

**CHANI（9步·仪式感最强）**
- 用主题插画替代枯燥表单（生日蛋糕插画选日期/猫咪和时钟选时间）→ 填数据变成"游戏"
- 数据收集完成后立刻给用户一个可探索的完整界面（而非马上付费墙）

### Runae 可抄什么

1. **"双命盘揭示"aha 时刻**：Runae 同时做西方占星 + 八字（东方）的核心优势。Onboarding 结尾设计一个高潮：「你的太阳星座是 [X]，但你的日主是 [Y]——东西方命理都在说同一件事：[核心特质]」→ 这是独家 aha，任何单一体系的对手都做不到。
2. **Onboarding 选关注领域放第一步**（学 Nebula/Hint）：不要上来就让填数据，先问「你最近在纠结什么？」→ 感情/事业/财运/家庭/健康/人生方向 → 整个体验聚焦在这个痛点上 → 后续报告围绕此主题展开。
3. **进度感设计**（学 Moonly）：每填一步给一个小反馈（「[名字]，你的月亮在天蝎——稍后告诉你这意味着什么」），让用户感觉越填越值钱，到付费墙时不舍得放弃。
4. **Paywall 时机**：命盘展示 + 关键结论（精华部分遮罩，"查看完整解读"）→ 比上来就付费转化高得多。
5. **$0.xx 试用门槛**（学 Hint）：真人大师服务不要一上来就 $99，设 $0.99 「体验一问」门槛 → 降低首次心理阻力 → 进来后情感投入 → 升级到完整档。

**优先级：P0（Onboarding 是最值得投入的单个改动）**

## 4. 真人/Chat：印钞机设计

### 它们怎么做

**Nebula（规模最大·1000+占星师）**
- 商业模式：用订阅吸引流量 → 订阅不含真人服务 → 真人按分钟另计 → 双重收入
- 定价：$2-$4/分钟（每个占星师自设价格）
- 获客钩子：新用户前3分钟免费（可体验3位不同占星师）
- 为什么有效：用户先发现自己"喜欢"某个占星师的风格 → 情感依附 → 不在乎每分钟费用
- 平台机制：占星师个人主页（年资/评分/擅长领域/用户评价）→ 用户自主选择 → 建立信任
- 离线消息：占星师不在线时可发消息 → 48小时内回复 → 维持关系

**Hint（情感陪伴模型）**
- 商业模式：月订阅 $29.99 → 无限制文字聊天真人占星师（非按分钟）
- 核心差异：Hint 的占星师被训练成"情感翻译者"而不是"预测者"——重点是让用户感觉被理解
- 为什么粘：用户说「我的占星师以一种我没想到的方式说出了我的感受」→ 人情 → 不想走
- 成本控制：占星师可能同时服务多个用户（异步文字）→ 边际成本低

**Sanctuary（Hint 的变体）**
- 订阅 + 按分钟双轨 → 但边界模糊导致用户混淆计费

**Moonly（AI"占星师"）**
- Luna AI：AI 驱动的即时问答 → 付费会员可用 → 不是真人但24/7可用
- 在 Onboarding 中强调"与你的私人占星师对话" → 降低真人高成本同时保留概念

### Runae 怎么做成印钞机（Agora 连麦已有）

Runae 已有 Agora 真人连麦引擎 → 这是最大未开发资产。

**设计方案（低成本快速验证）：**

1. **分级定价漏斗**：
   - 入口：$0.99「体验一问」（文字，真人大师回复，48小时内）→ 最低门槛
   - 中档：$29「文字深度咨询」（双向3轮，异步，24小时）
   - 旗舰：$99「30分钟视频连麦」（Agora 实时）→ 提前预约制

2. **大师主页设计**（参考 Nebula）：
   - 每位大师：简介照片（不用暴露真实长相，可水墨画风格）+ 擅长领域 + 服务次数 + 5条用户评价
   - 让用户选大师，不是平台指派 → 提高归属感

3. **情感转化钩子**：命盘生成后自动弹出「[大师名]已看过你的命盘，他想和你说一件事——」→ 激活好奇心 → 引导到咨询购买

4. **供给侧**（如何找到大师）：
   - 初期：5-10位签约华人命理师（兼职，按单结算）
   - 中期：开放申请，Runae 培训+认证体系 → 规模化

5. **为什么不直接做真人连麦主播平台**：高人汇/如意等已做且利润薄（抽佣40-50%）。Runae 的差异点是**命盘数据做预热**——用户带着自己的命盘去找大师，大师不用从零开始问，每分钟价值密度高 → 支撑更高客单价。

**优先级：P1（需要招募大师供给，但 Agora 引擎现成，3-4周可上线）**

## 5. 裂变/社交

### 它们怎么做

**Co-Star（裂变鼻祖）**
- 核心机制：加好友 → 看两人命盘叠加图 → 「今天你们在 [X] 方面有冲突，在 [Y] 方面和谐」→ 天天回来看
- 文化梗：「What's your Co-Star?」成为了「你是什么星座？」的2.0版本
- 传播路径：截图分享到 IG/TikTok → 引发跟风 → 新用户下载
- 现状：Co-Star 2026 年把好友功能放进付费墙，引发大量用户抱怨

**Nebula（内容裂变）**
- 分享兼容性报告 → 生成好看的图片 → 发社交媒体
- TikTok 投放钩子：「Did you know your Venus sign affects [具体痛点]?」→ 高 CTR
- 没有强社交功能，靠内容质量的口碑传播

**Moonly（梦境图裂变）**
- 梦境解读生成 AI 艺术图 → 高度个性化 + 好看 → 天然分享素材
- 月相日历截图分享 → 简单但有效

### Runae 可抄什么

1. **"合盘"就是裂变炸弹**（参考 Co-Star）：
   - 功能：两个人输入各自生辰 → 生成「东西合断合盘报告」（八字合婚 + 星盘 synastry 双分析）
   - 免费给：合盘总评分（5颗星）+ 3个亮点（遮住负面）
   - 付费给：完整合盘分析 + 改善建议
   - 裂变：「我和朋友测了合盘，结果……」→ 朋友好奇 → 下载

2. **每日宜忌图自动生成**：
   - 格式：今日 + 用户姓名/生肖 + 宜忌 + 月相 → 精美竖版图
   - 底部固定：Runae logo + 二维码 → 零成本品牌曝光

3. **"今日命运对比"**：同日主/同星座的人今天有什么共同挑战 → 生成「[X日主]族今日特别提醒」→ 群发到微信群/朋友圈的理由

4. **邀请机制**：邀请一位朋友 → 双方各得一次免费合盘分析（成本：API 调用；价值感：$29报告）

**优先级：P1（合盘裂变是技术难度最低、增长潜力最高的单个功能）**

## 6. UI/UX/情感设计

### 它们怎么做

**Moonly（暗色·神秘感·有机质感）**
- 配色：深紫/靛蓝/烟灰底色 + 月亮金色光效
- 插图风格：水彩星图 + 手绘宇宙感
- 语气：「你今天的能量比昨天更清晰了」→ 成长型语气，而非审判型
- 仪式感设计：每次冥想结束有呼吸动画 + 完成祝贺 → 小成就感
- 梦境 AI 图：每人每次不同 → 让用户感到独特

**CHANI（高端·政治正确·设计感）**
- 拼贴画风格 UI（像艺术杂志）
- 用主题插画替代枯燥表单（生日蛋糕/猫咪时钟）→ 降低填资料的厌恶感
- 月运/周运/年运三个时间维度 → 内容密度大但不乱
- 评分：4.9分，$500K/月收入 → 最高品质感

**Nebula（流畅·主流·略廉价）**
- 5个 Tab：星运/占星师/相性/聊天/解读 → 清晰分区
- 「选你自己的冒险」感 → 可以探索命盘任意细节
- 弱点：Android 评分 2.3分，UI 一致性问题

**Hint（极简·干净·人情温度）**
- 白底 + 简单图标 → 强调"真人"感（反衬竞品的过度设计）
- 占星师照片作为主视觉 → 建立人际感

### Runae 可抄什么

1. **"宣纸山水"风格**（Runae 独有差异点）：已有山水底图管线 → 在 UI 整体延续毛笔/宣纸/水墨元素 → 和西方灵性 App 彻底区隔，东方感即护城河。

2. **仪式感微交互**：
   - 命盘加载时：缓缓旋转的星盘动画（而不是普通进度条）
   - 报告解锁时："印章落下"的音效+动画
   - 每日宜忌卡片：日出时间刷新，错过的变灰（稀缺感）

3. **语气改造**（从功能描述 → 命运陪伴）：
   - 当前感：「您的报告已生成」
   - 目标感：「你今年有一段命理师专门标注的时间窗口。」
   - 当前感：「查看流年分析」
   - 目标感：「你2026年的节点，命理师画了红圈。」

4. **用户化名/角色感**：参考 Moonly 的「Luna」AI占星师角色 → Runae 可以有一个具名角色（如"玄机"）作为每日运势播报人格，而不是"系统消息"

**优先级：P1（语气改造成本最低，今天就能改）**

## 8. Retention：让人天天回来 + 续费

### 它们怎么做

**Moonly（日活设计最强）**
- 仪式感内容每日刷新（新月/满月/节气有特别版本）→ 制造"今天不一样"感
- 冥想完成记录 → 内隐 streak（没有显式数字，但有积累感）
- 梦境记录 → 用户沉淀自己的数据 → 越用越舍不得走
- 年度回顾功能（12月推出）→ 激活沉默用户

**Nebula（关系粘性）**
- 找到喜欢的占星师 → 建立"我的占星师"概念 → 品牌忠诚转移到个人关系
- 订阅积分余额心理 → "余额还有20积分，要用掉"

**Hint（情感依附）**
- 用户描述：「我开始把 Hint 的占星师当成可以倾诉的对象」
- 低成本产生的高粘性：异步文字 → 占星师"每天都在等你的消息"感

**通用最佳实践**
- 节点推送（满月/新月/逆行/节气）→ 不得不打开的理由
- 限时内容（24小时有效的每日运势）→ FOMO
- 年度续费优惠（续费前30天提醒 → 「你还有 [X] 个重要命运节点在年底，续费不要错过」）

### Runae 可抄什么

1. **中国节气 + 月相双日历**：八节二十四气 + 新月满月 → 每月至少10个推送节点，每个都有命理解读。海外华人特别有共鸣（离家越远越想抓住传统时间感）。
2. **用户命历（我的星迹）**：积累用户在 Runae 的咨询记录/报告/宜忌记录 → 年度回顾 → 让数据成为迁移成本。
3. **续费情感钩子**（而不是优惠码）：「你的2027年有3个命理师标注的重要转折——你的会员到期后将无法接收提醒。」→ 比"续费享8折"更有推力。
4. **「我的命理师」功能**：用户可以收藏特定大师 → 下次直接找他 → 建立关系 → 流失率下降。

**优先级：P1（推送节点设计今天就能启动）**

## Top 5 最该立刻抄（低成本·高ROI·结合 Runae 现有资产）

---

### #1. 改付费墙文案：从"功能锁定"→"情感悬念锁定"

**为什么是第一**：不改一行代码，只改文字，Moonly 案例显示 paywall 设计改动可带来 +39% 转化。
**落地方案**：把所有「解锁完整报告」「查看全部章节」改成基于用户命盘数据的个性化悬念句。模板：「你的[日主/命宫/流年]里有一个[关键词]——命理师专门标注了。」今天就能改，明天就能上线。
**预期效果**：付费转化率 +20-40%

---

### #2. Onboarding 加"双命盘揭示"aha 时刻

**为什么是第二**：Runae 东西合断是独家优势，却没有在 Onboarding 中利用。Moonly 用「Vedic vs 西洋差异」制造惊喜感。
**落地方案**：Onboarding 最后一步，用一段话揭示「你的太阳星座 + 你的日主 → 两个体系共同指向 [核心结论]」，免费送这一句洞察，让用户觉得 Runae 比任何单一体系的 App 更深。然后 Paywall 接上「完整解读 →」。
**预期效果**：用户投入感提升，Onboarding 完成率 +15%，首次付费转化 +25%

---

### #3. 合盘功能（裂变炸弹）

**为什么是第三**：Co-Star 靠合盘功能打破圈层；Runae 有东西合断双引擎，合盘比任何单系 App 都有内容深度。
**落地方案**：新增「合盘测试」入口（首页显眼位置）→ 两人各填生辰 → 生成「东西合断合盘指数」（总评+3条免费亮点）→ 完整版$9.99 → 结果页有分享图（自动生成）→ 扩散。成本：命理引擎 API 调用约$0.05/次。
**预期效果**：每月新增1000次分享 → 自然下载量 +20%

---

### #4. 节气+月相推送 × 命盘个性化

**为什么是第四**：海外华人对中国节气有情感共鸣，这是 Runae 独家内容优势。推送是最低成本的日活手段。
**落地方案**：建一个「命理事件日历」：24节气 + 8个新月/满月 + 重要星相 = 32个年度推送节点。每个节点推送内容基于用户日主生成（「[日主]逢冬至，今年冬至对你意味着[X]」）。需要：推送服务（已有）+ 节气命理内容库（一次性建设）。
**预期效果**：推送打开率 +40%（个性化 vs 通用），7日留存 +15%

---

### #5. $0.99「体验一问」真人大师入口

**为什么是第五**：Hint 用 $0.52 试用把真人服务的门槛砍到心理底线，Runae 有 Agora 连麦已就绪，$99 直接跳太高。
**落地方案**：在报告页底部加「向大师提一个问题 $0.99」→ 用户提交文字问题 + 命盘数据自动发给大师 → 大师48小时内文字回复 → 回复后推送「大师回复了你，点击查看」→ 情感投入 → 引导升级到 $29 深度咨询 / $99 连麦。
**供给侧**：初期找3-5位兼职命理师（按单结算$3-5/问），规模化后开放平台。
**预期效果**：$99档转化漏斗打通，客单价从$29提升到$59均值
