## 7. 架构说明

```
客户端（浏览器）
    ↓
Caddy 反代（shenyuan.mylumee.cn:443）
    ↓
PM2 进程（Node.js · /opt/shenyuan/index.js）
    ├─ 前端静态页面服务
    ├─ API 路由（报告生成、支付、Webhook）
    └─ JSON 数据持久化（/opt/shenyuan/server/data.json）
    ↓
DeepSeek API（LLM 报告内容生成）
    ↓
Stripe API（支付处理）
```

**关键**：所有 API 只在 HK PM2 单进程跑，Vercel 不再处理（已移除 `vercel.json functions`）。这样保证 JSON 落盘生效，PM2 重启不丢单。
