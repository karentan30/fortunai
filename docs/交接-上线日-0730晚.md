## 2. 关键架构

```
用户 → Caddy(HTTPS) → index.js(PM2:port3021)
                         ├── GET /pages/*.html (前端静态)
                         ├── POST /api/bazi (DeepSeek)
                         ├── POST /api/hehun
                         ├── POST /api/xingming
                         ├── POST /api/ziwei
                         ├── POST /api/chat (限次)
                         ├── POST /api/create-checkout (Stripe)
                         └── data.json (订单持久化)
```

- **后端**: Node.js Express, 单文件 `server/index.js`
- **LLM**: DeepSeek API (通过 DS_KEY + DEEPSEEK_API_KEY)
