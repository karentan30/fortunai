## 1. 一句话定位 · 目标用户 · 核心痛点

### 一句话定位
> **"AI 帮你测五行色彩季型，一键找到命中注定的口红色号。"**

### 目标用户
- **主力**：18-35 岁华人女性，活跃在小红书/抖音，有 K-Beauty 意识，做过或想做个人色彩诊断但嫌线下贵（¥300-1280/次）
- **次力**：韩国用户（복用善缘韩国已有落地·퍼스널컬러 认知成熟）
- **增量**：海外华人（英文/繁中渠道）

### 核心痛点（三层）
| 层级 | 痛点 | 竞品漏洞 |
|------|------|---------|
| 功能层 | 不知道自己的冷暖调，线下太贵，线上测试结果不可信 | 海外头部 App 无中文；国内无头部 AI 产品 |
| 结果层 | 知道季型也不知道买哪支口红，理论→购买断链 | 告诉你是"冷夏"但不给色号 |
| 情感层 | 穿了多年"错误颜色"的顿悟感，想分享炫耀 | 结果页设计丑，不适合截图分享 |

## 6. 技术方案

### 整体架构（MVP）
```
前端 H5 (Next.js or 纯 HTML)
  ↓ 图片 base64
后端 API (Node.js / Python)
  ↓
[图像预处理层]           [AI 分析层]               [数据层]
  - 压缩到 512px          - Qwen-VL vision API      - 季型映射表（JSON）
  - 亮度均值检测           - prompt 工程（见下）      - 明星库（JSON）
  - EXIF 去除（隐私）      - 置信度提取              - SKU 带货表（JSON）
                           ↓
                    [结构化输出解析]
                    冷暖调 + 明暗度 + 季型 + 描述
                           ↓
                    [五行映射层]（规则引擎）
                    春暖→火木 / 夏冷→水金 / 秋暖→土木 / 冬冷→水金阴
```

### 核心 Prompt 设计（Qwen-VL）
```
你是专业的个人色彩顾问，专精亚洲肤色分析。
请分析这张照片中人物的以下特征：
1. 皮肤底调：黄调/粉调/中性调（冷暖判断依据）
2. 皮肤明度：浅/中/深
3. 皮肤饱和度：清透/柔和/浓郁
4. 发色：黑色/深棕/棕色/浅棕/其他（如有）
5. 眼白颜色：偏蓝白/偏黄白
6. 唇色：自然唇色描述

请输出 JSON 格式：
{
  "undertone": "warm|cool|neutral",
  "brightness": "light|medium|deep",
  "saturation": "bright|muted|soft",
  "season": "spring|summer|autumn|winter",
  "confidence": 0.0-1.0,
  "reasoning": "一句话说明判断依据"
}

注意：仅分析可见面部特征，如图片质量不佳请在 confidence 中体现（低于 0.6 = 建议重拍）。
```

### 五行叙事映射（规则引擎，运营可调）
| 季型 | 五行属性 | 叙事文案 |
|------|---------|---------|
| 春暖 Spring | 木·火 | "生机勃发·阳光向上·自然温暖系" |
| 夏冷 Summer | 水·金（阴） | "柔雾朦胧·月光清冽·雅致含蓄系" |
| 秋暖 Autumn | 土·木（老） | "丰收厚重·大地沉稳·成熟复古系" |
| 冬冷 Winter | 水·金（阳） | "冰雪凛冽·精准犀利·高冷对比系" |

### 光线误判解法（MVP 可行方案）
| 问题 | 检测方法 | 处理策略 |
|------|---------|---------|
| 室内暖黄灯偏暖 | 亮度均值 + 色温估算（RGB 比例） | 置信度低时提示"建议在自然光或白光下重测"，不阻断流程 |
| 美颜/滤镜磨皮 | Qwen-VL prompt 内加："如疑似美颜请降低 confidence" | 低置信度时提示重拍 |
| 侧脸/遮挡 | MediaPipe 478 关键点检测是否正脸（复用现有） | 不满足正脸→引导重拍 |
| 高对比度妆容 | Prompt 加"如已上妆请评估素颜底色特征" | 无法确定时 reasoning 注明，建议素颜重测 |

## 7. 合规红线

### 必须执行（上线前逐条打勾）
- [ ] **AIGC 标注**：所有 AI 生成内容页面底部注明"本结果由 AI 生成，仅供参考"（字号≥12px，不可藏）
- [ ] **非医疗声明**：禁止使用"诊断""医学依据""皮肤科"等医疗词汇；使用"分析""参考""建议"
- [ ] **容貌焦虑红线**：禁止文案："你的肤色不适合XX""XX 色让你显老丑"；改为正向："XX 色会让你更亮眼"

- [ ] **数据隐私**：用户照片处理完毕后 24h 内自动删除（不入库）；明确告知用户照片用途
- [ ] **未成年保护**：如收集生日字段，<18 岁不展示带货链接
- [ ] **带货合规**：抖音联盟链接必须有带货资质；不得虚假标注佣金比例
- [ ] **无绝对化承诺**：不出现"100% 准确""专业认证"等绝对化表述

## 10. C端PM专家挑刺：最弱3点+补法

---

**这一版最弱的三个地方：**

### 弱点 1：准确率预期管理不足，信任危机是最大死穴
**问题：** PRD 把"光线误判"处理成技术问题，但核心是**用户信任危机**。Qwen-VL 用 Vision LLM 做肤色判断，天然存在随机性——同一张照片两次调用可能输出不同季型。竞品 Zamface 的一星评论 80% 都是"测出来不准""和朋友在专业机构测的不一样"。一旦小红书出现"AI 测色不准"的批评帖，病毒传播会反噬。

**补法（要在 MVP 前定）：**
1. **锁定输出稳定性**：同一用户 24h 内重测，结果必须相同（后端 cache by image hash）
2. **调整产品定位叙事**：不要说"AI 帮你测准季型"，改说"AI 带你探索你的色彩美学风格"——把"准确率"期望值往下压，把"趣味性"期望值往上抬
3. **加入用户自我校准**：结果页加 2 个选项"我觉得这个结果对" / "帮我重新分析"——用户主动确认后才推带货；误判用户不会带货，不如让他重测

---

### 弱点 2：五行叙事没有闭环，是噱头不是护城河
**问题：** PRD 把"五行色彩"列为最大差异化，但目前只有 4 个季型到五行的静态映射文案——这是贴标签，不是叙事。用户测完之后五行和季型之间没有产生任何逻辑联系（为什么水金调的人要避开暖橘？从五行视角是说不通的）。竞品一旦复制这个说法，护城河立刻消失。

**补法：**
1. **建立五行色彩理论框架**（在报告内用 1 页专门解释）：参考中医色彩理论（青=木/赤=火/黄=土/白=金/黑=水），把五行调和原则（相生/相克）翻译成"适合穿什么色"的逻辑依据，让用户觉得"说得通"
2. **和善缘八字联动**（中期）：如果用户有八字数据，可以做命盘×色彩的交叉推荐——"你的日柱是庚金，天然适合冷色系，和你的季型高度吻合"。这才是真护城河，竞品无法复制

---

### 弱点 3：带货 SKU 维护成本被低估，会成为持续人力黑洞
**问题：** PRD 的带货部分看起来是一个静态 JSON 表，但实际上彩妆 SKU 是高频变动的：口红经常断货/停产/限量/改价，联盟佣金比例每月变，抖音小店商品上下架快。如果 SKU 不维护，用户点击进去发现链接 404 或者商品已改色，体验崩溃。这是一个低估了运营成本的设计。

**补法：**
1. **MVP 阶段**：每个季型只推 1 支主力口红（不是 3 支），选品标准是"该品牌月销稳定>1000件+抖音联盟长期在线"，宁少勿滥
2. **加链接健康检测**：每日 cron 跑一遍带货链接状态，失效自动报警（5 行 Python 脚本，不是大工程）
3. **运营 SOP 定明**：每月第一周专人更新 SKU 表，以季度为周期重新选品——在 PRD 里明确这个运营节奏，别让工程师默默维护
