## 二、产品玩法：UX流程拆解

### 标准路径（全市场通用）
```
上传自拍/拍摄照片
  → AI提取：肤色RGB / 发色 / 眼睛颜色 / 嘴唇色
  → 判断：冷暖调（cool/warm undertone）+ 明暗度 + 饱和度
  → 映射到12/16季型（春暖浅/春暖明/夏冷浅/夏冷柔...）
  → 输出：季型标签 + 专属色盘 + 忌色 + 妆容/穿搭/发色推荐
```

### AI技术栈
- **核心算法**：深度学习图像分类，训练数据含数万张不同肤色面部图像
- **特征提取**：同时分析皮肤颜色分布、发色、眼色、眉色、唇色共5个维度（非单一肤色）
- **分类维度**：
  - 温度（冷/暖 undertone）
  - 明度（light/deep）
  - 彩度（bright/muted）
  - 再映射到12或16个细分季型
- **技术提供方**：Perfect Corp（YouCam系）有商业SDK；也有开源路线（HuggingFace模型微调）

### 输出标配内容
1. 季型标签（如"冷夏·Soft Summer"）
2. 代表色盘（20-120色）
3. 忌讳色/不适合色
4. 妆容推荐（口红/腮红/眼影具体色号）
5. 发色推荐
6. 穿搭颜色建议
7. （高端）适合金属色：黄金/白金哪个更适合

## 五、可抄的爆款点

### 内容/传播爆款公式
1. **明星/偶像季型揭秘**："IU原来是冷夏！你和她同类型吗？" → 强认同感，分享动力极强
2. **换脸对比**：同一张脸，冷暖调两套妆容对比图 → 视觉冲击，截图分享率极高
3. **MBTI+季型组合**："INFP冷夏是世界上最温柔的存在" → 双重标签游戏，病毒系数x2
4. **忌讳色揭秘**："我以前一直穿这个颜色，难怪显老！" → 恐惧感+顿悟感，转发高
5. **免费测试+截图晒结果**：结果页面设计成适合截图分享的样式（含季型+名人脸）
6. **彩妆色号对照**："你是暖春？这4支口红专为你选" → 直接种草，购买转化

### 病毒传播机制
- 结果页面一定要好看、有分享按钮 → 小红书/Instagram可直接发帖
- "测一测你是哪个季型" CTA极好用，好奇心驱动
- 细分标签越精准越有分享价值（"你不只是'冬季型'，你是'冷冬明亮型'"）

## 六、现有产品的坑与空白机会

### 现有产品的主要痛点

| 问题 | 细节 |
|------|------|
| **光线敏感性**：最大痛点 | 同一张脸在不同光线下测出不同季型，用户信任度低。现有方案没做光线归一化 |
| **数据集偏差** | 训练集多为欧美白人面孔，亚洲肤色（尤其黄皮、小麦皮、混血）准确率显著下降 |
| **高对比度脸偏误** | TikTok滤镜普遍对高对比度面孔优化，橄榄色/中性调肤色误判率高 |
| **输出无法用** | 告诉你是"冷夏"但不告诉你具体买哪支口红 → 中国用户需要色号，不需要理论 |
| **缺乏中文语境** | 海外头部产品（Dressika/Palette）无中文适配；韩国产品无简体中文 |
| **中国无头部App** | 国内没有一个超过百万下载的专属个人色彩App；市场分散在小红书笔记+线下工作室 |
| **变现路径断裂** | 诊断完不知道买什么 → 没有接电商/彩妆品牌的产品完成闭环 |

### 差异化空白机会

1. **亚洲肤色专项模型**：专门针对中韩日肤色训练，标榜"亚洲人专属色彩诊断"，精准度优势
2. **中文生态闭环**：诊断→推荐具体淘宝/京东商品→下单；海外产品完全不做
3. **社交分享原生设计**：结果页做成"为小红书而生"的视觉卡片，一键发帖
4. **命理+色彩交叉**：善缘独有切入点 — "你的八字五行决定了你的季型"（五行色→季型色，创造理论护城河）
5. **彩妆品牌B2B**：给国产彩妆品牌提供嵌入式诊断工具，品牌付费买SDK（参考Perfect Corp路线）
6. **韩国+中国双语**：善缘已有韩国落地，可复用服务器和用户

## 七、技术实现门槛

### 方案一：调用现有API（最快，1-2周上线）
- **Perfect Corp SDK** / **YouCam**：商业API，直接调用；精度高；按使用量收费
- **Media.io AI肤色检测**：有免费层
- 缺点：被供应商绑定；无法优化亚洲肤色

### 方案二：开源模型微调（中等，2-4周）
- 用HuggingFace上的皮肤分割+颜色分类模型
- 自建简单分类器：取脸部特征区域平均色→映射到暖冷调→分型
- 技术可行性：✅ 中等难度；需要懂Python/CV
- 核心工程量：图像预处理（光线归一化） + 颜色空间转换（RGB→HSL/LAB）+ 多特征加权分类

### 方案三：大模型Vision接口（最快验证，3天MVP）
- 把用户照片发给GPT-4o/Qwen-VL，prompt要求分析肤色/眼色/发色并输出季型
- 已有先例：多个网页产品用这个方式
- 精度一般但够用；最快验证市场
- **善缘现成条件**：已有Qwen-VL接入（面相分析），可直接复用！

### 实现难度总评
```
MVP验证（Vision API方案）：★★☆☆☆  3-5天，1个工程师
中等精度产品（开源模型）：★★★☆☆  2-4周，需CV能力
高精度亚洲特化：★★★★☆  2-3个月，需专项数据集
```

## 八、值不值得做 / 怎么切入

### 结论：**值得做，但要以病毒内容工具切入，不要以App切入**

**为什么值得做：**
- TikTok 7.5亿播放、Dressika 660万下载证明需求真实；中国几乎没有头部数字产品，是蓝海
- 技术门槛低（3天MVP）；善缘已有Qwen-VL，基础设施零成本复用
- 结果天然适合分享，病毒系数高，可为善缘带来用户增量

**怎么切入（3步走）：**
1. **第一步（1周）**：用Qwen-VL做H5测试页，输出季型+专属色盘+3条适合的口红色号推荐；做成"为小红书截图而生"的结果页；免费。目标：10万次测试带来10万次曝光
2. **第二步（2-4周）**：接淘宝/小红书好物联盟，在结果页推荐对应季型的彩妆商品，按佣金变现
3. **第三步（可选）**：韩国版本复用善缘韩国基建，标榜"亚洲人专属"，借K-Beauty热度获量

**核心差异化点：** 善缘独有的"五行色彩"理论——春暖型对应五行中的"火木"，冬冷型对应"水金"——这个叙事没有任何竞品做过，既有趣味性又有命理护城河，天然适合善缘平台

**风险：** 准确度争议会有；应对方案是加"仅供参考·建议结合线下专业诊断"免责文案，同时把"结果好玩"优先于"结果准确"的产品定位
