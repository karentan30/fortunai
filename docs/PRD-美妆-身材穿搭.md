# PRD：身材穿搭 · 明星风格参考
> 模块编号：美妆产品 #4 / 版本 v1.0 / 日期 2026-08-18

---

## 0. 一句话定位

**"输入身高体重，AI 告诉你和哪个明星同款身材，以及她们怎么穿出来的。"**

---

## 1. 定位 · 目标用户 · 核心痛点

### 1.1 产品定位
同款身材明星穿搭顾问——以"和 XX 明星同款身材"为病毒钩子，以体型科学穿搭公式 + 精选单品推荐为变现核心，$9.90 一份可执行 PDF 穿搭手册收口。

### 1.2 目标用户
| 主要用户 | 画像 |
|----------|------|
| **核心（80%）** | 18-35 岁女性，华人/东亚/东南亚；不知道自己"该怎么穿"；有一定穿搭意愿但缺乏体系 |
| **次要（15%）** | 产后、体重变化后需要重建穿搭认知的女性 |
| **海外华人（5%）** | 英文穿搭资讯不够贴合亚洲身材比例，有中文穿搭内容需求 |

### 1.3 核心痛点（三层）
1. **不知道自己是什么体型**：梨形？苹果型？——没有清晰的体型认知起点
2. **不知道体型对应的穿搭逻辑**：扬长避短只是口号，没有具体到"穿什么腰线的裤子"
3. **不知道和谁对标**：没有明星镜像参照，无法把"穿搭教程"映射到自己身上

## 2. 用户流程（主路径）

```
[第1步] 输入身高 + 体重（必填）
         ↓ 可选：上传正面全身照（二期 MediaPipe Pose 分析比例）
[第2步] AI 判断体型分类
         → 五大类型：梨形 / 沙漏型 / H型（直筒型）/ 倒三角型 / 苹果型
         → 叠加身高段：娇小（<160cm）/ 标准（160-167cm）/ 高挑（≥168cm）
         → 输出：体型名称 + 一句正向描述（参考"同款身材明星：XXX"）
[第3步] 免费预览层（钩子）
         → 体型标签 + 1-2 位同款身材明星图文卡
         → 穿搭原则摘要（1条，模糊化，非完整公式）
         → CTA："查看完整穿搭手册 $9.90 →"
[第4步] 付费解锁 PDF 手册
         → 完整穿搭公式（上装/下装/外套/配饰/禁忌）
         → 3-5 位同款明星的实拍穿搭解析
         → 精选单品推荐（品类+价格带+联盟带货链接）
         → 场合穿搭建议（日常/职场/约会/正式场合）
[第5步] 单品跳转
         → 点击单品图片 → 跳转联盟链接（淘客/亚马逊Associate/LTK）
         → 用户购买 → 平台分佣给我们
```

## 3. 免费钩子 vs 付费点

| 层级 | 内容 | 策略意图 |
|------|------|---------|
| **完全免费** | 体型分类标签（梨形/沙漏/H/倒三角/苹果） | 给体型认知，满足最基础好奇心 |
| **免费预览（模糊门）** | 1-2 位同款明星名字 + 半身图 + 1条穿搭提示（文字模糊打码后半段） | 制造"差一点"的信息缺口感，驱动付费 |
| **$9.90 完整解锁** | 完整穿搭公式 + 多场合拆解 + 单品清单（可点击购买） + PDF 可保存 | 核心变现；PDF 可打印/保存 → 留存钩子 |

**病毒传播钩子**：体型 + 明星匹配结果卡，可一键分享（格式："我和 XXX 同款身材 🎉 AI 帮我找的穿搭公式"），带产品链接。参考 Gradient 的 KOL + 截图分享机制。

## 4. 变现闭环

### 4.1 主变现：$9.90 PDF 报告
- 定价对标美妆模块统一：$9.90 单次购买，无订阅要求
- 毛利极高（生成成本＜$0.20/份，AI 调用 + PDF 渲染）
- PDF 落地格式提升感知价值（vs 纯 H5 页面）

### 4.2 被动变现：服装联盟带货（长尾）
| 平台 | 佣金率 | 适配场景 |
|------|--------|---------|
| **亚马逊 Associates** | 3-8%（服装类） | 海外用户（北美/东南亚/欧洲） |
| **LTK (LikeToKnow.it)** | 品牌直谈，均值 10-20% | 高客单品牌合作 |
| **淘宝客（阿里妈妈）** | 8-20%（女装） | 华语市场 |
| **抖音小店精选联盟** | 20-40%（直播带货类） | 大陆用户 + 内容合作 |

**带货逻辑**：单品推荐精而不多（每个体型 × 每个品类 ≤ 3 个选项），避免选择恐惧；每个单品嵌入跟踪链接；PDF 内链接可点击（H5 版PDF渲染）。

### 4.3 潜在变现：品牌联名专属穿搭手册
- 与女装品牌合作出"XX 品牌 × 梨形身材专属穿搭手册"：品牌付内容植入费，我们提供 AI 生成报告，双向获客
- 可参考美妆板块 B2B 白标 API 路线（后期）

## 5. 功能范围

### MVP（快速上线·规则版·仅输入身高体重）

**包含：**
- 身高体重输入 UI（简洁，2 步骤）
- 基于规则的体型分类算法（见第 6 节，逻辑简单但要诚实标注）
- 体型 + 明星匹配数据库（五大体型 × 3-5 位明星，共 15-25 条手工整理数据）
- 免费结果页（体型卡 + 模糊预览）
- $9.90 付费门（复用现有 Stripe 支付链路）
- PDF 生成（基于模板，LLM 注入个性化穿搭建议）
- 联盟带货链接嵌入 PDF

**不包含（MVP 阶段）：**
- 全身照上传（二期）
- 虚拟试穿（三期或不做）
- AR 功能

### 二期（4-8 周后·加全身照 MediaPipe Pose）

- 用户上传正面全身照
- MediaPipe Pose 提取 17 个关键点：肩宽、腰宽、臀宽、腿长比例
- 替代纯规则分类，提升体型判断准确性（尤其区分 H 型与沙漏型的细微差别）
- 技术复用已有 MediaPipe 栈（美妆产品 #1 个人色彩分析已接入）

## 6. 技术方案（诚实版）

### MVP：规则分类

```
WHR（腰臀比）= 腰围估算 / 臀围估算
BMI = 体重(kg) / 身高(m)²

体型分类规则（基于身高体重反推的近似）：

梨形：BMI 18-27 + 典型亚洲女性"下半身略重"
      → 系统提示：该判断基于统计规律，实际比例因个体差异较大
苹果型：BMI > 26 + 脂肪分布向腹部集中（问卷辅助确认）
沙漏型：BMI 18-23 + 自述腰线明显（可加 1 题问卷：腰围是否比肩宽臀宽明显细？）
H型：BMI 17-22 + 无明显腰线差（腰肩臀基本等宽）
倒三角：BMI 17-22 + 肩宽 > 臀宽（可加问卷：肩膀是否比臀部更宽？）
```

**诚实标注（必须在 UI 里显示）：**
> "体型判断基于身高体重统计模型，仅供参考。如需更准确结果，可上传全身照（二期功能）。体型本无好坏，穿搭建议以扬长为核心。"

### 二期：MediaPipe Pose（升级路径）

- 客户端 JS 跑 MediaPipe Pose，实时提取关键点，无需上传裸身照片
- 计算：肩宽/腰宽/臀宽的像素比例 → 映射到 WHR 和 SHR
- 准确率显著高于规则版（能区分 H 型 vs 苹果型，两者 BMI 相近但体型不同）
- **隐私处理**：照片在设备本地处理，不上传服务器，只传关键点坐标（参考美妆板块脸部分析隐私方案）

### 明星数据库

手工整理，非实时爬取（避免版权/API 费用）：
- 每体型 3-5 位明星：中文市场（刘亦菲/杨紫/迪丽热巴等）+ 海外选项（Kim Kardashian/Taylor Swift/Selena Gomez 等）
- 数据内容：明星名字、代表穿搭风格描述、标志性穿搭要素（非照片，避免版权问题）
- 明星图片：链接至公开来源（小红书/Getty 公开图），不自托管，MVP 阶段用文字描述代替图片

## 7. 合规红线（重点）

### 7.1 绝不制造身材焦虑（第一红线）

参考 Slim 减脂产品健康第一红线原则，本产品同样适用：

**禁止表述（举例）：**
- ❌ "苹果型身材需要遮住腹部赘肉"
- ❌ "你的身材缺点是 XXX"
- ❌ "BMI 过高说明你需要减肥才能穿好"
- ❌ "这个体型不适合穿 XXX（否定式）"

**必须使用正向表述：**
- ✅ "苹果型身材腰线高、上半身轮廓利落——A 字裙最能展现这条优势线"
- ✅ "你的肩部线条强劲有力，和 XX 明星同款——V 领和深色上衣放大这个优势"
- ✅ "每种体型都有最适合它的穿搭公式"

**写作原则：**
> 只讲"扬长"，不讲"避短"——"这样穿能让腿显更长"而非"这样穿能遮住粗腿"。措辞参考 Slim 教练语气铁律：讲为什么 + 安抚不吓唬 + 诚实科学 + 正向肯定 + 具体。

### 7.2 体型分类 ≠ 审美等级

- UI 中五大体型平等展示，无颜值/美丑标签
- 每种体型配一句正向解读（不是"缺陷补救"）
- 明星匹配：每个体型的明星都是公认有吸引力的，不得出现"这体型只能对标 XXX（负面联想明星）"

### 7.3 BMI / 体重相关

- 不展示用户 BMI 数值本身（避免制造体重焦虑）
- 不在结果页出现"超重/肥胖"等医学定性词汇
- 如用户输入 BMI 明显过低（BMI<16）或过高（BMI>35），温和提示"数据可能超出我们的模型范围，建议咨询专业造型师"，不拒绝服务

### 7.4 明星肖像权

- MVP 阶段：文字描述明星穿搭特征，不自行托管明星照片
- 如需图片：链接至已公开的媒体来源（Getty Public Images / 明星官方账号 embed），不截图上传
- 避免"你长得像 XXX"的人脸比对（那是明星脸模块 #2，此处只比体型，不比脸）

### 7.5 AIGC 标注

- PDF 报告页脚：「本报告由 AI 生成，仅供穿搭参考，不构成医疗或营养建议」
- 体型判断页面：「AI 体型分析 / AI Body Type Analysis」标注（符合国内 AIGC 规范）

### 7.6 儿童/青少年保护

- 输入年龄校验（如有）：不向 16 岁以下用户提供体型分析（避免青少年身体意象问题）
- 如无年龄门，结果页不出现体重相关数字

## 10. C 端穿搭 PM 挑刺：最弱 3 点 + 补救方案

### 弱点 1：仅凭身高体重判断体型，准确率太低，用户口碑风险高
**具体问题**：两个人身高 163cm 体重 55kg，一个梨形（下半身脂肪为主）、一个苹果型（腹部脂肪为主），规则算法完全无法区分。用户拿到错误的体型 + 错误的明星匹配 + 错误的穿搭建议 → 退款 + 负评。

**补救方案**：
1. MVP 阶段加 2-3 题辅助问卷（"你觉得自己哪个部位最丰满？肩/腰/臀/腿"），提升分类精度，代价很低
2. 对结果标注置信度："基于您的输入，最接近梨形（置信度：中等）。上传全身照可获得更精准判断 →" — 用置信度透明化代替硬承诺
3. 让用户自选最终体型（系统推荐 + 用户确认机制），降低"我明明不是这个体型"的负评率

### 弱点 2：明星匹配是产品的病毒钩子，但版权和肖像权暗雷多
**具体问题**：MVP 说"文字描述不托管图片"，但用户分享出去的卡片如果带明星大头照，平台（微信/小红书）可能警告；如果不带图只有文字，分享卡视觉传播力大幅下降（参考 Gradient 的可分享图是核心传播武器）

**补救方案**：
1. 分享卡只显示"体型轮廓插画"（非真人照片，AI 生成或矢量图）+ 明星名字文字，规避图片版权
2. 聘（或用 AI）手绘 5 种体型的时尚插画轮廓，每种体型 1-2 个插画形象，配色高颜值，满足截图传播需求
3. 明星名字以"灵感来自：XXX 的穿搭风格"表述，而非"你和 XXX 一样"——降低肖像权纠纷风险

### 弱点 3：单品推荐是联盟变现核心，但手工整理 20-30 款难以保持时效性（季节/断货/价格变化）
**具体问题**：服装上新快（快时尚 2 周一轮），手工整理的淘宝客链接 3 个月后很可能 30% 断链；用户点进去发现下架 → 体验崩溃，带货 GMV 归零

**补救方案**：
1. MVP 阶段推荐品类（如"高腰A字裙""V领上衣"），不绑定具体 SKU 链接，用关键词跳转搜索结果页（淘宝搜索链接 = 永久有效）
2. 第 8 周前接淘客实时 API（阿里妈妈有开发者 API，可按品类实时拉佣金商品），实现动态更新
3. 建立季度运营 SOP：每季度（3 个月）人工校验一次单品清单，更换断链，更新当季流行款
