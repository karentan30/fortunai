## 红线（碰之前先看这几条）

- 🔴 **`cf-ipcountry` 默认不可信**。生产是 Caddy 直连，前面没有 Cloudflare/Vercel，
  这个头谁都能自己加 —— 曾经加一个就能把 $11.99 买成 ¥44.90，且结账按低价真扣钱。
  现在只信 IP 查询。**哪天真挂到 CDN 后面才可以开 `TRUST_CDN_GEO=1`**，别为了调试顺手打开。
  （X-Forwarded-For 伪造实测挡得住，是 Caddy + `trust proxy 1` 的功劳，别动这个设置。）

- 🔴 **展示价和实收价必须同一个判定**。两边都走 `server/lib/price-region.js` 的 `priceRegion(req)`，
  价格只从 `PRODUCTS` 目录取。任何地方再写一份汇率或价目表 = 页面显示一个价、扣款另一个价。

- 🔴 **`assets/js/price.js` 必须放在 `<head>`**，且在页面自己的 inline script 之前。
  放晚了 `RunaePrice.ready()` 的注册会被静默跳过，页面不报错、价格就是不换。

- 🔴 **会员三档的实收价来自 Stripe 固定 price，不是目录**（monthly $9.90 / quarterly $24.90 / yearly $69）。
  改会员价必须 Stripe 和目录两边一起改，否则没有任何测试会报错。

- 🔴 **代烧/祈福是下架不是删除**。`RETIRED_PRODUCTS` 挡新单，目录条目保留，
  老买家的订单和报告还查得到。别去清理那些 `joss_*` 条目。

- 生产部署要 Karen 亲口说「部署」。流程：备份 data.json → `git fetch && git reset --hard origin/main`
  → `pm2 restart shenyuan` → 查 `/api/health`。`/opt/shenyuan` 里有一堆 `??` 备份文件，reset 不会动它们。
