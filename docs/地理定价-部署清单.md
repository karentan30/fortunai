## 前端部署

### 1. 脚本文件检查

- [ ] `public/geo-pricing.js` 已创建（500+ 行）
- [ ] 包含以下功能：
  - [ ] IP 地理位置检测
  - [ ] 缓存管理（24h）
  - [ ] 价格显示更新
  - [ ] 支付集成
  - [ ] 事件系统

### 2. HTML 集成

#### 方案 A：落地页（推荐）

- [ ] 创建/更新落地页：`pages/lp-bazi-geo.html`
- [ ] 页面顶部 `<head>` 中添加脚本：
  ```html
  <script src="/geo-pricing.js"></script>
  ```

- [ ] 使用 `data-price` 标记价格元素：
  ```html
  <span data-price="bazi_full">¥99</span>
  ```

- [ ] 使用 `data-currency-symbol` 显示符号：
  ```html
  <span data-currency-symbol>¥</span>99
  ```

- [ ] 支付按钮使用 `GEO.createCheckout()`：
  ```html
  <button onclick="GEO.createCheckout('bazi_full')">购买</button>
  ```

#### 方案 B：现有页面集成

对每个需要本地定价的页面：

1. 在 `<head>` 添加脚本：
   ```html
   <script src="/geo-pricing.js"></script>
   ```

2. 替换所有硬编码价格为动态元素：
   ```html
   <!-- 之前 -->
   <span>¥99</span>

   <!-- 之后 -->
   <span data-price="bazi_full">¥99</span>
   ```

3. 更新支付按钮：
   ```html
   <!-- 之前 -->
   <button onclick="checkout('bazi_full')">购买</button>

   <!-- 之后 -->
   <button onclick="GEO.createCheckout('bazi_full')">购买</button>
   ```

## 故障排查

### 症状：地理位置检测失败

**原因**:
1. IP API 服务不可用
2. 防火墙拦截
3. 网络延迟

**解决**:
```bash
# 检查 API 服务
curl https://get.geojs.io/geolocation/ip.json

# 检查日志
pm2 logs shenyuan | grep '[geo'
```

### 症状：支付流程报错

**原因**:
1. 价格验证失败（VPN 用户）
2. 货币配置不一致
3. Stripe/支付宝 API 问题

**解决**:
```javascript
// 放宽价格容差
// 在 payment.js 中修改：
if (amount < serverPrice * 0.8) {  // 改为 ±20%
  return res.status(400).json({error: 'Price mismatch'});
}
```
