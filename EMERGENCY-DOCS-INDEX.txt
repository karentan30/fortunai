【文档 4】QUICK-FIX-COMMANDS.sh (21KB) 🤖 自动化脚本
================================================================================

用途: 15 个一键修复命令
简介: Bash 脚本，自动执行 5-15 分钟的修复步骤

15 个命令分类:

【支付相关】(1-5)
  1. 修复支付端点不响应 → pm2 restart + verify
  2. 修复微信密钥缺失 → 补充 .env + 重启
  3. 修复支付宝回调 404 → 检查路由 + webhook
  4. 补偿失败订单 → 手动入账
  5. 重置支付 webhook → 注销 + 重新注册

【服务可用性】(6-10)
  6. 修复服务频繁重启 → 查错误日志
  7. 修复内存泄漏 → 强制重启 + 清空缓存
  8. 修复 PM2 损坏 → 重新初始化
  9. 修复 Caddy 反代 → 重启 Caddy
  10. 启用集群模式 → PM2 cluster max

【数据恢复】(11-15)
  11. 恢复数据（从 Git） → git checkout + 重启
  12. 从备份恢复 → cp + 重启
  13. 重生成邀请码 → API 调用
  14. 修复数据不一致 → 脚本检查 + 修复
  15. 热修复代码补丁 → git pull + 重启

使用方法:
  bash QUICK-FIX-COMMANDS.sh 1    # 执行命令 1
  bash QUICK-FIX-COMMANDS.sh 7    # 执行命令 7
  bash QUICK-FIX-COMMANDS.sh help # 查看帮助

何时查看:
  ✅ 需要快速一键修复时
  ✅ 不想手工输入长命令时
  ✅ 想自动验证恢复状态时
