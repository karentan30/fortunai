🚀 一分钟快速开始

1️⃣ 生成昨天的日报
   $ node server/daily-report.js
   
   输出: server/reports/report-2026-08-07.json
   包含: DAU/收入/转化率/支付成功率/环比对标/洞察分析

2️⃣ 导出cohort留存数据(用于投资者演讲)
   $ node server/analytics-export.js cohort json export/cohort.json
   
   输出: Day1/3/7/14/30留存率表 (支持JSON/CSV)

3️⃣ 查看留存可视化(无需数据源，Demo模式)
   $ open server/cohort-analysis.html
   
   浏览器中:
   - 选择"Demo数据"
   - 自动生成90天模拟数据
   - 留存趋势图 + 表格

4️⃣ 导出其他维度
   $ node server/analytics-export.js funnel json      # 转化漏斗
   $ node server/analytics-export.js traffic csv      # 流量来源(CSV)
   $ node server/analytics-export.js products json    # 商品销售排行
   $ node server/analytics-export.js payment json     # 支付方式分布
   $ node server/analytics-export.js retention json   # 用户留存率

📊 核心概念

daily_stats (日统计字段)
├── page_views           页面访问数
├── unique_visitors      DAU(日活用户)
├── report_generated     命盘生成人数
├── checkout_started     进入支付人数
├── payment_completed    支付成功笔数
├── payment_failed       支付失败笔数
├── revenue             总收入(USD)
├── avg_session_duration 平均会话时长(秒)
├── bounce_rate         跳出率(%)
├── top_sources         流量来源{source: count}
├── top_products        畅销产品{product: count}
└── payment_methods     支付方式{method: count}

关键指标计算
├── DAU = unique_visitors
├── ARPU = revenue / DAU
├── 转化率 = payment_completed / page_views * 100%
├── 支付成功率 = payment_completed / (payment_completed + payment_failed) * 100%
├── D1留存 = 第2天活跃用户 / 新增用户 * 100%
└── D7留存 = 第8天活跃用户 / 新增用户 * 100%

🐛 故障排查

Q: 报告显示 DAU: 0?
A: data.json可能为空。检查:
   cat server/data.json | jq '.daily_stats | keys'

Q: Cohort分析无数据?
A: data.json缺少users字段。检查:
   cat server/data.json | jq '.users | length'

Q: CSV无法在Excel打开?
A: 改用JSON格式，或指定UTF-8编码

Q: 脚本报错"Cannot find module"?
A: 确保在shenyuan目录运行，检查data.json路径
