## 生产流程

### 用即梦生成步骤
1. 打开 jimeng.jianying.com
2. 选"文生视频" → 竖版 9:16
3. 粘贴上面每个镜头的 prompt
4. 时长选3-5秒
5. 下载 → 存到 `output/CN0X/scene_0X.mp4`

### 剪映后期（每支约30分钟）
1. 导入所有 scene 片段 → 按顺序拼接
2. 加入口播配音（自录或豆包TTS）
3. 全程字幕（每句1行，字体白色加黑描边）
4. 配BGM：玄幻轻音乐，前3秒无音乐增紧张感
5. 导出 1080x1920，60fps

### 发布时间
- 最佳：工作日 12:00-13:00 或 20:00-22:00
- 标题用 hook 第一句原文
- 话题标签固定5个
