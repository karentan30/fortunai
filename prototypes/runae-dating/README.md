# Runae · 通过五行认识新朋友

最新入口：打开 `start.html`，先输入生日查日主，可展开填写九项个人亮点，再进入建档确认。请先阅读 [最新接续说明](接续说明-2026-11-04.txt)。

- `friends.html`：发现朋友、日历、合盘流程模拟、个人卡、公开权限及房车照片本地预览。
- `posters.html`：四款分享海报；`?design=1&export=1` 至 `4` 为1080×1440图片导出版式。
- `share.html`、`pair.html`、`index.html`：前期分享卡、双人结果和完整App样稿，保留对照。
